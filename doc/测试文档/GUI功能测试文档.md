## 1. 功能模块划分

### 1.1 主界面布局结构

```
┌─────────────────────────────────────────────────────────────┐
│                    顶部工具栏 (TopToolBar)                    │
│  菜单栏 | 文件操作 | 编辑操作 | 视图操作 | 用户信息 | 运行控制  │
├────────────┬────────────────────────────────────────────────┤
│            │         任务导航栏 (TaskNavigationBar)          │
│  树形视图  ├────────────────────────────────────────────────┤
│            │                                                │
│ (TaskTree) │           画布区域 (NodeCanvas)                 │
│            │         - 节点拖拽                              │
│            │         - 连线绘制                              │
├────────────┤         - 框选操作                              │
│            │         - 右键菜单                              │
│  小地图    │                                                │
│ (MiniMap)  ├────────────────────────────────────────────────┤
│            │          日志面板 (LogPanel)                    │
└────────────┴────────────────────────────────────────────────┘
```

### 1.2 功能模块清单

| 模块编号 | 模块名称 | 主要功能 | 测试优先级 |
|---------|---------|---------|-----------|
| M01 | 顶部工具栏 | 文件操作、编辑操作、视图控制、任务管理 | ★★★★★ |
| M02 | 画布交互 | 节点创建、移动、编辑、删除、连线 | ★★★★★ |
| M03 | 树形视图 | 任务组导航、节点管理、层级展示 | ★★★★☆ |
| M04 | 任务导航栏 | 多任务组切换、标签页管理 | ★★★★☆ |
| M05 | 日志面板 | 日志输出、搜索、导出、多标签页 | ★★★☆☆ |
| M06 | 小地图 | 画布缩略图、视口导航 | ★★★☆☆ |
| M07 | 面板管理 | 面板展开/收起/弹出 | ★★☆☆☆ |
| M08 | 撤销重做 | 操作历史管理 | ★★★★☆ |
| M09 | 缩放平移 | 画布缩放、平移 | ★★★☆☆ |
| M10 | 快捷键 | 键盘快捷操作 | ★★★★☆ |
