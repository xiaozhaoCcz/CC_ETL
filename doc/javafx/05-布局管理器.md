# 05-布局管理器

## 5.1 布局管理器概述

布局管理器（Layout Manager）负责自动排列和调整子组件的位置和大小。JavaFX提供了多种布局容器，每种都有不同的布局策略。

### 5.1.1 常用布局管理器

| 布局 | 描述 | 适用场景 |
|------|------|----------|
| **BorderPane** | 将区域分为上、下、左、右、中五个区域 | 经典应用布局 |
| **HBox** | 水平排列子组件 | 工具栏、按钮组 |
| **VBox** | 垂直排列子组件 | 表单、菜单 |
| **GridPane** | 网格布局 | 表单、计算器 |
| **FlowPane** | 流式布局，自动换行 | 标签云、图片墙 |
| **StackPane** | 堆叠布局，子组件重叠 | 重叠效果、居中对齐 |
| **AnchorPane** | 锚点布局，固定边距 | 复杂自定义布局 |
| **TilePane** | 瓦片布局，统一大小 | 图标网格 |

## 5.2 BorderPane（边框布局）

BorderPane将区域分为Top、Bottom、Left、Right、Center五个部分，是最常用的应用布局。

### 5.2.1 基本使用

```java
package com.example.javafx.layout;

import javafx.application.Application;
import javafx.geometry.Insets;
import javafx.scene.Scene;
import javafx.scene.control.Button;
import javafx.scene.control.Label;
import javafx.scene.control.TextArea;
import javafx.scene.layout.BorderPane;
import javafx.scene.layout.HBox;
import javafx.scene.layout.VBox;
import javafx.stage.Stage;

public class BorderPaneDemo extends Application {

    @Override
    public void start(Stage primaryStage) {
        BorderPane root = new BorderPane();
        
        // Top - 标题栏
        Label titleLabel = new Label("BorderPane 演示");
        titleLabel.setStyle("-fx-font-size: 20px; -fx-font-weight: bold;");
        HBox topBox = new HBox(titleLabel);
        topBox.setStyle("-fx-padding: 10; -fx-background-color: #3498db;");
        topBox.setAlignment(javafx.geometry.Pos.CENTER);
        root.setTop(topBox);
        
        // Left - 侧边栏
        VBox leftBox = new VBox(10);
        leftBox.setStyle("-fx-padding: 10; -fx-background-color: #ecf0f1;");
        leftBox.setPrefWidth(150);
        for (int i = 1; i <= 5; i++) {
            Button btn = new Button("菜单 " + i);
            btn.setPrefWidth(130);
            leftBox.getChildren().add(btn);
        }
        root.setLeft(leftBox);
        
        // Right - 工具面板
        VBox rightBox = new VBox(10);
        rightBox.setStyle("-fx-padding: 10; -fx-background-color: #ecf0f1;");
        rightBox.setPrefWidth(150);
        Label toolLabel = new Label("工具");
        toolLabel.setStyle("-fx-font-weight: bold;");
        Button tool1 = new Button("工具1");
        Button tool2 = new Button("工具2");
        rightBox.getChildren().addAll(toolLabel, tool1, tool2);
        root.setRight(rightBox);
        
        // Bottom - 状态栏
        Label statusLabel = new Label("就绪");
        HBox bottomBox = new HBox(statusLabel);
        bottomBox.setStyle("-fx-padding: 5; -fx-background-color: #95a5a6;");
        root.setBottom(bottomBox);
        
        // Center - 内容区域
        TextArea textArea = new TextArea("这是中心内容区域\n" +
                                        "BorderPane 非常适合构建经典的应用程序布局");
        textArea.setWrapText(true);
        BorderPane.setMargin(textArea, new Insets(10));
        root.setCenter(textArea);
        
        Scene scene = new Scene(root, 800, 600);
        primaryStage.setTitle("BorderPane 示例");
        primaryStage.setScene(scene);
        primaryStage.show();
    }

    public static void main(String[] args) {
        launch(args);
    }
}
```

## 5.3 HBox和VBox（水平/垂直布局）

HBox将子组件水平排列，VBox将子组件垂直排列。

### 5.3.1 基本使用

```java
package com.example.javafx.layout;

import javafx.application.Application;
import javafx.geometry.Insets;
import javafx.geometry.Pos;
import javafx.scene.Scene;
import javafx.scene.control.Button;
import javafx.scene.control.Label;
import javafx.scene.layout.HBox;
import javafx.scene.layout.VBox;
import javafx.stage.Stage;

public class HBoxVBoxDemo extends Application {

    @Override
    public void start(Stage primaryStage) {
        // ===== VBox 示例 =====
        Label vboxLabel = new Label("VBox - 垂直布局");
        vboxLabel.setStyle("-fx-font-size: 16px; -fx-font-weight: bold;");
        
        VBox vbox = new VBox(10);  // 10像素间距
        vbox.setAlignment(Pos.CENTER);
        vbox.setPadding(new Insets(20));
        vbox.setStyle("-fx-border-color: blue; -fx-border-width: 2;");
        
        for (int i = 1; i <= 4; i++) {
            Button btn = new Button("按钮 " + i);
            btn.setPrefWidth(120);
            vbox.getChildren().add(btn);
        }
        
        // ===== HBox 示例 =====
        Label hboxLabel = new Label("HBox - 水平布局");
        hboxLabel.setStyle("-fx-font-size: 16px; -fx-font-weight: bold;");
        
        HBox hbox = new HBox(15);  // 15像素间距
        hbox.setAlignment(Pos.CENTER);
        hbox.setPadding(new Insets(20));
        hbox.setStyle("-fx-border-color: red; -fx-border-width: 2;");
        
        for (int i = 1; i <= 4; i++) {
            Button btn = new Button("按钮 " + i);
            hbox.getChildren().add(btn);
        }
        
        // 组合布局
        VBox root = new VBox(30);
        root.setAlignment(Pos.CENTER);
        root.setPadding(new Insets(20));
        root.getChildren().addAll(vboxLabel, vbox, hboxLabel, hbox);
        
        Scene scene = new Scene(root, 600, 500);
        primaryStage.setTitle("HBox & VBox 示例");
        primaryStage.setScene(scene);
        primaryStage.show();
    }

    public static void main(String[] args) {
        launch(args);
    }
}
```

### 5.3.2 对齐和填充

```java
package com.example.javafx.layout;

import javafx.application.Application;
import javafx.geometry.Insets;
import javafx.geometry.Pos;
import javafx.scene.Scene;
import javafx.scene.control.Button;
import javafx.scene.control.Label;
import javafx.scene.layout.HBox;
import javafx.scene.layout.Priority;
import javafx.scene.layout.Region;
import javafx.scene.layout.VBox;
import javafx.stage.Stage;

public class HBoxVBoxAlignmentDemo extends Application {

    @Override
    public void start(Stage primaryStage) {
        VBox root = new VBox(20);
        root.setPadding(new Insets(20));
        
        // 不同对齐方式的HBox
        root.getChildren().addAll(
            createAlignmentDemo("TOP_LEFT", Pos.TOP_LEFT),
            createAlignmentDemo("CENTER", Pos.CENTER),
            createAlignmentDemo("BOTTOM_RIGHT", Pos.BOTTOM_RIGHT)
        );
        
        // 使用spacer实现左右分布
        Label spacerDemo = new Label("使用Spacer的HBox:");
        spacerDemo.setStyle("-fx-font-weight: bold;");
        
        HBox spacerBox = new HBox(10);
        spacerBox.setPadding(new Insets(10));
        spacerBox.setStyle("-fx-border-color: black; -fx-border-width: 1;");
        spacerBox.setPrefHeight(60);
        
        Button leftBtn = new Button("左边");
        Region spacer = new Region();
        HBox.setHgrow(spacer, Priority.ALWAYS);  // spacer会填充剩余空间
        Button rightBtn = new Button("右边");
        
        spacerBox.getChildren().addAll(leftBtn, spacer, rightBtn);
        
        root.getChildren().addAll(spacerDemo, spacerBox);
        
        Scene scene = new Scene(root, 600, 450);
        primaryStage.setTitle("HBox & VBox 对齐演示");
        primaryStage.setScene(scene);
        primaryStage.show();
    }

    private VBox createAlignmentDemo(String title, Pos alignment) {
        Label label = new Label("Alignment: " + title);
        label.setStyle("-fx-font-weight: bold;");
        
        HBox hbox = new HBox(10);
        hbox.setAlignment(alignment);
        hbox.setPadding(new Insets(10));
        hbox.setStyle("-fx-border-color: gray; -fx-border-width: 1;");
        hbox.setPrefHeight(80);
        
        hbox.getChildren().addAll(
            new Button("A"),
            new Button("B"),
            new Button("C")
        );
        
        VBox container = new VBox(5);
        container.getChildren().addAll(label, hbox);
        return container;
    }

    public static void main(String[] args) {
        launch(args);
    }
}
```

## 5.4 GridPane（网格布局）

GridPane将空间划分为行和列的网格，非常适合表单布局。

### 5.4.1 基本使用

```java
package com.example.javafx.layout;

import javafx.application.Application;
import javafx.geometry.Insets;
import javafx.geometry.Pos;
import javafx.scene.Scene;
import javafx.scene.control.*;
import javafx.scene.layout.GridPane;
import javafx.stage.Stage;

public class GridPaneDemo extends Application {

    @Override
    public void start(Stage primaryStage) {
        GridPane grid = new GridPane();
        grid.setAlignment(Pos.CENTER);
        grid.setHgap(10);  // 水平间距
        grid.setVgap(10);  // 垂直间距
        grid.setPadding(new Insets(25));
        
        // 标题
        Label titleLabel = new Label("用户注册");
        titleLabel.setStyle("-fx-font-size: 20px; -fx-font-weight: bold;");
        grid.add(titleLabel, 0, 0, 2, 1);  // 列0，行0，跨2列1行
        
        // 用户名
        Label userLabel = new Label("用户名:");
        grid.add(userLabel, 0, 1);
        TextField userField = new TextField();
        userField.setPromptText("请输入用户名");
        grid.add(userField, 1, 1);
        
        // 密码
        Label pwLabel = new Label("密码:");
        grid.add(pwLabel, 0, 2);
        PasswordField pwField = new PasswordField();
        pwField.setPromptText("请输入密码");
        grid.add(pwField, 1, 2);
        
        // 确认密码
        Label confirmLabel = new Label("确认密码:");
        grid.add(confirmLabel, 0, 3);
        PasswordField confirmField = new PasswordField();
        grid.add(confirmField, 1, 3);
        
        // 性别
        Label genderLabel = new Label("性别:");
        grid.add(genderLabel, 0, 4);
        
        ToggleGroup genderGroup = new ToggleGroup();
        RadioButton maleRadio = new RadioButton("男");
        maleRadio.setToggleGroup(genderGroup);
        maleRadio.setSelected(true);
        RadioButton femaleRadio = new RadioButton("女");
        femaleRadio.setToggleGroup(genderGroup);
        
        javafx.scene.layout.HBox genderBox = new javafx.scene.layout.HBox(15);
        genderBox.getChildren().addAll(maleRadio, femaleRadio);
        grid.add(genderBox, 1, 4);
        
        // 兴趣爱好
        Label hobbyLabel = new Label("兴趣:");
        grid.add(hobbyLabel, 0, 5);
        
        CheckBox readingCb = new CheckBox("阅读");
        CheckBox sportsCb = new CheckBox("运动");
        CheckBox musicCb = new CheckBox("音乐");
        
        javafx.scene.layout.HBox hobbyBox = new javafx.scene.layout.HBox(10);
        hobbyBox.getChildren().addAll(readingCb, sportsCb, musicCb);
        grid.add(hobbyBox, 1, 5);
        
        // 按钮
        Button registerBtn = new Button("注册");
        registerBtn.setPrefWidth(80);
        Button cancelBtn = new Button("取消");
        cancelBtn.setPrefWidth(80);
        
        javafx.scene.layout.HBox buttonBox = new javafx.scene.layout.HBox(15);
        buttonBox.setAlignment(Pos.CENTER_RIGHT);
        buttonBox.getChildren().addAll(registerBtn, cancelBtn);
        grid.add(buttonBox, 0, 6, 2, 1);
        
        // 注册按钮事件
        registerBtn.setOnAction(e -> {
            String username = userField.getText();
            String password = pwField.getText();
            String confirm = confirmField.getText();
            
            if (username.isEmpty() || password.isEmpty()) {
                showAlert("请填写所有必填项");
            } else if (!password.equals(confirm)) {
                showAlert("两次密码输入不一致");
            } else {
                showAlert("注册成功！\n用户名: " + username);
            }
        });
        
        // 显示网格线（调试用）
        grid.setGridLinesVisible(false);  // 设为true可以看到网格线
        
        Scene scene = new Scene(grid, 450, 400);
        primaryStage.setTitle("GridPane 示例 - 注册表单");
        primaryStage.setScene(scene);
        primaryStage.show();
    }

    private void showAlert(String message) {
        Alert alert = new Alert(Alert.AlertType.INFORMATION);
        alert.setTitle("提示");
        alert.setHeaderText(null);
        alert.setContentText(message);
        alert.showAndWait();
    }

    public static void main(String[] args) {
        launch(args);
    }
}
```

### 5.4.2 GridPane的约束

```java
package com.example.javafx.layout;

import javafx.application.Application;
import javafx.geometry.HPos;
import javafx.geometry.Insets;
import javafx.geometry.VPos;
import javafx.scene.Scene;
import javafx.scene.control.Button;
import javafx.scene.control.Label;
import javafx.scene.layout.ColumnConstraints;
import javafx.scene.layout.GridPane;
import javafx.scene.layout.Priority;
import javafx.scene.layout.RowConstraints;
import javafx.stage.Stage;

public class GridPaneConstraintsDemo extends Application {

    @Override
    public void start(Stage primaryStage) {
        GridPane grid = new GridPane();
        grid.setPadding(new Insets(10));
        grid.setHgap(10);
        grid.setVgap(10);
        
        // 设置列约束
        ColumnConstraints col1 = new ColumnConstraints();
        col1.setPercentWidth(30);  // 第1列占30%
        col1.setHalignment(HPos.RIGHT);  // 水平右对齐
        
        ColumnConstraints col2 = new ColumnConstraints();
        col2.setPercentWidth(70);  // 第2列占70%
        col2.setHgrow(Priority.ALWAYS);  // 可以增长
        
        grid.getColumnConstraints().addAll(col1, col2);
        
        // 设置行约束
        for (int i = 0; i < 4; i++) {
            RowConstraints row = new RowConstraints();
            row.setMinHeight(40);
            row.setVgrow(Priority.SOMETIMES);
            row.setValignment(VPos.CENTER);
            grid.getRowConstraints().add(row);
        }
        
        // 添加内容
        grid.add(new Label("标签1:"), 0, 0);
        grid.add(new Button("按钮1"), 1, 0);
        
        grid.add(new Label("标签2:"), 0, 1);
        Button btn2 = new Button("按钮2（跨2列）");
        btn2.setMaxWidth(Double.MAX_VALUE);
        grid.add(btn2, 1, 1, 2, 1);
        
        grid.add(new Label("标签3:"), 0, 2);
        grid.add(new Button("按钮3"), 1, 2);
        
        grid.setGridLinesVisible(true);  // 显示网格线
        
        Scene scene = new Scene(grid, 500, 300);
        primaryStage.setTitle("GridPane 约束演示");
        primaryStage.setScene(scene);
        primaryStage.show();
    }

    public static void main(String[] args) {
        launch(args);
    }
}
```

## 5.5 StackPane（堆叠布局）

StackPane将子组件堆叠在一起，默认居中对齐。

```java
package com.example.javafx.layout;

import javafx.application.Application;
import javafx.geometry.Pos;
import javafx.scene.Scene;
import javafx.scene.control.Label;
import javafx.scene.layout.StackPane;
import javafx.scene.paint.Color;
import javafx.scene.shape.Circle;
import javafx.scene.shape.Rectangle;
import javafx.stage.Stage;

public class StackPaneDemo extends Application {

    @Override
    public void start(Stage primaryStage) {
        StackPane stack = new StackPane();
        
        // 底层：矩形
        Rectangle rect = new Rectangle(250, 150);
        rect.setFill(Color.LIGHTBLUE);
        rect.setArcWidth(20);
        rect.setArcHeight(20);
        
        // 中层：圆形
        Circle circle = new Circle(60);
        circle.setFill(Color.LIGHTCORAL);
        circle.setOpacity(0.7);
        
        // 顶层：文本
        Label label = new Label("StackPane\n堆叠布局");
        label.setStyle("-fx-font-size: 20px; -fx-font-weight: bold; " +
                      "-fx-text-fill: white;");
        label.setAlignment(Pos.CENTER);
        
        // 按添加顺序堆叠
        stack.getChildren().addAll(rect, circle, label);
        
        // 设置对齐方式
        StackPane.setAlignment(rect, Pos.CENTER);
        StackPane.setAlignment(circle, Pos.TOP_RIGHT);
        StackPane.setAlignment(label, Pos.CENTER);
        
        Scene scene = new Scene(stack, 400, 300);
        primaryStage.setTitle("StackPane 示例");
        primaryStage.setScene(scene);
        primaryStage.show();
    }

    public static void main(String[] args) {
        launch(args);
    }
}
```

## 5.8 TilePane（瓦片布局）

TilePane将子组件排列成统一大小的网格。

```java
package com.example.javafx.layout;

import javafx.application.Application;
import javafx.geometry.Insets;
import javafx.geometry.Orientation;
import javafx.geometry.Pos;
import javafx.scene.Scene;
import javafx.scene.control.Label;
import javafx.scene.layout.TilePane;
import javafx.scene.paint.Color;
import javafx.scene.shape.Rectangle;
import javafx.stage.Stage;

public class TilePaneDemo extends Application {

    @Override
    public void start(Stage primaryStage) {
        TilePane tilePane = new TilePane();
        tilePane.setOrientation(Orientation.HORIZONTAL);
        tilePane.setPrefColumns(4);  // 首选列数
        tilePane.setHgap(10);
        tilePane.setVgap(10);
        tilePane.setPadding(new Insets(15));
        tilePane.setAlignment(Pos.CENTER);
        
        // 添加瓦片
        Color[] colors = {
            Color.RED, Color.BLUE, Color.GREEN, Color.YELLOW,
            Color.ORANGE, Color.PURPLE, Color.PINK, Color.CYAN
        };
        
        for (int i = 0; i < colors.length; i++) {
            javafx.scene.layout.StackPane tile = new javafx.scene.layout.StackPane();
            
            Rectangle rect = new Rectangle(100, 100);
            rect.setFill(colors[i]);
            rect.setArcWidth(10);
            rect.setArcHeight(10);
            
            Label label = new Label("瓦片 " + (i + 1));
            label.setStyle("-fx-font-size: 14px; -fx-font-weight: bold; -fx-text-fill: white;");
            
            tile.getChildren().addAll(rect, label);
            tilePane.getChildren().add(tile);
        }
        
        Scene scene = new Scene(tilePane, 500, 400);
        primaryStage.setTitle("TilePane 示例");
        primaryStage.setScene(scene);
        primaryStage.show();
    }

    public static void main(String[] args) {
        launch(args);
    }
}
```

## 5.9 布局嵌套

实际应用中，通常需要嵌套多种布局来实现复杂界面。

```java
package com.example.javafx.layout;

import javafx.application.Application;
import javafx.geometry.Insets;
import javafx.geometry.Pos;
import javafx.scene.Scene;
import javafx.scene.control.*;
import javafx.scene.layout.*;
import javafx.stage.Stage;

public class NestedLayoutDemo extends Application {

    @Override
    public void start(Stage primaryStage) {
        // 根布局：BorderPane
        BorderPane root = new BorderPane();
        
        // Top: 工具栏 (HBox)
        HBox toolbar = new HBox(10);
        toolbar.setPadding(new Insets(10));
        toolbar.setStyle("-fx-background-color: #34495e;");
        Button newBtn = new Button("新建");
        Button openBtn = new Button("打开");
        Button saveBtn = new Button("保存");
        toolbar.getChildren().addAll(newBtn, openBtn, saveBtn);
        root.setTop(toolbar);
        
        // Left: 导航栏 (VBox)
        VBox navigation = new VBox(5);
        navigation.setPadding(new Insets(10));
        navigation.setPrefWidth(150);
        navigation.setStyle("-fx-background-color: #ecf0f1;");
        Label navLabel = new Label("导航");
        navLabel.setStyle("-fx-font-weight: bold;");
        ListView<String> navList = new ListView<>();
        navList.getItems().addAll("首页", "设置", "关于");
        VBox.setVgrow(navList, Priority.ALWAYS);
        navigation.getChildren().addAll(navLabel, navList);
        root.setLeft(navigation);
        
        // Center: 内容区 (GridPane嵌套VBox)
        VBox centerBox = new VBox(15);
        centerBox.setPadding(new Insets(20));
        
        Label titleLabel = new Label("表单示例");
        titleLabel.setStyle("-fx-font-size: 18px; -fx-font-weight: bold;");
        
        GridPane form = new GridPane();
        form.setHgap(10);
        form.setVgap(10);
        form.add(new Label("姓名:"), 0, 0);
        form.add(new TextField(), 1, 0);
        form.add(new Label("邮箱:"), 0, 1);
        form.add(new TextField(), 1, 1);
        
        HBox buttonBox = new HBox(10);
        buttonBox.setAlignment(Pos.CENTER_RIGHT);
        buttonBox.getChildren().addAll(new Button("提交"), new Button("取消"));
        
        centerBox.getChildren().addAll(titleLabel, form, buttonBox);
        root.setCenter(centerBox);
        
        // Bottom: 状态栏 (HBox)
        HBox statusBar = new HBox();
        statusBar.setPadding(new Insets(5, 10, 5, 10));
        statusBar.setStyle("-fx-background-color: #95a5a6;");
        Label statusLabel = new Label("就绪");
        statusBar.getChildren().add(statusLabel);
        root.setBottom(statusBar);
        
        Scene scene = new Scene(root, 700, 500);
        primaryStage.setTitle("嵌套布局示例");
        primaryStage.setScene(scene);
        primaryStage.show();
    }

    public static void main(String[] args) {
        launch(args);
    }
}
```

## 5.10 小结

本章学习了JavaFX的各种布局管理器：

1. ✅ **BorderPane**：五区域布局，适合应用程序主框架
2. ✅ **HBox/VBox**：水平/垂直线性布局
3. ✅ **GridPane**：网格布局，适合表单
4. ✅ **StackPane**：堆叠布局，组件重叠
5. ✅ **FlowPane**：流式布局，自动换行
6. ✅ **AnchorPane**：锚点布局，精确控制位置
7. ✅ **TilePane**：瓦片布局，统一大小网格
8. ✅ **布局嵌套**：组合多种布局实现复杂界面

选择合适的布局管理器是构建良好UI的关键。
