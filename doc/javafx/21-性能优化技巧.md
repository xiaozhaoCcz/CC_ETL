# 21-性能优化技巧

## 21.1 性能优化概述

JavaFX应用的性能优化主要关注以下几个方面：

1. **渲染性能**：界面刷新和动画流畅度
2. **内存使用**：避免内存泄漏和过度消耗
3. **启动速度**：应用启动时间
4. **响应性**：用户操作的响应速度

## 21.2 渲染性能优化

### 21.2.1 使用CSS而非代码设置样式

**❌ 不推荐**：
```java
button.setStyle("-fx-background-color: blue; -fx-text-fill: white;");
```

**✅ 推荐**：
```css
/* style.css */
.my-button {
    -fx-background-color: blue;
    -fx-text-fill: white;
}
```

```java
button.getStyleClass().add("my-button");
```

### 21.2.2 减少节点数量

**❌ 不推荐**：
```java
VBox container = new VBox();
for (int i = 0; i < 1000; i++) {
    Label label = new Label("Item " + i);
    container.getChildren().add(label);
}
```

**✅ 推荐**：使用虚拟化控件
```java
ListView<String> listView = new ListView<>();
ObservableList<String> items = FXCollections.observableArrayList();
for (int i = 0; i < 1000; i++) {
    items.add("Item " + i);
}
listView.setItems(items);
```

### 21.2.3 避免频繁的布局计算

```java
// ❌ 每次循环都触发布局
for (int i = 0; i < 100; i++) {
    container.getChildren().add(new Button("Button " + i));
}

// ✅ 批量添加
List<Node> nodes = new ArrayList<>();
for (int i = 0; i < 100; i++) {
    nodes.add(new Button("Button " + i));
}
container.getChildren().addAll(nodes);
```

### 21.2.4 使用缓存提示

```java
node.setCache(true);
node.setCacheHint(CacheHint.SPEED);  // 或 CacheHint.QUALITY
```

### 21.2.5 TableView性能优化

```java
// 设置固定单元格大小
tableView.setFixedCellSize(25);

// 使用自定义CellFactory时重用Cell
column.setCellFactory(col -> new TableCell<MyData, String>() {
    @Override
    protected void updateItem(String item, boolean empty) {
        super.updateItem(item, empty);
        if (empty || item == null) {
            setText(null);
            setGraphic(null);
        } else {
            setText(item);
        }
    }
});
```

## 21.3 内存优化

### 21.3.1 避免内存泄漏

**问题：监听器未移除**
```java
// ❌ 可能导致内存泄漏
property.addListener((obs, oldVal, newVal) -> {
    // 处理逻辑
});

// ✅ 正确做法
ChangeListener<String> listener = (obs, oldVal, newVal) -> {
    // 处理逻辑
};
property.addListener(listener);

// 不需要时移除
property.removeListener(listener);
```

**问题：绑定未解除**
```java
// ❌ 绑定后忘记解绑
label.textProperty().bind(field.textProperty());

// ✅ 不需要时解绑
label.textProperty().unbind();
```

### 21.3.2 弱引用监听器

```java
WeakChangeListener<String> weakListener = new WeakChangeListener<>(listener);
property.addListener(weakListener);
```

### 21.3.3 及时释放资源

```java
@Override
public void stop() {
    // 停止Timer和Timeline
    if (timeline != null) {
        timeline.stop();
    }
    
    // 释放MediaPlayer
    if (mediaPlayer != null) {
        mediaPlayer.dispose();
    }
    
    // 关闭数据库连接
    if (connection != null) {
        connection.close();
    }
}
```

### 21.3.4 使用对象池

```java
public class NodePool<T extends Node> {
    private final Queue<T> pool = new LinkedList<>();
    private final Supplier<T> factory;
    
    public NodePool(Supplier<T> factory, int initialSize) {
        this.factory = factory;
        for (int i = 0; i < initialSize; i++) {
            pool.offer(factory.get());
        }
    }
    
    public T acquire() {
        T node = pool.poll();
        return node != null ? node : factory.get();
    }
    
    public void release(T node) {
        pool.offer(node);
    }
}
```

## 21.4 线程优化

### 21.4.1 使用Task处理耗时操作

```java
Task<List<Data>> task = new Task<List<Data>>() {
    @Override
    protected List<Data> call() throws Exception {
        // 耗时操作在后台线程
        return loadData();
    }
};

task.setOnSucceeded(e -> {
    // UI更新在JavaFX线程
    tableView.setItems(FXCollections.observableArrayList(task.getValue()));
});

new Thread(task).start();
```

### 21.4.2 使用线程池

```java
private static final ExecutorService executor = 
    Executors.newFixedThreadPool(4);

public void executeTask(Runnable task) {
    executor.submit(() -> {
        task.run();
        Platform.runLater(() -> {
            // 更新UI
        });
    });
}

@Override
public void stop() {
    executor.shutdown();
}
```

### 21.4.3 减少Platform.runLater调用

**❌ 频繁调用**：
```java
for (int i = 0; i < 1000; i++) {
    int index = i;
    Platform.runLater(() -> {
        label.setText("Progress: " + index);
    });
}
```

**✅ 批量更新**：
```java
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 1000; i++) {
    sb.append("Item ").append(i).append("\n");
}
String finalText = sb.toString();
Platform.runLater(() -> {
    textArea.setText(finalText);
});
```

## 21.5 图像优化

### 21.5.1 懒加载图像

```java
Image image = new Image(url, true);  // true表示后台加载
```

### 21.5.2 指定图像大小

```java
// 加载时就指定大小，避免原始尺寸加载
Image image = new Image(url, 200, 150, true, true);
```

### 21.5.3 使用图像缓存

```java
public class ImageCache {
    private static final Map<String, Image> cache = new HashMap<>();
    
    public static Image getImage(String url) {
        return cache.computeIfAbsent(url, k -> new Image(k));
    }
    
    public static void clear() {
        cache.clear();
    }
}
```

## 21.6 启动优化

### 21.6.1 延迟初始化

```java
@Override
public void start(Stage primaryStage) {
    // 先显示主界面
    Scene scene = new Scene(createMainUI(), 800, 600);
    primaryStage.setScene(scene);
    primaryStage.show();
    
    // 然后在后台加载其他资源
    Task<Void> initTask = new Task<Void>() {
        @Override
        protected Void call() throws Exception {
            loadHeavyResources();
            return null;
        }
    };
    new Thread(initTask).start();
}
```

### 21.6.2 使用启动画面

```java
public class SplashScreen {
    private Stage splashStage;
    
    public void show() {
        splashStage = new Stage(StageStyle.UNDECORATED);
        // 显示启动画面
        splashStage.show();
    }
    
    public void hide() {
        if (splashStage != null) {
            splashStage.close();
        }
    }
}
```

## 21.7 动画性能优化

### 21.7.1 减少动画节点数量

```java
// ❌ 对100个节点同时动画
for (Node node : nodes) {
    TranslateTransition tt = new TranslateTransition(Duration.seconds(1), node);
    tt.play();
}

// ✅ 对容器动画
TranslateTransition tt = new TranslateTransition(Duration.seconds(1), container);
tt.play();
```

### 21.7.2 使用Timeline而非循环

**❌ 不推荐**：
```java
new Thread(() -> {
    while (running) {
        Platform.runLater(() -> updateUI());
        Thread.sleep(16);  // ~60 FPS
    }
}).start();
```

**✅ 推荐**：
```java
Timeline timeline = new Timeline(
    new KeyFrame(Duration.millis(16), e -> updateUI())
);
timeline.setCycleCount(Animation.INDEFINITE);
timeline.play();
```

## 21.8 性能监控

### 21.8.1 FPS监控

```java
public class FPSCounter {
    private long lastTime = System.nanoTime();
    private int frameCount = 0;
    private double fps = 0;
    
    public void update() {
        frameCount++;
        long currentTime = System.nanoTime();
        long elapsed = currentTime - lastTime;
        
        if (elapsed >= 1_000_000_000) {  // 1秒
            fps = frameCount / (elapsed / 1_000_000_000.0);
            frameCount = 0;
            lastTime = currentTime;
            System.out.println("FPS: " + fps);
        }
    }
}
```

### 21.8.2 内存监控

```java
public class MemoryMonitor {
    public void printMemoryUsage() {
        Runtime runtime = Runtime.getRuntime();
        long totalMemory = runtime.totalMemory();
        long freeMemory = runtime.freeMemory();
        long usedMemory = totalMemory - freeMemory;
        
        System.out.printf("内存使用: %d MB / %d MB\n",
            usedMemory / 1024 / 1024,
            totalMemory / 1024 / 1024);
    }
    
    public void forceGC() {
        System.gc();
    }
}
```
