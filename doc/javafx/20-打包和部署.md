# 20-打包和部署

## 20.1 打包方式概述

JavaFX应用有多种打包方式：

1. **JAR打包**：传统JAR文件
2. **Fat JAR**：包含所有依赖的JAR
3. **jpackage**：生成原生安装包
4. **jlink**：创建自定义运行时

## 20.2 Maven JAR打包

### 20.2.1 基本JAR打包

```xml
<build>
    <plugins>
        <plugin>
            <groupId>org.apache.maven.plugins</groupId>
            <artifactId>maven-jar-plugin</artifactId>
            <version>3.3.0</version>
            <configuration>
                <archive>
                    <manifest>
                        <addClasspath>true</addClasspath>
                        <mainClass>com.example.MainApp</mainClass>
                    </manifest>
                </archive>
            </configuration>
        </plugin>
    </plugins>
</build>
```

**打包命令**：
```bash
mvn clean package
```

### 20.2.2 Fat JAR（使用maven-shade-plugin）

```xml
<build>
    <plugins>
        <plugin>
            <groupId>org.apache.maven.plugins</groupId>
            <artifactId>maven-shade-plugin</artifactId>
            <version>3.5.0</version>
            <executions>
                <execution>
                    <phase>package</phase>
                    <goals>
                        <goal>shade</goal>
                    </goals>
                    <configuration>
                        <transformers>
                            <transformer implementation="org.apache.maven.plugins.shade.resource.ManifestResourceTransformer">
                                <mainClass>com.example.MainApp</mainClass>
                            </transformer>
                        </transformers>
                    </configuration>
                </execution>
            </executions>
        </plugin>
    </plugins>
</build>
```

**打包命令**：
```bash
mvn clean package
```

生成的JAR文件可以直接运行：
```bash
java -jar target/myapp.jar
```

## 20.3 JavaFX Maven Plugin

使用JavaFX专用Maven插件。

```xml
<build>
    <plugins>
        <plugin>
            <groupId>org.openjfx</groupId>
            <artifactId>javafx-maven-plugin</artifactId>
            <version>0.0.8</version>
            <configuration>
                <mainClass>com.example.MainApp</mainClass>
            </configuration>
        </plugin>
    </plugins>
</build>
```

**运行命令**：
```bash
mvn javafx:run
```

**打包为可执行JAR**：
```bash
mvn javafx:jlink
```

## 20.4 jpackage打包

jpackage是JDK 14+提供的工具，可以生成原生安装包。

### 20.4.1 准备工作

1. 确保使用JDK 14+
2. 准备应用图标
3. 创建JAR文件

### 20.4.2 Maven配置

```xml
<build>
    <plugins>
        <plugin>
            <groupId>org.panteleyev</groupId>
            <artifactId>jpackage-maven-plugin</artifactId>
            <version>1.6.0</version>
            <configuration>
                <name>MyJavaFXApp</name>
                <appVersion>1.0.0</appVersion>
                <vendor>MyCompany</vendor>
                <destination>target/dist</destination>
                <module>com.example/com.example.MainApp</module>
                <runtimeImage>target/java-runtime</runtimeImage>
                <javaOptions>
                    <option>-Dfile.encoding=UTF-8</option>
                </javaOptions>
                <icon>src/main/resources/icon.png</icon>
                
                <!-- Windows配置 -->
                <winDirChooser>true</winDirChooser>
                <winMenu>true</winMenu>
                <winShortcut>true</winShortcut>
                
                <!-- macOS配置 -->
                <macPackageName>MyJavaFXApp</macPackageName>
                
                <!-- Linux配置 -->
                <linuxShortcut>true</linuxShortcut>
            </configuration>
        </plugin>
    </plugins>
</build>
```

### 20.4.3 命令行打包

**Windows MSI安装包**：
```bash
jpackage --input target \
         --name MyApp \
         --main-jar myapp.jar \
         --main-class com.example.MainApp \
         --type msi \
         --win-dir-chooser \
         --win-menu \
         --win-shortcut
```

**macOS DMG安装包**：
```bash
jpackage --input target \
         --name MyApp \
         --main-jar myapp.jar \
         --main-class com.example.MainApp \
         --type dmg \
         --icon src/main/resources/icon.icns
```

**Linux DEB包**：
```bash
jpackage --input target \
         --name MyApp \
         --main-jar myapp.jar \
         --main-class com.example.MainApp \
         --type deb \
         --linux-shortcut
```

## 20.5 jlink自定义运行时

jlink可以创建包含应用和最小JRE的自定义运行时。

### 20.5.1 创建模块化应用

**module-info.java**:
```java
module com.example.myapp {
    requires javafx.controls;
    requires javafx.fxml;
    requires javafx.graphics;
    
    opens com.example.myapp to javafx.fxml;
    exports com.example.myapp;
}
```

### 20.5.2 使用jlink

```bash
# 1. 编译模块
javac --module-path $JAVAFX_HOME/lib \
      -d out \
      src/main/java/module-info.java \
      src/main/java/com/example/myapp/*.java

# 2. 创建自定义运行时
jlink --module-path $JAVAFX_HOME/lib:out \
      --add-modules com.example.myapp \
      --output myapp-runtime \
      --strip-debug \
      --compress=2 \
      --no-header-files \
      --no-man-pages
```

## 20.6 完整的打包脚本

### 20.6.1 Windows批处理脚本

**build.bat**:
```batch
@echo off
echo ====================================
echo JavaFX Application Build Script
echo ====================================

REM 清理旧文件
echo Cleaning old files...
rmdir /s /q target 2>nul
mkdir target

REM 编译
echo Compiling...
call mvn clean compile

REM 打包
echo Packaging...
call mvn package

REM 使用jpackage创建安装包
echo Creating installer...
jpackage --input target ^
         --name MyJavaFXApp ^
         --main-jar myapp.jar ^
         --main-class com.example.MainApp ^
         --type msi ^
         --icon src/main/resources/icon.ico ^
         --win-dir-chooser ^
         --win-menu ^
         --win-shortcut ^
         --win-menu-group "My Applications" ^
         --vendor "My Company" ^
         --app-version "1.0.0"

echo Build completed!
pause
```

### 20.6.2 macOS/Linux Shell脚本

**build.sh**:
```bash
#!/bin/bash

echo "===================================="
echo "JavaFX Application Build Script"
echo "===================================="

# 清理旧文件
echo "Cleaning old files..."
rm -rf target
mkdir -p target

# 编译
echo "Compiling..."
mvn clean compile

# 打包
echo "Packaging..."
mvn package

# 创建DMG（macOS）或DEB（Linux）
echo "Creating installer..."
if [[ "$OSTYPE" == "darwin"* ]]; then
    # macOS
    jpackage --input target \
             --name MyJavaFXApp \
             --main-jar myapp.jar \
             --main-class com.example.MainApp \
             --type dmg \
             --icon src/main/resources/icon.icns \
             --vendor "My Company" \
             --app-version "1.0.0"
else
    # Linux
    jpackage --input target \
             --name MyJavaFXApp \
             --main-jar myapp.jar \
             --main-class com.example.MainApp \
             --type deb \
             --icon src/main/resources/icon.png \
             --linux-shortcut \
             --vendor "My Company" \
             --app-version "1.0.0"
fi

echo "Build completed!"
```

## 20.7 资源文件处理

### 20.7.1 确保资源打包

在`pom.xml`中配置：

```xml
<build>
    <resources>
        <resource>
            <directory>src/main/resources</directory>
            <includes>
                <include>**/*.fxml</include>
                <include>**/*.css</include>
                <include>**/*.png</include>
                <include>**/*.jpg</include>
                <include>**/*.properties</include>
            </includes>
        </resource>
    </resources>
</build>
```

### 20.7.2 资源访问

```java
// 正确的资源访问方式
URL fxmlUrl = getClass().getResource("/fxml/main.fxml");
InputStream cssStream = getClass().getResourceAsStream("/css/style.css");

// 不要使用File路径
// 错误：new File("src/main/resources/fxml/main.fxml")
```
