# 09-属性和绑定

## 9.1 属性（Property）概述

JavaFX引入了属性（Property）系统，提供了强大的数据绑定功能。属性是可观察的值，当值改变时可以通知监听器。

### 9.1.1 为什么需要Property

传统Java Bean的问题：
```java
// 传统方式 - 无法自动通知变化
private String name;
public String getName() { return name; }
public void setName(String name) { this.name = name; }
```

JavaFX Property的优势：
- 自动通知变化
- 支持数据绑定
- 支持双向绑定
- 链式调用

## 9.2 Property基本使用

### 9.2.1 常用Property类型

```java
package com.example.javafx.properties;

import javafx.application.Application;
import javafx.beans.property.*;
import javafx.geometry.Insets;
import javafx.scene.Scene;
import javafx.scene.control.Label;
import javafx.scene.layout.VBox;
import javafx.stage.Stage;

public class PropertyBasicsDemo extends Application {

    @Override
    public void start(Stage primaryStage) {
        VBox root = new VBox(15);
        root.setPadding(new Insets(20));
        
        // ===== 基本Property类型 =====
        
        // 字符串属性
        StringProperty nameProperty = new SimpleStringProperty("张三");
        Label nameLabel = new Label("姓名: " + nameProperty.get());
        
        // 整数属性
        IntegerProperty ageProperty = new SimpleIntegerProperty(25);
        Label ageLabel = new Label("年龄: " + ageProperty.get());
        
        // 双精度属性
        DoubleProperty salaryProperty = new SimpleDoubleProperty(8000.50);
        Label salaryLabel = new Label("薪资: " + salaryProperty.get());
        
        // 布尔属性
        BooleanProperty activeProperty = new SimpleBooleanProperty(true);
        Label activeLabel = new Label("激活: " + activeProperty.get());
        
        // ===== 添加监听器 =====
        
        nameProperty.addListener((obs, oldVal, newVal) -> {
            nameLabel.setText("姓名: " + newVal);
            System.out.println("姓名从 " + oldVal + " 改为 " + newVal);
        });
        
        ageProperty.addListener((obs, oldVal, newVal) -> {
            ageLabel.setText("年龄: " + newVal);
            System.out.println("年龄从 " + oldVal + " 改为 " + newVal);
        });
        
        salaryProperty.addListener((obs, oldVal, newVal) -> {
            salaryLabel.setText("薪资: " + newVal);
        });
        
        activeProperty.addListener((obs, oldVal, newVal) -> {
            activeLabel.setText("激活: " + newVal);
        });
        
        // 修改属性值
        javafx.scene.control.Button changeBtn = new javafx.scene.control.Button("修改属性");
        changeBtn.setOnAction(e -> {
            nameProperty.set("李四");
            ageProperty.set(30);
            salaryProperty.set(10000.00);
            activeProperty.set(false);
        });
        
        root.getChildren().addAll(nameLabel, ageLabel, salaryLabel, 
                                 activeLabel, changeBtn);
        
        Scene scene = new Scene(root, 350, 300);
        primaryStage.setTitle("Property 基础");
        primaryStage.setScene(scene);
        primaryStage.show();
    }

    public static void main(String[] args) {
        launch(args);
    }
}
```

## 9.3 单向绑定

单向绑定使一个属性自动跟随另一个属性的变化。

```java
package com.example.javafx.properties;

import javafx.application.Application;
import javafx.geometry.Insets;
import javafx.geometry.Pos;
import javafx.scene.Scene;
import javafx.scene.control.Label;
import javafx.scene.control.Slider;
import javafx.scene.control.TextField;
import javafx.scene.layout.VBox;
import javafx.stage.Stage;

public class UnidirectionalBindingDemo extends Application {

    @Override
    public void start(Stage primaryStage) {
        VBox root = new VBox(20);
        root.setPadding(new Insets(30));
        root.setAlignment(Pos.CENTER);
        
        // ===== 示例1: Slider和Label绑定 =====
        Label sliderLabel = new Label("滑块值: 50");
        sliderLabel.setStyle("-fx-font-size: 16px;");
        
        Slider slider = new Slider(0, 100, 50);
        slider.setShowTickLabels(true);
        slider.setShowTickMarks(true);
        slider.setMajorTickUnit(25);
        
        // 单向绑定：Label的文本跟随Slider的值
        sliderLabel.textProperty().bind(
            slider.valueProperty().asString("滑块值: %.0f")
        );
        
        // ===== 示例2: TextField绑定 =====
        Label inputLabel = new Label("输入内容将显示在下方");
        
        TextField inputField = new TextField();
        inputField.setPromptText("在这里输入...");
        
        Label echoLabel = new Label();
        echoLabel.setStyle("-fx-font-size: 14px; -fx-text-fill: blue;");
        
        // 单向绑定：echoLabel的文本跟随inputField
        echoLabel.textProperty().bind(
            inputField.textProperty()
        );
        
        // ===== 示例3: 计算绑定 =====
        TextField num1Field = new TextField("10");
        TextField num2Field = new TextField("20");
        Label resultLabel = new Label("结果: 30");
        resultLabel.setStyle("-fx-font-size: 16px; -fx-font-weight: bold;");
        
        // 绑定计算结果
        resultLabel.textProperty().bind(
            javafx.beans.binding.Bindings.createStringBinding(() -> {
                try {
                    double n1 = Double.parseDouble(num1Field.getText());
                    double n2 = Double.parseDouble(num2Field.getText());
                    return String.format("结果: %.2f", n1 + n2);
                } catch (NumberFormatException e) {
                    return "结果: 输入无效";
                }
            }, num1Field.textProperty(), num2Field.textProperty())
        );
        
        javafx.scene.layout.HBox calcBox = new javafx.scene.layout.HBox(10);
        calcBox.setAlignment(Pos.CENTER);
        calcBox.getChildren().addAll(
            num1Field, new Label("+"), num2Field, new Label("=")
        );
        
        root.getChildren().addAll(
            sliderLabel, slider,
            new javafx.scene.control.Separator(),
            inputLabel, inputField, echoLabel,
            new javafx.scene.control.Separator(),
            calcBox, resultLabel
        );
        
        Scene scene = new Scene(root, 450, 550);
        primaryStage.setTitle("单向绑定示例");
        primaryStage.setScene(scene);
        primaryStage.show();
    }

    public static void main(String[] args) {
        launch(args);
    }
}
```

## 9.4 双向绑定

双向绑定使两个属性相互同步。

```java
package com.example.javafx.properties;

import javafx.application.Application;
import javafx.geometry.Insets;
import javafx.geometry.Pos;
import javafx.scene.Scene;
import javafx.scene.control.Label;
import javafx.scene.control.Slider;
import javafx.scene.control.TextField;
import javafx.scene.layout.VBox;
import javafx.stage.Stage;

public class BidirectionalBindingDemo extends Application {

    @Override
    public void start(Stage primaryStage) {
        VBox root = new VBox(20);
        root.setPadding(new Insets(30));
        root.setAlignment(Pos.CENTER);
        
        Label titleLabel = new Label("双向绑定示例");
        titleLabel.setStyle("-fx-font-size: 20px; -fx-font-weight: bold;");
        
        // ===== Slider和TextField双向绑定 =====
        Label infoLabel = new Label("移动滑块或在文本框输入数字（0-100）");
        
        Slider slider = new Slider(0, 100, 50);
        slider.setShowTickLabels(true);
        slider.setShowTickMarks(true);
        slider.setMajorTickUnit(25);
        slider.setPrefWidth(300);
        
        TextField textField = new TextField("50");
        textField.setPrefWidth(100);
        
        // 双向绑定
        slider.valueProperty().bindBidirectional(
            textField.textProperty(),
            new javafx.util.StringConverter<Number>() {
                @Override
                public String toString(Number number) {
                    return String.format("%.0f", number.doubleValue());
                }
                
                @Override
                public Number fromString(String string) {
                    try {
                        double value = Double.parseDouble(string);
                        return Math.max(0, Math.min(100, value));
                    } catch (NumberFormatException e) {
                        return slider.getValue();
                    }
                }
            }
        );
        
        // ===== 两个TextField双向绑定 =====
        Label syncLabel = new Label("两个文本框内容同步");
        
        TextField field1 = new TextField("同步文本");
        TextField field2 = new TextField();
        
        // 简单双向绑定
        field1.textProperty().bindBidirectional(field2.textProperty());
        
        javafx.scene.layout.HBox syncBox = new javafx.scene.layout.HBox(15);
        syncBox.setAlignment(Pos.CENTER);
        syncBox.getChildren().addAll(field1, new Label("↔"), field2);
        
        root.getChildren().addAll(
            titleLabel,
            infoLabel,
            slider,
            textField,
            new javafx.scene.control.Separator(),
            syncLabel,
            syncBox
        );
        
        Scene scene = new Scene(root, 450, 400);
        primaryStage.setTitle("双向绑定示例");
        primaryStage.setScene(scene);
        primaryStage.show();
    }

    public static void main(String[] args) {
        launch(args);
    }
}
```

## 9.5 绑定表达式

JavaFX提供了Bindings工具类来创建复杂的绑定表达式。

```java
package com.example.javafx.properties;

import javafx.application.Application;
import javafx.beans.binding.Bindings;
import javafx.beans.property.DoubleProperty;
import javafx.beans.property.SimpleDoubleProperty;
import javafx.geometry.Insets;
import javafx.scene.Scene;
import javafx.scene.control.Label;
import javafx.scene.control.Slider;
import javafx.scene.layout.VBox;
import javafx.stage.Stage;

public class BindingExpressionsDemo extends Application {

    @Override
    public void start(Stage primaryStage) {
        VBox root = new VBox(20);
        root.setPadding(new Insets(30));
        
        // 创建属性
        DoubleProperty num1 = new SimpleDoubleProperty(10);
        DoubleProperty num2 = new SimpleDoubleProperty(20);
        
        // 滑块1
        Label label1 = new Label();
        label1.textProperty().bind(num1.asString("数字1: %.1f"));
        Slider slider1 = new Slider(0, 100, 10);
        slider1.valueProperty().bindBidirectional(num1);
        
        // 滑块2
        Label label2 = new Label();
        label2.textProperty().bind(num2.asString("数字2: %.1f"));
        Slider slider2 = new Slider(0, 100, 20);
        slider2.valueProperty().bindBidirectional(num2);
        
        // ===== 各种绑定表达式 =====
        
        // 加法
        Label addLabel = new Label();
        addLabel.textProperty().bind(
            Bindings.createStringBinding(
                () -> String.format("加法: %.1f + %.1f = %.1f", 
                    num1.get(), num2.get(), num1.get() + num2.get()),
                num1, num2
            )
        );
        
        // 减法
        Label subLabel = new Label();
        subLabel.textProperty().bind(
            num1.subtract(num2).asString("减法: %.1f")
        );
        
        // 乘法
        Label mulLabel = new Label();
        mulLabel.textProperty().bind(
            num1.multiply(num2).asString("乘法: %.1f")
        );
        
        // 除法
        Label divLabel = new Label();
        divLabel.textProperty().bind(
            num1.divide(num2).asString("除法: %.2f")
        );
        
        // 最大值
        Label maxLabel = new Label();
        maxLabel.textProperty().bind(
            Bindings.max(num1, num2).asString("最大值: %.1f")
        );
        
        // 最小值
        Label minLabel = new Label();
        minLabel.textProperty().bind(
            Bindings.min(num1, num2).asString("最小值: %.1f")
        );
        
        // 条件绑定
        Label compareLabel = new Label();
        compareLabel.textProperty().bind(
            Bindings.when(num1.greaterThan(num2))
                .then("数字1 > 数字2")
                .otherwise(
                    Bindings.when(num1.lessThan(num2))
                        .then("数字1 < 数字2")
                        .otherwise("数字1 = 数字2")
                )
        );
        
        root.getChildren().addAll(
            label1, slider1,
            label2, slider2,
            new javafx.scene.control.Separator(),
            addLabel, subLabel, mulLabel, divLabel,
            maxLabel, minLabel, compareLabel
        );
        
        Scene scene = new Scene(root, 400, 550);
        primaryStage.setTitle("绑定表达式示例");
        primaryStage.setScene(scene);
        primaryStage.show();
    }

    public static void main(String[] args) {
        launch(args);
    }
}
```

## 9.6 Observable集合

JavaFX提供了可观察的集合类，当集合内容改变时会通知监听器。

```java
package com.example.javafx.properties;

import javafx.application.Application;
import javafx.collections.FXCollections;
import javafx.collections.ListChangeListener;
import javafx.collections.ObservableList;
import javafx.geometry.Insets;
import javafx.scene.Scene;
import javafx.scene.control.*;
import javafx.scene.layout.BorderPane;
import javafx.scene.layout.HBox;
import javafx.stage.Stage;

public class ObservableCollectionDemo extends Application {

    @Override
    public void start(Stage primaryStage) {
        BorderPane root = new BorderPane();
        root.setPadding(new Insets(15));
        
        // 创建ObservableList
        ObservableList<String> items = FXCollections.observableArrayList(
            "苹果", "香蕉", "橙子"
        );
        
        // ListView自动观察ObservableList的变化
        ListView<String> listView = new ListView<>(items);
        listView.setPrefHeight(250);
        root.setCenter(listView);
        
        // 监听集合变化
        items.addListener((ListChangeListener<String>) change -> {
            System.out.println("\n=== 集合变化 ===");
            while (change.next()) {
                if (change.wasAdded()) {
                    System.out.println("添加: " + change.getAddedSubList());
                }
                if (change.wasRemoved()) {
                    System.out.println("移除: " + change.getRemoved());
                }
                if (change.wasReplaced()) {
                    System.out.println("替换");
                }
                if (change.wasPermutated()) {
                    System.out.println("重排序");
                }
            }
            System.out.println("当前列表: " + items);
        });
        
        // 底部按钮
        HBox buttonBox = new HBox(10);
        buttonBox.setPadding(new Insets(10, 0, 0, 0));
        
        TextField inputField = new TextField();
        inputField.setPromptText("输入项目名称");
        
        Button addBtn = new Button("添加");
        addBtn.setOnAction(e -> {
            String text = inputField.getText();
            if (!text.isEmpty()) {
                items.add(text);
                inputField.clear();
            }
        });
        
        Button removeBtn = new Button("删除选中");
        removeBtn.setOnAction(e -> {
            String selected = listView.getSelectionModel().getSelectedItem();
            if (selected != null) {
                items.remove(selected);
            }
        });
        
        Button clearBtn = new Button("清空");
        clearBtn.setOnAction(e -> items.clear());
        
        Button sortBtn = new Button("排序");
        sortBtn.setOnAction(e -> FXCollections.sort(items));
        
        buttonBox.getChildren().addAll(inputField, addBtn, removeBtn, 
                                       clearBtn, sortBtn);
        root.setBottom(buttonBox);
        
        Scene scene = new Scene(root, 450, 400);
        primaryStage.setTitle("Observable集合示例");
        primaryStage.setScene(scene);
        primaryStage.show();
    }

    public static void main(String[] args) {
        launch(args);
    }
}
```

## 9.7 自定义Property类

```java
package com.example.javafx.properties;

import javafx.application.Application;
import javafx.beans.property.*;
import javafx.geometry.Insets;
import javafx.scene.Scene;
import javafx.scene.control.Button;
import javafx.scene.control.Label;
import javafx.scene.layout.VBox;
import javafx.stage.Stage;

public class CustomPropertyDemo extends Application {

    // 自定义JavaFX Bean类
    public static class Person {
        private final StringProperty name;
        private final IntegerProperty age;
        private final StringProperty email;

        public Person(String name, int age, String email) {
            this.name = new SimpleStringProperty(this, "name", name);
            this.age = new SimpleIntegerProperty(this, "age", age);
            this.email = new SimpleStringProperty(this, "email", email);
        }

        // Name属性
        public String getName() { return name.get(); }
        public void setName(String value) { name.set(value); }
        public StringProperty nameProperty() { return name; }

        // Age属性
        public int getAge() { return age.get(); }
        public void setAge(int value) { age.set(value); }
        public IntegerProperty ageProperty() { return age; }

        // Email属性
        public String getEmail() { return email.get(); }
        public void setEmail(String value) { email.set(value); }
        public StringProperty emailProperty() { return email; }

        @Override
        public String toString() {
            return String.format("Person{name='%s', age=%d, email='%s'}", 
                               getName(), getAge(), getEmail());
        }
    }

    @Override
    public void start(Stage primaryStage) {
        VBox root = new VBox(15);
        root.setPadding(new Insets(20));
        
        // 创建Person对象
        Person person = new Person("张三", 25, "zhangsan@example.com");
        
        Label nameLabel = new Label();
        nameLabel.textProperty().bind(
            person.nameProperty().concat(" (").concat(person.ageProperty().asString()).concat("岁)")
        );
        nameLabel.setStyle("-fx-font-size: 18px; -fx-font-weight: bold;");
        
        Label emailLabel = new Label();
        emailLabel.textProperty().bind(
            javafx.beans.binding.Bindings.concat("邮箱: ", person.emailProperty())
        );
        
        Label infoLabel = new Label(person.toString());
        infoLabel.setStyle("-fx-font-size: 12px; -fx-text-fill: gray;");
        
        // 监听属性变化
        person.nameProperty().addListener((obs, oldVal, newVal) -> {
            System.out.println("姓名变化: " + oldVal + " -> " + newVal);
            infoLabel.setText(person.toString());
        });
        
        person.ageProperty().addListener((obs, oldVal, newVal) -> {
            System.out.println("年龄变化: " + oldVal + " -> " + newVal);
            infoLabel.setText(person.toString());
        });
        
        // 修改按钮
        Button changeBtn = new Button("修改信息");
        changeBtn.setOnAction(e -> {
            person.setName("李四");
            person.setAge(30);
            person.setEmail("lisi@example.com");
        });
        
        Button incrementBtn = new Button("年龄+1");
        incrementBtn.setOnAction(e -> {
            person.setAge(person.getAge() + 1);
        });
        
        root.getChildren().addAll(nameLabel, emailLabel, infoLabel, 
                                 changeBtn, incrementBtn);
        
        Scene scene = new Scene(root, 400, 250);
        primaryStage.setTitle("自定义Property示例");
        primaryStage.setScene(scene);
        primaryStage.show();
    }

    public static void main(String[] args) {
        launch(args);
    }
}
```

## 9.8 小结

本章学习了JavaFX的属性和绑定系统：

1. ✅ **Property**：可观察的属性对象
2. ✅ **监听器**：监听属性值的变化
3. ✅ **单向绑定**：一个属性跟随另一个属性
4. ✅ **双向绑定**：两个属性相互同步
5. ✅ **绑定表达式**：创建复杂的计算绑定
6. ✅ **Observable集合**：可观察的列表、映射等
7. ✅ **自定义Property**：创建JavaFX Bean类

属性和绑定是JavaFX最强大的特性之一，极大简化了UI和数据的同步。
