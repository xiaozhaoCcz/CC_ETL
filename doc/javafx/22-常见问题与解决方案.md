# 22-常见问题与解决方案

## 22.1 环境配置问题

### 22.1.1 JavaFX runtime components are missing

**问题**：运行时提示JavaFX运行时组件缺失。

**原因**：
- JDK 11+不再包含JavaFX
- 未正确配置模块路径

**解决方案1：使用Maven**
```xml
<dependencies>
    <dependency>
        <groupId>org.openjfx</groupId>
        <artifactId>javafx-controls</artifactId>
        <version>21</version>
    </dependency>
    <dependency>
        <groupId>org.openjfx</groupId>
        <artifactId>javafx-fxml</artifactId>
        <version>21</version>
    </dependency>
</dependencies>
```

**解决方案2：配置VM参数**
```
--module-path "C:\javafx-sdk-21\lib" 
--add-modules javafx.controls,javafx.fxml
```

### 22.1.2 Module not found错误

**问题**：`Error: Module javafx.controls not found`

**解决方案**：
1. 确认JavaFX SDK路径正确
2. 检查模块名称拼写
3. 使用绝对路径
4. 路径包含空格需要用引号

```bash
# Windows
--module-path "C:\Program Files\javafx-sdk-21\lib"

# macOS/Linux  
--module-path "/usr/local/javafx-sdk-21/lib"
```

### 22.1.3 Graphics Device initialization failed

**问题**：图形设备初始化失败。

**原因**：
- 图形驱动问题
- 在无图形环境运行
- 硬件加速问题

**解决方案**：
```bash
# 禁用硬件加速
-Dprism.order=sw

# 或指定渲染管道
-Dprism.order=j2d

# 调试信息
-Dprism.verbose=true
```

## 22.2 界面问题

### 22.2.1 控件不显示或位置错误

**问题**：控件添加到布局后不显示。

**原因**：
- 未添加到Scene Graph
- 布局约束问题
- 尺寸为0

**解决方案**：
```java
// 检查是否添加到容器
root.getChildren().add(button);

// 设置首选尺寸
button.setPrefSize(100, 30);

// 检查是否可见
button.setVisible(true);

// 打印调试信息
System.out.println("Button bounds: " + button.getBoundsInLocal());
```

### 22.2.2 CSS样式不生效

**问题**：CSS样式未应用到控件。

**检查清单**：
```java
// 1. 确认CSS文件路径正确
scene.getStylesheets().add(
    getClass().getResource("/css/style.css").toExternalForm()
);

// 2. 确认样式类已添加
button.getStyleClass().add("my-button");

// 3. 检查ID设置
button.setId("submit-button");

// 4. CSS选择器语法
// 类型选择器
.button { }

// 类选择器
.my-button { }

// ID选择器
#submit-button { }

// 5. 优先级：inline > ID > class > type
```

### 22.2.3 中文显示乱码

**问题**：中文字符显示为方块或乱码。

**解决方案**：
```java
// 1. 设置字体
label.setStyle("-fx-font-family: 'Microsoft YaHei', 'SimHei', sans-serif;");

// 2. 文件编码
// 确保.java和.fxml文件使用UTF-8编码

// 3. Properties文件
// 使用native2ascii工具或Unicode编码
// 或使用UTF-8编码的.properties文件

// 4. FXML文件头部
<?xml version="1.0" encoding="UTF-8"?>
```

## 22.3 事件处理问题

### 22.3.1 事件不触发

**问题**：按钮点击等事件不响应。

**检查清单**：
```java
// 1. 确认事件处理器已设置
button.setOnAction(e -> System.out.println("Clicked"));

// 2. 控件未被禁用
button.setDisable(false);

// 3. 控件可见且在前面
button.setVisible(true);
button.toFront();

// 4. 没有被其他控件覆盖
// 检查布局层次

// 5. 事件未被consume
// 不要随意调用 e.consume()
```

### 22.3.2 MouseEvent获取不到坐标

**问题**：`e.getX()`返回0或负数。

**解决方案**：
```java
// 使用不同坐标系统
node.setOnMouseClicked(e -> {
    // 相对于节点的坐标
    double x = e.getX();
    double y = e.getY();
    
    // 相对于场景的坐标
    double sceneX = e.getSceneX();
    double sceneY = e.getSceneY();
    
    // 屏幕坐标
    double screenX = e.getScreenX();
    double screenY = e.getScreenY();
});
```

## 22.4 线程问题

### 22.4.1 Not on FX application thread

**问题**：
```
java.lang.IllegalStateException: 
Not on FX application thread; currentThread = Thread-XX
```

**原因**：在非JavaFX线程更新UI。

**解决方案**：
```java
// 错误方式
new Thread(() -> {
    label.setText("错误");  // 崩溃！
}).start();

// 正确方式
new Thread(() -> {
    // 后台处理
    String result = doWork();
    
    // 使用Platform.runLater更新UI
    Platform.runLater(() -> {
        label.setText(result);
    });
}).start();
```

### 22.4.2 UI冻结

**问题**：执行耗时操作时UI无响应。

**解决方案**：
```java
// 使用Task
Task<String> task = new Task<String>() {
    @Override
    protected String call() throws Exception {
        // 耗时操作
        return performLongOperation();
    }
};

task.setOnSucceeded(e -> {
    label.setText(task.getValue());
});

new Thread(task).start();
```

## 22.5 数据绑定问题

### 22.5.1 绑定后值不更新

**问题**：属性绑定后，值变化不反映到UI。

**检查清单**：
```java
// 1. 使用Property类型
private StringProperty name = new SimpleStringProperty();

// 不要使用
private String name;  // 错误！无法绑定

// 2. 正确的绑定方式
label.textProperty().bind(name);

// 3. 确认没有解绑
// label.textProperty().unbind();

// 4. 双向绑定
field1.textProperty().bindBidirectional(field2.textProperty());
```

### 22.5.2 循环绑定

**问题**：
```
Exception: A bound value cannot be set
```

**原因**：已绑定的属性不能再设置值。

**解决方案**：
```java
// 错误
label.textProperty().bind(field.textProperty());
label.setText("Test");  // 抛出异常

// 解决方案1：先解绑
label.textProperty().unbind();
label.setText("Test");

// 解决方案2：不要直接设置，修改源属性
field.setText("Test");  // label会自动更新
```

## 22.6 FXML问题

### 22.6.1 FXMLLoader.load()返回null

**问题**：加载FXML文件返回null。

**原因**：
- 文件路径错误
- 文件不存在
- 资源未打包

**解决方案**：
```java
// 1. 检查路径
URL fxmlUrl = getClass().getResource("/fxml/sample.fxml");
System.out.println("FXML URL: " + fxmlUrl);

if (fxmlUrl == null) {
    System.err.println("FXML文件未找到！");
    return;
}

// 2. 确认资源目录配置（Maven）
// src/main/resources/fxml/sample.fxml

// 3. IDE中标记resources目录为资源根目录
```

### 22.6.2 fx:id注入失败

**问题**：`@FXML`注入的控件为null。

**检查清单**：
```java
// 1. FXML中设置fx:id
<Button fx:id="myButton" text="Click"/>

// 2. Controller中变量名一致
@FXML
private Button myButton;  // 名称必须匹配

// 3. Controller设置正确
<VBox fx:controller="com.example.MyController">

// 4. 使用@FXML注解
// 不要忘记注解！

// 5. 访问时机
@FXML
private void initialize() {
    // 此时所有fx:id已注入
    myButton.setText("Ready");
}
```

## 22.7 性能问题

### 22.7.1 TableView数据量大时卡顿

**问题**：TableView显示大量数据时滚动卡顿。

**优化方案**：
```java
// 1. 使用虚拟化（默认已启用）
tableView.setFixedCellSize(25);

// 2. 延迟加载
// 只加载可见行的数据

// 3. 减少列数和复杂度
// 移除不必要的列

// 4. 优化CellFactory
// 重用Cell，避免频繁创建

// 5. 分页加载
// 每页显示100条数据
```

### 22.7.2 内存泄漏

**问题**：应用运行一段时间后内存持续增长。

**常见原因**：
```java
// 1. 监听器未移除
node.widthProperty().addListener(listener);
// 记得在不需要时移除
node.widthProperty().removeListener(listener);

// 2. 绑定未解除
label.textProperty().bind(property);
// 不需要时解绑
label.textProperty().unbind();

// 3. TimeLine未停止
timeline.play();
// 记得停止
timeline.stop();

// 4. 循环引用
// 避免控件之间的循环引用
```

## 22.8 打包部署问题

### 22.8.1 打包后无法运行

**问题**：JAR文件双击无法运行。

**检查清单**：
```xml
<!-- 1. 确认Main-Class -->
<plugin>
    <groupId>org.apache.maven.plugins</groupId>
    <artifactId>maven-jar-plugin</artifactId>
    <configuration>
        <archive>
            <manifest>
                <mainClass>com.example.MainApp</mainClass>
            </manifest>
        </archive>
    </configuration>
</plugin>

<!-- 2. 包含JavaFX依赖 -->
<!-- 使用maven-shade-plugin或jpackage -->
```

### 22.8.2 资源文件找不到

**问题**：打包后CSS、图片等资源无法加载。

**解决方案**：
```java
// 1. 使用getResource
URL cssUrl = getClass().getResource("/css/style.css");

// 2. 不要使用File路径
// 错误
new File("src/main/resources/css/style.css");

// 正确
getClass().getResourceAsStream("/css/style.css");

// 3. 确认资源已打包
// 检查JAR文件中是否包含资源
```

### 22.9.2 Scene Graph检查

```java
// 打印Scene Graph结构
private void printSceneGraph(Node node, int level) {
    String indent = "  ".repeat(level);
    System.out.println(indent + node.getClass().getSimpleName() + 
                       " [" + node.getId() + "]");
    
    if (node instanceof Parent) {
        Parent parent = (Parent) node;
        for (Node child : parent.getChildrenUnmodifiable()) {
            printSceneGraph(child, level + 1);
        }
    }
}
```
