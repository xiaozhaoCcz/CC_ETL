# 17 - 常见问题与解决方案

本章汇总 FlaUI 使用过程中的常见问题及其解决方案。

---

## 安装和环境问题

### 问题 1：找不到 FlaUI 命名空间

**症状**：
```csharp
using FlaUI.Core;  // 错误：找不到命名空间
```

**原因**：
- 未安装 FlaUI NuGet 包
- 包版本不兼容

**解决方案**：
```bash
# 安装 FlaUI 核心包
dotnet add package FlaUI.Core

# 安装 UIA3 自动化引擎
dotnet add package FlaUI.UIA3

# 重新生成项目
dotnet build
```

### 问题 2：运行时找不到 DLL

**症状**：
```
System.IO.FileNotFoundException: 无法加载文件或程序集 'FlaUI.Core'
```

**解决方案**：
```bash
# 清理并重新生成
dotnet clean
dotnet restore
dotnet build
```

### 问题 3：UIA3 不可用

**症状**：
```csharp
var automation = new UIA3Automation();  // 抛出异常
```

**原因**：
- Windows 版本过低（需要 Windows 7+）
- 缺少必要的系统组件

**解决方案**：
```csharp
// 尝试使用 UIA2
using FlaUI.UIA2;

var automation = new UIA2Automation();
```

## 元素查找问题

### 问题 4：找不到元素

**症状**：
```csharp
var element = window.FindFirstDescendant(cf => cf.ByName("按钮"));
// element 为 null
```

**可能原因**：
1. 元素尚未加载
2. 元素名称不正确
3. 元素不在当前查找范围内
4. 使用了错误的自动化引擎

**解决方案**：

```csharp
// 方案 1：增加等待时间
Thread.Sleep(2000);
var element = window.FindFirstDescendant(cf => cf.ByName("按钮"));

// 方案 2：使用智能等待
var element = WaitForElement(window, cf => cf.ByName("按钮"), 5000);

// 方案 3：使用 Inspect 工具验证元素属性
// 打开 Inspect.exe 查看实际的 Name、AutomationId 等

// 方案 4：扩大查找范围
var desktop = automation.GetDesktop();
var element = desktop.FindFirstDescendant(cf => cf.ByName("按钮"));

// 方案 5：使用多个查找条件
var element = window.FindFirstDescendant(cf => 
    cf.ByName("按钮")
      .Or(cf.ByAutomationId("btnSave"))
      .Or(cf.ByClassName("Button")));

// 方案 6：打印所有元素以调试
PrintAllElements(window);

void PrintAllElements(AutomationElement element, int depth = 0)
{
    string indent = new string(' ', depth * 2);
    Console.WriteLine($"{indent}[{element.ControlType}] {element.Name} (ID: {element.AutomationId})");
    
    if (depth < 3)
    {
        foreach (var child in element.FindAllChildren())
        {
            PrintAllElements(child, depth + 1);
        }
    }
}
```

### 问题 5：元素找到但操作失败

**症状**：
```csharp
var button = window.FindFirstDescendant(cf => cf.ByName("按钮")).AsButton();
button.Invoke();  // 抛出异常或无效果
```

**可能原因**：
1. 元素被禁用
2. 元素不可见
3. 元素被其他元素遮挡

**解决方案**：

```csharp
// 检查元素状态
var button = window.FindFirstDescendant(cf => cf.ByName("按钮")).AsButton();

if (button == null)
{
    Console.WriteLine("按钮未找到");
}
else if (!button.IsEnabled)
{
    Console.WriteLine("按钮被禁用");
}
else if (button.IsOffscreen)
{
    Console.WriteLine("按钮不在屏幕上");
}
else
{
    // 设置窗口焦点
    window.SetForeground();
    Thread.Sleep(300);
    
    // 尝试点击
    button.Invoke();
}

// 或使用鼠标点击
var bounds = button.BoundingRectangle;
Mouse.MoveTo((int)(bounds.X + bounds.Width / 2), (int)(bounds.Y + bounds.Height / 2));
Mouse.Click();
```

### 问题 6：元素定位不稳定

**症状**：
- 有时能找到元素，有时找不到
- 测试运行结果不一致

**解决方案**：

```csharp
// 使用更稳定的定位方式
// 1. 优先使用 AutomationId
var element = window.FindFirstDescendant(cf => cf.ByAutomationId("stableId"));

// 2. 组合多个条件
var element = window.FindFirstDescendant(cf => 
    cf.ByAutomationId("btnSave")
      .And(cf.ByControlType(ControlType.Button)));

// 3. 实现重试机制
public AutomationElement FindWithRetry(
    AutomationElement parent,
    Func<ConditionFactory, ConditionBase> condition,
    int maxAttempts = 3)
{
    for (int i = 0; i < maxAttempts; i++)
    {
        try
        {
            var element = parent.FindFirstDescendant(condition);
            if (element != null)
            {
                return element;
            }
        }
        catch (Exception ex)
        {
            Console.WriteLine($"尝试 {i + 1} 失败: {ex.Message}");
        }
        
        Thread.Sleep(1000);
    }
    
    throw new Exception($"元素在 {maxAttempts} 次尝试后仍未找到");
}
```

## 窗口和应用程序问题

### 问题 7：无法获取主窗口

**症状**：
```csharp
var window = app.GetMainWindow(automation);  // 超时或返回 null
```

**解决方案**：

```csharp
// 方案 1：增加超时时间
var window = app.GetMainWindow(automation, timeout: TimeSpan.FromSeconds(10));

// 方案 2：手动查找窗口
Thread.Sleep(2000);
var desktop = automation.GetDesktop();
var window = desktop.FindFirstChild(cf => 
    cf.ByName("应用标题").And(cf.ByControlType(ControlType.Window)));

// 方案 3：通过类名查找
var window = desktop.FindFirstChild(cf => cf.ByClassName("ApplicationFrameWindow"));
```

### 问题 8：应用程序未正常关闭

**症状**：
- `app.Close()` 后应用仍在运行
- 出现保存对话框

**解决方案**：

```csharp
// 方案 1：处理关闭对话框
app.Close();
Thread.Sleep(500);

var desktop = automation.GetDesktop();
var dialog = desktop.FindFirstChild(cf => cf.ByControlType(ControlType.Window));

if (dialog != null)
{
    // 查找"不保存"按钮
    var noButton = dialog.FindFirstDescendant(cf => 
        cf.ByName("不保存")
          .Or(cf.ByName("Don't Save"))
          .Or(cf.ByName("No")))?.AsButton();
    
    noButton?.Invoke();
}

// 方案 2：强制终止
if (!app.HasExited)
{
    app.Kill();
}

// 方案 3：使用 WaitWhileBusy
app.Close();
app.WaitWhileBusy(TimeSpan.FromSeconds(5));

if (!app.HasExited)
{
    app.Kill();
}
```

### 问题 9：多窗口应用的窗口切换

**症状**：
- 操作了错误的窗口
- 找不到目标窗口

**解决方案**：

```csharp
// 获取所有窗口
var allWindows = app.GetAllTopLevelWindows(automation);

Console.WriteLine($"找到 {allWindows.Length} 个窗口:");
foreach (var win in allWindows)
{
    Console.WriteLine($"  - {win.Title}");
}

// 根据标题查找特定窗口
var targetWindow = allWindows.FirstOrDefault(w => w.Title.Contains("目标窗口"));

if (targetWindow != null)
{
    targetWindow.SetForeground();  // 切换到目标窗口
    // 进行操作...
}
```

## 控件操作问题

### 问题 10：文本框输入失败

**症状**：
```csharp
textBox.Text = "测试";  // 文本未输入
```

**解决方案**：

```csharp
// 方案 1：设置焦点后输入
window.SetForeground();
textBox.Click();
Thread.Sleep(300);
textBox.Text = "测试";

// 方案 2：使用键盘输入
textBox.Click();
Thread.Sleep(300);
Keyboard.Type("测试");

// 方案 3：清空后输入
textBox.Text = "";
Thread.Sleep(100);
textBox.Text = "测试";

// 方案 4：检查文本框状态
if (textBox.IsEnabled && !textBox.IsReadOnly)
{
    textBox.Text = "测试";
}
else
{
    Console.WriteLine("文本框不可编辑");
}
```

### 问题 11：下拉框选择失败

**症状**：
```csharp
comboBox.Select("选项1");  // 未选中或抛出异常
```

**解决方案**：

```csharp
// 方案 1：先展开再选择
comboBox.Expand();
Thread.Sleep(500);
comboBox.Select("选项1");

// 方案 2：按索引选择
comboBox.Select(0);  // 选择第一项

// 方案 3：使用键盘选择
comboBox.Click();
Thread.Sleep(300);
Keyboard.Press(VirtualKeyShort.DOWN);  // 下移
Keyboard.Press(VirtualKeyShort.ENTER);  // 确认

// 方案 4：检查选项是否存在
var items = comboBox.Items;
var item = items.FirstOrDefault(i => i.Name == "选项1");
if (item != null)
{
    item.Select();
}
else
{
    Console.WriteLine("选项不存在");
}
```

### 问题 12：复选框状态设置失败

**症状**：
```csharp
checkBox.IsChecked = true;  // 状态未改变
```

**解决方案**：

```csharp
// 方案 1：使用 Toggle 方法
if (checkBox.IsChecked == false)
{
    checkBox.Toggle();
}

// 方案 2：点击复选框
if (checkBox.IsChecked != true)
{
    checkBox.Click();
}

// 方案 3：检查是否支持 Toggle 模式
if (checkBox.Patterns.Toggle.IsSupported)
{
    var togglePattern = checkBox.Patterns.Toggle.Pattern;
    if (togglePattern.ToggleState.Value != ToggleState.On)
    {
        togglePattern.Toggle();
    }
}
```

## 性能和稳定性问题

### 问题 13：测试运行缓慢

**原因**：
- 查找范围过大
- 使用固定等待
- 频繁截图

**解决方案**：

```csharp
// 1. 缩小查找范围
// ❌ 从桌面查找
var element = automation.GetDesktop().FindFirstDescendant(cf => cf.ByName("按钮"));

// ✅ 从窗口查找
var element = window.FindFirstDescendant(cf => cf.ByName("按钮"));

// 2. 使用智能等待
// ❌ 固定等待
Thread.Sleep(5000);

// ✅ 智能等待
WaitForElement(window, cf => cf.ByName("按钮"), 5000);

// 3. 减少截图
// ❌ 每步都截图
screenshot.Capture("step1");
// ... 操作
screenshot.Capture("step2");
// ... 操作
screenshot.Capture("step3");

// ✅ 仅在关键步骤或错误时截图
try
{
    // 测试步骤
}
catch (Exception ex)
{
    screenshot.Capture("error");
    throw;
}

// 4. 缓存元素
// ❌ 重复查找
for (int i = 0; i < 10; i++)
{
    var button = window.FindFirstDescendant(cf => cf.ByName("保存"));
    button.AsButton().Invoke();
}

// ✅ 缓存元素
var button = window.FindFirstDescendant(cf => cf.ByName("保存")).AsButton();
for (int i = 0; i < 10; i++)
{
    button.Invoke();
}
```

### 问题 14：测试不稳定，偶尔失败

**原因**：
- 时序问题
- 元素状态不一致
- 资源竞争

**解决方案**：

```csharp
// 1. 添加重试机制
public void ClickButtonWithRetry(string automationId, int maxAttempts = 3)
{
    for (int i = 0; i < maxAttempts; i++)
    {
        try
        {
            var button = window.FindFirstDescendant(cf => 
                cf.ByAutomationId(automationId)).AsButton();
            
            if (button != null && button.IsEnabled)
            {
                button.Invoke();
                return;
            }
        }
        catch (Exception ex)
        {
            Console.WriteLine($"尝试 {i + 1} 失败: {ex.Message}");
            if (i == maxAttempts - 1)
            {
                throw;
            }
        }
        
        Thread.Sleep(1000);
    }
}

// 2. 等待元素稳定
public AutomationElement WaitForStableElement(
    AutomationElement parent,
    Func<ConditionFactory, ConditionBase> condition)
{
    AutomationElement lastElement = null;
    int stableCount = 0;
    
    for (int i = 0; i < 10; i++)
    {
        var element = parent.FindFirstDescendant(condition);
        
        if (element != null && element == lastElement)
        {
            stableCount++;
            if (stableCount >= 3)  // 连续 3 次找到相同元素
            {
                return element;
            }
        }
        else
        {
            stableCount = 0;
        }
        
        lastElement = element;
        Thread.Sleep(500);
    }
    
    throw new Exception("元素状态不稳定");
}
```

### 问题 15：内存泄漏

**症状**：
- 长时间运行后内存占用增加
- 测试执行越来越慢

**解决方案**：

```csharp
// 1. 正确释放资源
public class TestBase : IDisposable
{
    protected UIA3Automation Automation { get; private set; }
    protected Application App { get; private set; }
    
    protected TestBase()
    {
        Automation = new UIA3Automation();
        App = Application.Launch("app.exe");
    }
    
    public void Dispose()
    {
        // 确保资源被释放
        try
        {
            App?.Close();
            Thread.Sleep(500);
            App?.Kill();
        }
        catch { }
        finally
        {
            Automation?.Dispose();
        }
    }
}

// 2. 避免保留元素引用
// ❌ 累积元素引用
private List<AutomationElement> _allElements = new List<AutomationElement>();

[Fact]
public void Test()
{
    for (int i = 0; i < 1000; i++)
    {
        var element = window.FindFirstDescendant(cf => cf.ByName($"Item{i}"));
        _allElements.Add(element);  // 内存累积
    }
}

// ✅ 不保留引用
[Fact]
public void Test()
{
    for (int i = 0; i < 1000; i++)
    {
        var element = window.FindFirstDescendant(cf => cf.ByName($"Item{i}"));
        ProcessElement(element);
        // 元素会被 GC 回收
    }
}
```

## 特殊情况处理

### 问题 16：处理模态对话框

**解决方案**：

```csharp
public bool HandleDialog(string dialogTitle, string buttonName, int timeoutMs = 5000)
{
    var startTime = DateTime.Now;
    
    while ((DateTime.Now - startTime).TotalMilliseconds < timeoutMs)
    {
        var desktop = automation.GetDesktop();
        var dialog = desktop.FindFirstChild(cf => 
            cf.ByName(dialogTitle).And(cf.ByControlType(ControlType.Window)));
        
        if (dialog != null)
        {
            var button = dialog.FindFirstDescendant(cf => 
                cf.ByName(buttonName))?.AsButton();
            
            if (button != null)
            {
                button.Invoke();
                return true;
            }
        }
        
        Thread.Sleep(500);
    }
    
    return false;
}

// 使用
ClickSaveButton();
HandleDialog("保存", "是", 3000);
```

### 问题 17：处理动态内容

**解决方案**：

```csharp
// 等待内容加载完成
public void WaitForContentLoaded(string loadingIndicatorId)
{
    var startTime = DateTime.Now;
    var timeout = 30000;
    
    while ((DateTime.Now - startTime).TotalMilliseconds < timeout)
    {
        var loadingIndicator = window.FindFirstDescendant(cf => 
            cf.ByAutomationId(loadingIndicatorId));
        
        // 等待加载指示器消失
        if (loadingIndicator == null || loadingIndicator.IsOffscreen)
        {
            return;
        }
        
        Thread.Sleep(500);
    }
    
    throw new TimeoutException("内容加载超时");
}

// 或等待特定元素出现
public void WaitForDynamicContent(string contentId)
{
    var element = WaitForElement(window, cf => cf.ByAutomationId(contentId), 30000);
    
    // 确保元素完全加载
    Thread.Sleep(500);
}
```

## 调试技巧

### 打印元素树

```csharp
public static void PrintElementTree(AutomationElement element, int maxDepth = 5)
{
    Console.WriteLine("=== 元素树 ===");
    PrintElementRecursive(element, 0, maxDepth);
}

private static void PrintElementRecursive(AutomationElement element, int depth, int maxDepth)
{
    if (depth > maxDepth) return;
    
    string indent = new string(' ', depth * 2);
    
    try
    {
        Console.WriteLine($"{indent}[{element.ControlType}] " +
                         $"Name: {element.Name}, " +
                         $"ID: {element.AutomationId}, " +
                         $"Class: {element.ClassName}");
        
        var children = element.FindAllChildren();
        foreach (var child in children)
        {
            PrintElementRecursive(child, depth + 1, maxDepth);
        }
    }
    catch (Exception ex)
    {
        Console.WriteLine($"{indent}[ERROR] {ex.Message}");
    }
}
```
