# 10 - 模式和树结构

本章深入介绍 FlaUI 的模式（Patterns）系统和 UI 元素树结构，帮助你更好地理解和使用 UI Automation。

---

## UI Automation 模式概述

### 什么是模式？

模式（Pattern）定义了 UI 元素支持的操作和属性。不同类型的控件支持不同的模式。

**核心概念**：
- 每个模式对应一组特定的功能
- 元素可以支持多个模式
- 必须先检查元素是否支持某个模式

### 常用模式列表

| 模式 | 说明 | 适用控件 |
|------|------|---------|
| InvokePattern | 调用/点击 | Button, MenuItem |
| ValuePattern | 值的读取和设置 | TextBox, Slider |
| TogglePattern | 切换状态 | CheckBox |
| SelectionPattern | 选择项 | ListBox, ComboBox |
| SelectionItemPattern | 被选择的项 | ListItem |
| ExpandCollapsePattern | 展开/折叠 | TreeItem, ComboBox |
| TextPattern | 文本操作 | Document, TextBox |
| RangeValuePattern | 范围值 | Slider, ProgressBar |
| WindowPattern | 窗口操作 | Window |
| TransformPattern | 移动、调整大小 | Window |

## 常用模式详解

### 1. InvokePattern（调用模式）

用于可以被"点击"或"调用"的元素。

```csharp
using FlaUI.Core.Patterns;

var button = window.FindFirstDescendant(cf => cf.ByName("确定"))?.AsButton();

// 检查是否支持 Invoke 模式
if (button.Patterns.Invoke.IsSupported)
{
    var invokePattern = button.Patterns.Invoke.Pattern;
    invokePattern.Invoke();
    
    // 或者直接使用
    button.Invoke();
}
```

### 2. ValuePattern（值模式）

用于有值的元素，如文本框。

```csharp
var textBox = window.FindFirstDescendant(cf => cf.ByControlType(ControlType.Edit))?.AsTextBox();

// 检查是否支持 Value 模式
if (textBox.Patterns.Value.IsSupported)
{
    var valuePattern = textBox.Patterns.Value.Pattern;
    
    // 设置值
    valuePattern.SetValue("新文本");
    
    // 获取值
    string value = valuePattern.Value.Value;
    Console.WriteLine($"当前值: {value}");
    
    // 检查是否只读
    bool isReadOnly = valuePattern.IsReadOnly.Value;
    Console.WriteLine($"是否只读: {isReadOnly}");
}
```

### 3. TogglePattern（切换模式）

用于有开/关状态的元素，如复选框。

```csharp
using FlaUI.Core.Definitions;

var checkBox = window.FindFirstDescendant(cf => cf.ByName("记住密码"))?.AsCheckBox();

if (checkBox.Patterns.Toggle.IsSupported)
{
    var togglePattern = checkBox.Patterns.Toggle.Pattern;
    
    // 获取当前状态
    ToggleState state = togglePattern.ToggleState.Value;
    Console.WriteLine($"当前状态: {state}");
    
    // 切换状态
    togglePattern.Toggle();
    
    // 或者直接使用
    checkBox.Toggle();
}

// ToggleState 的可能值：
// - ToggleState.Off (未选中)
// - ToggleState.On (选中)
// - ToggleState.Indeterminate (不确定状态)
```

### 4. SelectionPattern（选择模式）

用于包含可选项的容器，如列表框。

```csharp
var listBox = window.FindFirstDescendant(cf => cf.ByControlType(ControlType.List))?.AsListBox();

if (listBox.Patterns.Selection.IsSupported)
{
    var selectionPattern = listBox.Patterns.Selection.Pattern;
    
    // 获取所有选中项
    var selectedItems = selectionPattern.Selection.Value;
    Console.WriteLine($"选中了 {selectedItems.Length} 项");
    
    foreach (var item in selectedItems)
    {
        Console.WriteLine($"  - {item.Name}");
    }
    
    // 是否可以多选
    bool canSelectMultiple = selectionPattern.CanSelectMultiple.Value;
    
    // 是否必须选中一项
    bool isSelectionRequired = selectionPattern.IsSelectionRequired.Value;
}
```

### 5. SelectionItemPattern（选择项模式）

用于可被选择的项。

```csharp
var listItem = listBox.Items[0];

if (listItem.Patterns.SelectionItem.IsSupported)
{
    var selectionItemPattern = listItem.Patterns.SelectionItem.Pattern;
    
    // 选择此项
    selectionItemPattern.Select();
    
    // 添加到选择（多选）
    selectionItemPattern.AddToSelection();
    
    // 从选择中移除
    selectionItemPattern.RemoveFromSelection();
    
    // 检查是否被选中
    bool isSelected = selectionItemPattern.IsSelected.Value;
    Console.WriteLine($"是否选中: {isSelected}");
}
```

### 6. ExpandCollapsePattern（展开折叠模式）

用于可展开/折叠的元素，如树节点、下拉框。

```csharp
using FlaUI.Core.Definitions;

var treeItem = tree.Items[0].AsTreeItem();

if (treeItem.Patterns.ExpandCollapse.IsSupported)
{
    var expandCollapsePattern = treeItem.Patterns.ExpandCollapse.Pattern;
    
    // 获取当前状态
    ExpandCollapseState state = expandCollapsePattern.ExpandCollapseState.Value;
    Console.WriteLine($"展开状态: {state}");
    
    // 展开
    expandCollapsePattern.Expand();
    
    // 折叠
    expandCollapsePattern.Collapse();
    
    // 或者直接使用
    treeItem.Expand();
    treeItem.Collapse();
}

// ExpandCollapseState 的可能值：
// - ExpandCollapseState.Collapsed (折叠)
// - ExpandCollapseState.Expanded (展开)
// - ExpandCollapseState.PartiallyExpanded (部分展开)
// - ExpandCollapseState.LeafNode (叶子节点，不可展开)
```

### 7. RangeValuePattern（范围值模式）

用于有范围的值，如滑块、进度条。

```csharp
var slider = window.FindFirstDescendant(cf => cf.ByControlType(ControlType.Slider))?.AsSlider();

if (slider.Patterns.RangeValue.IsSupported)
{
    var rangeValuePattern = slider.Patterns.RangeValue.Pattern;
    
    // 获取范围
    double minimum = rangeValuePattern.Minimum.Value;
    double maximum = rangeValuePattern.Maximum.Value;
    double current = rangeValuePattern.Value.Value;
    
    Console.WriteLine($"范围: {minimum} - {maximum}");
    Console.WriteLine($"当前值: {current}");
    
    // 设置值
    rangeValuePattern.SetValue(50.0);
    
    // 获取步长
    double smallChange = rangeValuePattern.SmallChange.Value;
    double largeChange = rangeValuePattern.LargeChange.Value;
    
    // 是否只读
    bool isReadOnly = rangeValuePattern.IsReadOnly.Value;
}
```

### 8. WindowPattern（窗口模式）

用于窗口操作。

```csharp
using FlaUI.Core.Definitions;

var window = app.GetMainWindow(automation);

if (window.Patterns.Window.IsSupported)
{
    var windowPattern = window.Patterns.Window.Pattern;
    
    // 获取窗口状态
    WindowVisualState state = windowPattern.WindowVisualState.Value;
    WindowInteractionState interactionState = windowPattern.WindowInteractionState.Value;
    
    // 设置窗口状态
    windowPattern.SetWindowVisualState(WindowVisualState.Maximized);
    
    // 关闭窗口
    windowPattern.Close();
    
    // 等待输入空闲
    windowPattern.WaitForInputIdle(5000);
    
    // 检查窗口属性
    bool isModal = windowPattern.IsModal.Value;
    bool isTopmost = windowPattern.IsTopmost.Value;
    bool canMaximize = windowPattern.CanMaximize.Value;
    bool canMinimize = windowPattern.CanMinimize.Value;
}
```

### 9. TextPattern（文本模式）

用于文本内容的高级操作。

```csharp
var editBox = window.FindFirstDescendant(cf => cf.ByControlType(ControlType.Edit));

if (editBox.Patterns.Text.IsSupported)
{
    var textPattern = editBox.Patterns.Text.Pattern;
    
    // 获取整个文本
    var documentRange = textPattern.DocumentRange.Value;
    string text = documentRange.GetText(-1);
    Console.WriteLine($"文本内容: {text}");
    
    // 获取选中的文本
    var selectedRanges = textPattern.GetSelection();
    foreach (var range in selectedRanges)
    {
        Console.WriteLine($"选中文本: {range.GetText(-1)}");
    }
    
    // 查找文本
    var foundRange = documentRange.FindText("查找", false, false);
    if (foundRange != null)
    {
        Console.WriteLine("找到文本");
        foundRange.Select();  // 选中找到的文本
    }
}
```

## 模式使用示例

### 完整示例：检查元素支持的所有模式

```csharp
using System;
using System.Linq;
using FlaUI.Core;
using FlaUI.Core.AutomationElements;
using FlaUI.UIA3;

class PatternInspectionExample
{
    static void Main()
    {
        using var automation = new UIA3Automation();
        var app = Application.Launch("calc.exe");
        System.Threading.Thread.Sleep(1500);
        
        var window = app.GetMainWindow(automation);
        
        // 查找一个按钮
        var button = window.FindFirstDescendant(cf => cf.ByName("一"))?.AsButton();
        
        if (button != null)
        {
            Console.WriteLine($"元素: {button.Name}");
            Console.WriteLine("支持的模式:\n");
            
            CheckPattern(button, "Invoke", button.Patterns.Invoke.IsSupported);
            CheckPattern(button, "Value", button.Patterns.Value.IsSupported);
            CheckPattern(button, "Toggle", button.Patterns.Toggle.IsSupported);
            CheckPattern(button, "Selection", button.Patterns.Selection.IsSupported);
            CheckPattern(button, "SelectionItem", button.Patterns.SelectionItem.IsSupported);
            CheckPattern(button, "ExpandCollapse", button.Patterns.ExpandCollapse.IsSupported);
            CheckPattern(button, "RangeValue", button.Patterns.RangeValue.IsSupported);
            CheckPattern(button, "Transform", button.Patterns.Transform.IsSupported);
            CheckPattern(button, "Text", button.Patterns.Text.IsSupported);
        }
        
        System.Threading.Thread.Sleep(2000);
        app.Close();
    }
    
    static void CheckPattern(AutomationElement element, string patternName, bool isSupported)
    {
        string status = isSupported ? "✓" : "✗";
        Console.WriteLine($"  {status} {patternName}Pattern");
    }
}
```

## UI 元素树结构

### 树的概念

UI Automation 将应用程序的 UI 组织成树状结构：

```
Desktop (桌面)
└── Window (窗口)
    ├── TitleBar (标题栏)
    ├── MenuBar (菜单栏)
    │   ├── MenuItem (菜单项)
    │   └── MenuItem (菜单项)
    ├── ToolBar (工具栏)
    └── Client Area (客户区)
        ├── Panel (面板)
        │   ├── Button (按钮)
        │   └── TextBox (文本框)
        └── StatusBar (状态栏)
```

### 遍历树结构

#### 1. 遍历子元素

```csharp
var window = app.GetMainWindow(automation);

// 获取所有直接子元素
var children = window.FindAllChildren();

Console.WriteLine($"窗口有 {children.Length} 个子元素:");
foreach (var child in children)
{
    Console.WriteLine($"  - [{child.ControlType}] {child.Name}");
}
```

#### 2. 递归遍历所有后代

```csharp
public static void TraverseTree(AutomationElement element, int depth = 0)
{
    string indent = new string(' ', depth * 2);
    
    try
    {
        Console.WriteLine($"{indent}[{element.ControlType}] {element.Name} " +
                         $"(ID: {element.AutomationId})");
        
        // 限制深度避免过深
        if (depth < 5)
        {
            var children = element.FindAllChildren();
            foreach (var child in children)
            {
                TraverseTree(child, depth + 1);
            }
        }
    }
    catch (Exception ex)
    {
        Console.WriteLine($"{indent}错误: {ex.Message}");
    }
}

// 使用
var window = app.GetMainWindow(automation);
TraverseTree(window);
```

#### 3. 查找特定深度的元素

```csharp
// 只查找子元素（深度 1）
var children = window.FindAllChildren(cf => cf.ByControlType(ControlType.Button));

// 查找所有后代（所有深度）
var allButtons = window.FindAllDescendants(cf => cf.ByControlType(ControlType.Button));

Console.WriteLine($"子按钮数: {children.Length}");
Console.WriteLine($"所有按钮数: {allButtons.Length}");
```

### TreeScope（树作用域）

```csharp
using FlaUI.Core.Definitions;

// 不同的搜索范围
var element = window.FindFirst(TreeScope.Element, cf => cf.ByName("按钮"));      // 仅当前元素
var child = window.FindFirst(TreeScope.Children, cf => cf.ByName("按钮"));       // 直接子元素
var descendant = window.FindFirst(TreeScope.Descendants, cf => cf.ByName("按钮"));// 所有后代
var subtree = window.FindFirst(TreeScope.Subtree, cf => cf.ByName("按钮"));      // 当前元素及所有后代
```

## 实用工具：UI 树浏览器

```csharp
using System;
using System.Collections.Generic;
using FlaUI.Core.AutomationElements;

public class UITreeBrowser
{
    public static void Browse(AutomationElement root)
    {
        var stack = new Stack<(AutomationElement element, int depth)>();
        stack.Push((root, 0));
        
        int index = 0;
        var elements = new List<AutomationElement>();
        
        Console.WriteLine("UI 树结构:");
        Console.WriteLine("=" + new string('=', 70));
        
        while (stack.Count > 0)
        {
            var (element, depth) = stack.Pop();
            string indent = new string(' ', depth * 2);
            
            try
            {
                elements.Add(element);
                
                Console.WriteLine($"{index,3}. {indent}[{element.ControlType,-15}] " +
                                $"{element.Name,-30} " +
                                $"ID: {element.AutomationId}");
                
                index++;
                
                // 限制深度
                if (depth < 4)
                {
                    var children = element.FindAllChildren();
                    // 反向压栈以保持正确顺序
                    for (int i = children.Length - 1; i >= 0; i--)
                    {
                        stack.Push((children[i], depth + 1));
                    }
                }
            }
            catch (Exception ex)
            {
                Console.WriteLine($"{index,3}. {indent}[ERROR] {ex.Message}");
                index++;
            }
        }
        
        Console.WriteLine("=" + new string('=', 70));
        Console.WriteLine($"共 {elements.Count} 个元素");
        
        // 交互式查看
        InteractiveView(elements);
    }
    
    private static void InteractiveView(List<AutomationElement> elements)
    {
        Console.WriteLine("\n输入元素编号查看详情 (输入 'q' 退出):");
        
        while (true)
        {
            Console.Write("> ");
            string input = Console.ReadLine();
            
            if (input?.ToLower() == "q")
            {
                break;
            }
            
            if (int.TryParse(input, out int index) && index >= 0 && index < elements.Count)
            {
                ShowElementDetails(elements[index]);
            }
            else
            {
                Console.WriteLine("无效的编号");
            }
        }
    }
    
    private static void ShowElementDetails(AutomationElement element)
    {
        Console.WriteLine("\n" + new string('-', 70));
        Console.WriteLine("元素详情:");
        Console.WriteLine($"  Name: {element.Name}");
        Console.WriteLine($"  AutomationId: {element.AutomationId}");
        Console.WriteLine($"  ClassName: {element.ClassName}");
        Console.WriteLine($"  ControlType: {element.ControlType}");
        Console.WriteLine($"  IsEnabled: {element.IsEnabled}");
        Console.WriteLine($"  IsOffscreen: {element.IsOffscreen}");
        Console.WriteLine($"  BoundingRectangle: {element.BoundingRectangle}");
        
        Console.WriteLine("\n支持的模式:");
        Console.WriteLine($"  Invoke: {element.Patterns.Invoke.IsSupported}");
        Console.WriteLine($"  Value: {element.Patterns.Value.IsSupported}");
        Console.WriteLine($"  Toggle: {element.Patterns.Toggle.IsSupported}");
        Console.WriteLine($"  Selection: {element.Patterns.Selection.IsSupported}");
        Console.WriteLine(new string('-', 70) + "\n");
    }
}

// 使用示例
class UITreeBrowserExample
{
    static void Main()
    {
        using var automation = new UIA3Automation();
        var app = Application.Launch("calc.exe");
        System.Threading.Thread.Sleep(1500);
        
        var window = app.GetMainWindow(automation);
        
        // 浏览 UI 树
        UITreeBrowser.Browse(window);
        
        app.Close();
    }
}
```
