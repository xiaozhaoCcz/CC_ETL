# 04 - 元素定位详解

元素定位是 UI 自动化测试的核心技能。本章将详细介绍 FlaUI 提供的各种元素定位方法。

---

## 基本定位方法

### 1. 按名称查找 (ByName)

最常用的查找方式，通过元素的 `Name` 属性定位。

```csharp
using FlaUI.Core;
using FlaUI.UIA3;

using var automation = new UIA3Automation();
var app = Application.Launch("notepad.exe");
var window = app.GetMainWindow(automation);

// 查找菜单项
var fileMenu = window.FindFirstDescendant(cf => cf.ByName("文件"));

// 组合条件：名称 + 控件类型
var saveButton = window.FindFirstDescendant(cf => 
    cf.ByName("保存").And(cf.ByControlType(ControlType.Button)));
```

**优点**：
- 直观易懂
- 适合用户可见的元素

**缺点**：
- 受语言环境影响（中英文）
- 名称可能重复
- 可能随版本变化

### 2. 按 AutomationId 查找 (ByAutomationId)

最推荐的查找方式，使用元素的唯一标识符。

```csharp
// 按 AutomationId 查找（最稳定）
var element = window.FindFirstDescendant(cf => cf.ByAutomationId("SaveButton"));

// 示例：查找记事本的编辑区
var editBox = window.FindFirstDescendant(cf => cf.ByAutomationId("15"));
```

**优点**：
- 唯一性强
- 不受语言影响
- 稳定性高

**缺点**：
- 需要开发者设置
- 部分旧应用没有 AutomationId

**如何查看 AutomationId**：
使用 Inspect.exe 或 FlaUInspect 工具查看元素的 AutomationId 属性。

### 3. 按类名查找 (ByClassName)

通过元素的 CSS 类名或控件类名查找。

```csharp
// 查找按钮类
var button = window.FindFirstDescendant(cf => cf.ByClassName("Button"));

// 查找编辑框
var textBox = window.FindFirstDescendant(cf => cf.ByClassName("Edit"));

// WPF 应用示例
var wpfButton = window.FindFirstDescendant(cf => cf.ByClassName("System.Windows.Controls.Button"));
```

**适用场景**：
- 当没有 AutomationId 时
- 需要查找特定类型的控件

### 4. 按控件类型查找 (ByControlType)

通过 UI Automation 定义的控件类型查找。

```csharp
using FlaUI.Core.Definitions;

// 查找按钮
var button = window.FindFirstDescendant(cf => cf.ByControlType(ControlType.Button));

// 查找文本框
var textBox = window.FindFirstDescendant(cf => cf.ByControlType(ControlType.Edit));

// 查找所有按钮
var allButtons = window.FindAllDescendants(cf => cf.ByControlType(ControlType.Button));

// 查找菜单
var menu = window.FindFirstDescendant(cf => cf.ByControlType(ControlType.Menu));

// 查找列表
var list = window.FindFirstDescendant(cf => cf.ByControlType(ControlType.List));
```

**常用控件类型**：
- `ControlType.Button` - 按钮
- `ControlType.Edit` - 文本框
- `ControlType.CheckBox` - 复选框
- `ControlType.RadioButton` - 单选按钮
- `ControlType.ComboBox` - 下拉框
- `ControlType.List` - 列表
- `ControlType.Menu` - 菜单
- `ControlType.MenuItem` - 菜单项
- `ControlType.Tree` - 树形控件
- `ControlType.DataGrid` - 数据表格
- `ControlType.Tab` - 标签页

### 5. 按帮助文本查找 (ByHelpText)

通过元素的帮助文本（工具提示）查找。

```csharp
// 按帮助文本查找
var button = window.FindFirstDescendant(cf => cf.ByHelpText("点击保存文件"));
```

## 高级定位方法

### 1. XPath 查找

使用 XPath 表达式查找元素。

```csharp
// 简单 XPath
var button = window.FindFirstByXPath("//Button[@Name='保存']");

// 复杂 XPath
var element = window.FindFirstByXPath("//Pane/Button[@AutomationId='SaveButton']");

// 查找所有匹配元素
var elements = window.FindAllByXPath("//Button");
```

**XPath 语法示例**：

```csharp
// 按属性查找
"//Button[@Name='确定']"
"//Edit[@AutomationId='txtUsername']"

// 按层级查找
"//Window/Pane/Button"

// 按索引查找
"//Button[1]"  // 第一个按钮
"//Button[last()]"  // 最后一个按钮

// 组合条件
"//Button[@Name='保存' and @ClassName='Button']"

// 包含文本
"//Button[contains(@Name, '保存')]"
```

**注意事项**：
- XPath 查找速度较慢
- 应作为备选方案
- 仅在其他方法不可用时使用

### 2. 组合条件查找

使用 `And` 和 `Or` 组合多个查找条件。

```csharp
// And：所有条件都满足
var saveButton = window.FindFirstDescendant(cf => 
    cf.ByName("保存")
      .And(cf.ByControlType(ControlType.Button))
      .And(cf.ByClassName("Button")));

// Or：满足任一条件
var button = window.FindFirstDescendant(cf => 
    cf.ByName("确定")
      .Or(cf.ByName("OK"))
      .Or(cf.ByName("Yes")));

// 复杂组合
var element = window.FindFirstDescendant(cf => 
    cf.ByControlType(ControlType.Button)
      .And(
          cf.ByName("保存").Or(cf.ByName("Save"))
      ));
```

### 3. 自定义条件查找

使用自定义函数进行复杂查找。

```csharp
// 自定义条件：查找包含特定文本的元素
var element = window.FindFirstDescendant(cf => 
    cf.ByControlType(ControlType.Button)
      .And(new PropertyCondition(
          automation.PropertyLibrary.Element.Name,
          "保存",
          PropertyConditionFlags.IgnoreCase)));

// 使用 Func 自定义查找逻辑
var button = window.FindFirst(TreeScope.Descendants, elem => 
{
    return elem.ControlType == ControlType.Button && 
           elem.Name.Contains("保存") &&
           elem.IsEnabled;
});
```

## 层级定位

### 1. 父子关系定位

```csharp
// 查找子元素
var child = parent.FindFirstChild(cf => cf.ByName("ChildElement"));

// 查找所有子元素
var children = parent.FindAllChildren();

// 查找父元素
var parent = element.Parent;

// 查找祖先元素
var ancestor = element.Parent?.Parent;
```

### 2. 兄弟元素定位

```csharp
using FlaUI.Core.AutomationElements;

// 获取所有兄弟元素
var siblings = element.Parent?.FindAllChildren();

// 查找下一个兄弟元素
var parent = element.Parent;
var children = parent?.FindAllChildren();
if (children != null)
{
    var index = Array.IndexOf(children, element);
    var nextSibling = (index >= 0 && index < children.Length - 1) 
        ? children[index + 1] 
        : null;
}
```

### 3. 相对定位

```csharp
// 先定位父容器，再定位目标元素
var panel = window.FindFirstDescendant(cf => cf.ByAutomationId("MainPanel"));
var button = panel?.FindFirstDescendant(cf => cf.ByName("保存"));

// 链式定位
var element = window
    .FindFirstDescendant(cf => cf.ByAutomationId("Toolbar"))
    ?.FindFirstChild(cf => cf.ByControlType(ControlType.Button));
```

## 实战示例

### 示例 1：定位记事本元素

```csharp
using System;
using FlaUI.Core;
using FlaUI.Core.Definitions;
using FlaUI.UIA3;

class NotepadExample
{
    static void Main()
    {
        using var automation = new UIA3Automation();
        var app = Application.Launch("notepad.exe");
        System.Threading.Thread.Sleep(1000);
        
        var window = app.GetMainWindow(automation);
        Console.WriteLine($"窗口标题: {window.Title}");
        
        // 方式1：按控件类型查找编辑框
        var editBox1 = window.FindFirstDescendant(cf => 
            cf.ByControlType(ControlType.Edit));
        
        // 方式2：按类名查找
        var editBox2 = window.FindFirstDescendant(cf => 
            cf.ByClassName("Edit"));
        
        // 方式3：按 AutomationId 查找（记事本的编辑框ID是"15"）
        var editBox3 = window.FindFirstDescendant(cf => 
            cf.ByAutomationId("15"));
        
        if (editBox1 != null)
        {
            Console.WriteLine("方式1：找到编辑框");
            var textBox = editBox1.AsTextBox();
            textBox.Text = "Hello FlaUI!";
        }
        
        Console.ReadKey();
        app.Close();
    }
}
```

### 示例 2：定位计算器按钮

```csharp
using System;
using FlaUI.Core;
using FlaUI.Core.Definitions;
using FlaUI.UIA3;

class CalculatorExample
{
    static void Main()
    {
        using var automation = new UIA3Automation();
        var app = Application.Launch("calc.exe");
        System.Threading.Thread.Sleep(1500);
        
        var window = app.GetMainWindow(automation);
        
        // 查找数字按钮 "1"（中文系统）
        var button1_cn = window.FindFirstDescendant(cf => 
            cf.ByName("一").And(cf.ByControlType(ControlType.Button)));
        
        // 查找数字按钮 "1"（英文系统）
        var button1_en = window.FindFirstDescendant(cf => 
            cf.ByName("One").And(cf.ByControlType(ControlType.Button)));
        
        // 兼容中英文系统
        var button1 = button1_cn ?? button1_en;
        
        if (button1 != null)
        {
            Console.WriteLine($"找到按钮: {button1.Name}");
            button1.AsButton()?.Invoke();
        }
        
        System.Threading.Thread.Sleep(2000);
        app.Close();
    }
}
```

### 示例 3：查找所有按钮并打印信息

```csharp
using System;
using FlaUI.Core;
using FlaUI.Core.Definitions;
using FlaUI.UIA3;

class FindAllButtonsExample
{
    static void Main()
    {
        using var automation = new UIA3Automation();
        var app = Application.Launch("calc.exe");
        System.Threading.Thread.Sleep(1500);
        
        var window = app.GetMainWindow(automation);
        
        // 查找所有按钮
        var buttons = window.FindAllDescendants(cf => 
            cf.ByControlType(ControlType.Button));
        
        Console.WriteLine($"找到 {buttons.Length} 个按钮:\n");
        
        foreach (var button in buttons)
        {
            Console.WriteLine($"名称: {button.Name,-20} " +
                            $"ID: {button.AutomationId,-15} " +
                            $"启用: {button.IsEnabled}");
        }
        
        Console.ReadKey();
        app.Close();
    }
}
```

### 示例 4：封装元素定位辅助类

```csharp
using FlaUI.Core;
using FlaUI.Core.AutomationElements;
using FlaUI.Core.Definitions;
using System;

public class ElementFinder
{
    private readonly AutomationElement _root;
    
    public ElementFinder(AutomationElement root)
    {
        _root = root ?? throw new ArgumentNullException(nameof(root));
    }
    
    /// <summary>
    /// 按多种方式查找元素（优先级：AutomationId > Name）
    /// </summary>
    public AutomationElement FindElement(string automationId = null, string name = null, 
        ControlType controlType = null, int timeoutMs = 5000)
    {
        var startTime = DateTime.Now;
        
        while ((DateTime.Now - startTime).TotalMilliseconds < timeoutMs)
        {
            AutomationElement element = null;
            
            // 优先使用 AutomationId
            if (!string.IsNullOrEmpty(automationId))
            {
                element = _root.FindFirstDescendant(cf => cf.ByAutomationId(automationId));
                if (element != null) return element;
            }
            
            // 其次使用 Name + ControlType
            if (!string.IsNullOrEmpty(name))
            {
                if (controlType != null)
                {
                    element = _root.FindFirstDescendant(cf => 
                        cf.ByName(name).And(cf.ByControlType(controlType)));
                }
                else
                {
                    element = _root.FindFirstDescendant(cf => cf.ByName(name));
                }
                
                if (element != null) return element;
            }
            
            // 仅使用 ControlType
            if (controlType != null && string.IsNullOrEmpty(name) && string.IsNullOrEmpty(automationId))
            {
                element = _root.FindFirstDescendant(cf => cf.ByControlType(controlType));
                if (element != null) return element;
            }
            
            System.Threading.Thread.Sleep(500);
        }
        
        return null;
    }
    
    /// <summary>
    /// 查找按钮
    /// </summary>
    public Button FindButton(string name = null, string automationId = null)
    {
        var element = FindElement(automationId, name, ControlType.Button);
        return element?.AsButton();
    }
    
    /// <summary>
    /// 查找文本框
    /// </summary>
    public TextBox FindTextBox(string name = null, string automationId = null)
    {
        var element = FindElement(automationId, name, ControlType.Edit);
        return element?.AsTextBox();
    }
    
    /// <summary>
    /// 查找复选框
    /// </summary>
    public CheckBox FindCheckBox(string name = null, string automationId = null)
    {
        var element = FindElement(automationId, name, ControlType.CheckBox);
        return element?.AsCheckBox();
    }
}

// 使用示例
class Program
{
    static void Main()
    {
        using var automation = new UIA3Automation();
        var app = Application.Launch("notepad.exe");
        System.Threading.Thread.Sleep(1000);
        
        var window = app.GetMainWindow(automation);
        var finder = new ElementFinder(window);
        
        // 使用封装的查找方法
        var editBox = finder.FindTextBox(automationId: "15");
        if (editBox != null)
        {
            editBox.Text = "使用封装的查找方法！";
            Console.WriteLine("文本已输入");
        }
        
        Console.ReadKey();
        app.Close();
    }
}
```

## 定位策略最佳实践

### 1. 优先级推荐

```
1️⃣ AutomationId（最优）
   - 唯一性强
   - 不受语言影响
   - 维护成本低

2️⃣ Name + ControlType（推荐）
   - 直观易读
   - 适合用户可见元素
   - 需考虑多语言

3️⃣ ClassName（一般）
   - 适合特定控件
   - 可能不唯一

4️⃣ XPath（备选）
   - 功能强大
   - 性能较差
   - 维护困难
```

### 2. 提高定位稳定性

```csharp
// ❌ 不稳定：仅使用名称
var button = window.FindFirstDescendant(cf => cf.ByName("按钮"));

// ✅ 更稳定：组合多个条件
var button = window.FindFirstDescendant(cf => 
    cf.ByName("按钮")
      .And(cf.ByControlType(ControlType.Button))
      .And(cf.ByClassName("Button")));

// ✅ 最稳定：使用 AutomationId
var button = window.FindFirstDescendant(cf => cf.ByAutomationId("btnSubmit"));
```

### 3. 性能优化

```csharp
// ❌ 性能差：从桌面开始查找
var desktop = automation.GetDesktop();
var button = desktop.FindFirstDescendant(cf => cf.ByName("按钮"));

// ✅ 性能好：缩小查找范围
var window = app.GetMainWindow(automation);
var button = window.FindFirstDescendant(cf => cf.ByName("按钮"));

// ✅ 更好：先定位容器
var panel = window.FindFirstDescendant(cf => cf.ByAutomationId("MainPanel"));
var button = panel.FindFirstChild(cf => cf.ByName("按钮"));
```

### 4. 处理动态元素

```csharp
// 等待元素出现
public static AutomationElement WaitForElement(
    AutomationElement parent, 
    Func<ConditionFactory, ConditionBase> condition,
    int timeoutMs = 5000)
{
    var startTime = DateTime.Now;
    
    while ((DateTime.Now - startTime).TotalMilliseconds < timeoutMs)
    {
        var element = parent.FindFirstDescendant(condition);
        if (element != null)
        {
            return element;
        }
        System.Threading.Thread.Sleep(500);
    }
    
    return null;
}

// 使用示例
var button = WaitForElement(window, cf => cf.ByName("加载完成的按钮"), 10000);
```

## 常见问题

### 问题 1：找不到元素

**可能原因**：
1. 元素尚未加载
2. 元素属性不正确
3. 查找范围不对

**解决方案**：
```csharp
// 1. 增加等待时间
System.Threading.Thread.Sleep(2000);

// 2. 使用 Inspect 工具验证属性
// 确认 Name、AutomationId 等是否正确

// 3. 扩大查找范围
var element = window.FindFirstDescendant(cf => cf.ByName("元素"));

// 4. 尝试不同的查找方式
var element = window.FindFirstByXPath("//Button[@Name='元素']");
```

### 问题 2：找到多个相同元素

**解决方案**：
```csharp
// 方案1：添加更多限定条件
var button = window.FindFirstDescendant(cf => 
    cf.ByName("确定")
      .And(cf.ByControlType(ControlType.Button))
      .And(cf.ByClassName("PrimaryButton")));

// 方案2：通过父容器缩小范围
var dialog = window.FindFirstDescendant(cf => cf.ByName("对话框"));
var button = dialog?.FindFirstChild(cf => cf.ByName("确定"));

// 方案3：使用索引
var buttons = window.FindAllDescendants(cf => cf.ByName("确定"));
var firstButton = buttons[0];
```
