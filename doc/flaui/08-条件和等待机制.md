# 08 - 条件和等待机制

在 UI 自动化测试中，正确处理等待和条件判断是确保测试稳定性的关键。本章介绍 FlaUI 的等待机制和条件处理。

---

## 为什么需要等待

### 常见问题

1. **元素未加载**：应用启动或页面切换时，元素可能尚未出现
2. **动画效果**：某些 UI 有过渡动画，需要等待动画完成
3. **异步操作**：网络请求、数据加载等异步操作需要时间
4. **性能差异**：不同机器性能不同，加载速度有差异

### 错误示例

```csharp
// ❌ 不好的做法：没有等待
var app = Application.Launch("notepad.exe");
var window = app.GetMainWindow(automation);  // 可能失败：窗口未加载
var textBox = window.FindFirstDescendant(cf => cf.ByControlType(ControlType.Edit));  // 可能失败

// ❌ 不好的做法：固定等待时间
System.Threading.Thread.Sleep(5000);  // 浪费时间或时间不够
```

### 正确示例

```csharp
// ✅ 好的做法：智能等待
var app = Application.Launch("notepad.exe");
var window = app.GetMainWindow(automation, timeout: TimeSpan.FromSeconds(10));
var textBox = WaitForElement(window, cf => cf.ByControlType(ControlType.Edit), 5000);
```

## 基本等待方法

### 1. Thread.Sleep（固定等待）

最简单但不推荐的等待方式。

```csharp
using System.Threading;

// 等待 1 秒
Thread.Sleep(1000);

// 等待 500 毫秒
Thread.Sleep(500);
```

**优点**：
- 简单直接

**缺点**：
- 浪费时间（即使条件已满足）
- 不够灵活
- 可能等待时间不够

**使用场景**：
- 演示和调试
- 动画效果的等待
- 已知确切等待时间的场景

### 2. WaitWhileBusy（等待应用就绪）

等待应用程序处理完当前操作。

```csharp
var app = Application.Launch("notepad.exe");

// 等待应用就绪
app.WaitWhileBusy();

// 带超时的等待
bool ready = app.WaitWhileBusy(TimeSpan.FromSeconds(5));
if (!ready)
{
    Console.WriteLine("应用未就绪");
}
```

## 等待元素出现

### 1. 简单等待实现

```csharp
using System;
using FlaUI.Core.AutomationElements;
using FlaUI.Core.Conditions;

/// <summary>
/// 等待元素出现
/// </summary>
public static AutomationElement WaitForElement(
    AutomationElement parent,
    Func<ConditionFactory, ConditionBase> condition,
    int timeoutMs = 5000)
{
    var startTime = DateTime.Now;
    
    while ((DateTime.Now - startTime).TotalMilliseconds < timeoutMs)
    {
        var element = parent.FindFirstDescendant(condition);
        if (element != null)
        {
            return element;
        }
        
        System.Threading.Thread.Sleep(500);
    }
    
    throw new TimeoutException($"元素在 {timeoutMs}ms 内未找到");
}

// 使用示例
var button = WaitForElement(
    window,
    cf => cf.ByName("保存").And(cf.ByControlType(ControlType.Button)),
    10000
);
```

### 2. 增强版等待实现

```csharp
using System;
using FlaUI.Core.AutomationElements;
using FlaUI.Core.Conditions;

public class WaitHelper
{
    /// <summary>
    /// 等待元素出现
    /// </summary>
    public static AutomationElement WaitForElement(
        AutomationElement parent,
        Func<ConditionFactory, ConditionBase> condition,
        int timeoutMs = 5000,
        int pollIntervalMs = 500,
        bool throwOnTimeout = true)
    {
        var startTime = DateTime.Now;
        
        while ((DateTime.Now - startTime).TotalMilliseconds < timeoutMs)
        {
            try
            {
                var element = parent.FindFirstDescendant(condition);
                if (element != null)
                {
                    return element;
                }
            }
            catch
            {
                // 忽略查找过程中的异常
            }
            
            System.Threading.Thread.Sleep(pollIntervalMs);
        }
        
        if (throwOnTimeout)
        {
            throw new TimeoutException($"元素在 {timeoutMs}ms 内未找到");
        }
        
        return null;
    }
    
    /// <summary>
    /// 等待元素消失
    /// </summary>
    public static bool WaitForElementToDisappear(
        AutomationElement parent,
        Func<ConditionFactory, ConditionBase> condition,
        int timeoutMs = 5000,
        int pollIntervalMs = 500)
    {
        var startTime = DateTime.Now;
        
        while ((DateTime.Now - startTime).TotalMilliseconds < timeoutMs)
        {
            try
            {
                var element = parent.FindFirstDescendant(condition);
                if (element == null)
                {
                    return true;  // 元素已消失
                }
            }
            catch
            {
                return true;  // 查找失败说明元素已不存在
            }
            
            System.Threading.Thread.Sleep(pollIntervalMs);
        }
        
        return false;  // 超时，元素仍存在
    }
    
    /// <summary>
    /// 等待元素可点击
    /// </summary>
    public static AutomationElement WaitForElementClickable(
        AutomationElement parent,
        Func<ConditionFactory, ConditionBase> condition,
        int timeoutMs = 5000)
    {
        var startTime = DateTime.Now;
        
        while ((DateTime.Now - startTime).TotalMilliseconds < timeoutMs)
        {
            try
            {
                var element = parent.FindFirstDescendant(condition);
                if (element != null && element.IsEnabled && !element.IsOffscreen)
                {
                    return element;
                }
            }
            catch
            {
                // 继续等待
            }
            
            System.Threading.Thread.Sleep(500);
        }
        
        throw new TimeoutException($"元素在 {timeoutMs}ms 内未变为可点击状态");
    }
}

// 使用示例
class WaitHelperExample
{
    static void Main()
    {
        using var automation = new UIA3Automation();
        var app = Application.Launch("notepad.exe");
        
        var window = app.GetMainWindow(automation);
        
        // 等待编辑框出现并可用
        var editBox = WaitHelper.WaitForElementClickable(
            window,
            cf => cf.ByControlType(ControlType.Edit),
            10000
        );
        
        editBox.AsTextBox().Text = "元素已就绪";
        
        System.Threading.Thread.Sleep(2000);
        app.Close();
        
        // 等待窗口消失
        bool disappeared = WaitHelper.WaitForElementToDisappear(
            automation.GetDesktop(),
            cf => cf.ByName("记事本").And(cf.ByControlType(ControlType.Window)),
            5000
        );
        
        Console.WriteLine(disappeared ? "窗口已关闭" : "窗口仍存在");
    }
}
```

## 条件等待

### 1. 等待特定条件

```csharp
/// <summary>
/// 等待条件满足
/// </summary>
public static bool WaitUntil(
    Func<bool> condition,
    int timeoutMs = 5000,
    int pollIntervalMs = 500)
{
    var startTime = DateTime.Now;
    
    while ((DateTime.Now - startTime).TotalMilliseconds < timeoutMs)
    {
        if (condition())
        {
            return true;
        }
        
        System.Threading.Thread.Sleep(pollIntervalMs);
    }
    
    return false;
}

// 使用示例
var textBox = window.FindFirstDescendant(cf => cf.ByControlType(ControlType.Edit))?.AsTextBox();

// 等待文本框包含特定文本
bool success = WaitUntil(
    () => textBox?.Text?.Contains("完成") ?? false,
    10000
);

if (success)
{
    Console.WriteLine("文本已包含'完成'");
}
```

### 2. 等待窗口状态

```csharp
using FlaUI.Core.Definitions;

/// <summary>
/// 等待窗口达到特定状态
/// </summary>
public static bool WaitForWindowState(
    Window window,
    WindowVisualState expectedState,
    int timeoutMs = 5000)
{
    return WaitUntil(
        () => window.WindowVisualState == expectedState,
        timeoutMs
    );
}

// 使用示例
var window = app.GetMainWindow(automation);

// 最大化窗口
window.SetWindowVisualState(WindowVisualState.Maximized);

// 等待窗口最大化完成
bool maximized = WaitForWindowState(window, WindowVisualState.Maximized, 3000);
Console.WriteLine(maximized ? "窗口已最大化" : "最大化超时");
```

## 重试机制

### 1. 简单重试

```csharp
/// <summary>
/// 重试执行操作
/// </summary>
public static T Retry<T>(
    Func<T> action,
    int maxAttempts = 3,
    int delayMs = 1000)
{
    Exception lastException = null;
    
    for (int i = 0; i < maxAttempts; i++)
    {
        try
        {
            return action();
        }
        catch (Exception ex)
        {
            lastException = ex;
            Console.WriteLine($"尝试 {i + 1}/{maxAttempts} 失败: {ex.Message}");
            
            if (i < maxAttempts - 1)
            {
                System.Threading.Thread.Sleep(delayMs);
            }
        }
    }
    
    throw new Exception($"操作在 {maxAttempts} 次尝试后仍失败", lastException);
}

// 使用示例
var button = Retry(
    () => window.FindFirstDescendant(cf => cf.ByName("保存"))?.AsButton() 
          ?? throw new Exception("按钮未找到"),
    maxAttempts: 3,
    delayMs: 1000
);

button.Invoke();
```

### 2. 带指数退避的重试

```csharp
/// <summary>
/// 使用指数退避策略重试
/// </summary>
public static T RetryWithBackoff<T>(
    Func<T> action,
    int maxAttempts = 3,
    int initialDelayMs = 500,
    double backoffMultiplier = 2.0)
{
    Exception lastException = null;
    int delay = initialDelayMs;
    
    for (int i = 0; i < maxAttempts; i++)
    {
        try
        {
            return action();
        }
        catch (Exception ex)
        {
            lastException = ex;
            Console.WriteLine($"尝试 {i + 1}/{maxAttempts} 失败: {ex.Message}");
            
            if (i < maxAttempts - 1)
            {
                Console.WriteLine($"等待 {delay}ms 后重试...");
                System.Threading.Thread.Sleep(delay);
                delay = (int)(delay * backoffMultiplier);
            }
        }
    }
    
    throw new Exception($"操作在 {maxAttempts} 次尝试后仍失败", lastException);
}
```

## 完整的等待工具类

```csharp
using System;
using FlaUI.Core.AutomationElements;
using FlaUI.Core.Conditions;
using FlaUI.Core.Definitions;

public class Wait
{
    private readonly int _defaultTimeoutMs;
    private readonly int _defaultPollIntervalMs;
    
    public Wait(int defaultTimeoutMs = 5000, int defaultPollIntervalMs = 500)
    {
        _defaultTimeoutMs = defaultTimeoutMs;
        _defaultPollIntervalMs = defaultPollIntervalMs;
    }
    
    /// <summary>
    /// 等待元素出现
    /// </summary>
    public AutomationElement ForElement(
        AutomationElement parent,
        Func<ConditionFactory, ConditionBase> condition,
        int? timeoutMs = null)
    {
        var timeout = timeoutMs ?? _defaultTimeoutMs;
        var startTime = DateTime.Now;
        
        while ((DateTime.Now - startTime).TotalMilliseconds < timeout)
        {
            var element = parent.FindFirstDescendant(condition);
            if (element != null)
            {
                return element;
            }
            
            System.Threading.Thread.Sleep(_defaultPollIntervalMs);
        }
        
        throw new TimeoutException($"元素在 {timeout}ms 内未找到");
    }
    
    /// <summary>
    /// 等待元素消失
    /// </summary>
    public bool ForElementToDisappear(
        AutomationElement parent,
        Func<ConditionFactory, ConditionBase> condition,
        int? timeoutMs = null)
    {
        var timeout = timeoutMs ?? _defaultTimeoutMs;
        var startTime = DateTime.Now;
        
        while ((DateTime.Now - startTime).TotalMilliseconds < timeout)
        {
            try
            {
                var element = parent.FindFirstDescendant(condition);
                if (element == null)
                {
                    return true;
                }
            }
            catch
            {
                return true;
            }
            
            System.Threading.Thread.Sleep(_defaultPollIntervalMs);
        }
        
        return false;
    }
    
    /// <summary>
    /// 等待条件满足
    /// </summary>
    public bool Until(Func<bool> condition, int? timeoutMs = null)
    {
        var timeout = timeoutMs ?? _defaultTimeoutMs;
        var startTime = DateTime.Now;
        
        while ((DateTime.Now - startTime).TotalMilliseconds < timeout)
        {
            if (condition())
            {
                return true;
            }
            
            System.Threading.Thread.Sleep(_defaultPollIntervalMs);
        }
        
        return false;
    }
    
    /// <summary>
    /// 等待元素可用
    /// </summary>
    public AutomationElement ForElementEnabled(
        AutomationElement parent,
        Func<ConditionFactory, ConditionBase> condition,
        int? timeoutMs = null)
    {
        var element = ForElement(parent, condition, timeoutMs);
        
        var timeout = timeoutMs ?? _defaultTimeoutMs;
        var startTime = DateTime.Now;
        
        while ((DateTime.Now - startTime).TotalMilliseconds < timeout)
        {
            if (element.IsEnabled)
            {
                return element;
            }
            
            System.Threading.Thread.Sleep(_defaultPollIntervalMs);
        }
        
        throw new TimeoutException($"元素在 {timeout}ms 内未变为可用状态");
    }
    
    /// <summary>
    /// 等待窗口状态
    /// </summary>
    public bool ForWindowState(
        Window window,
        WindowVisualState expectedState,
        int? timeoutMs = null)
    {
        return Until(() => window.WindowVisualState == expectedState, timeoutMs);
    }
}

// 使用示例
class WaitExample
{
    static void Main()
    {
        using var automation = new UIA3Automation();
        var app = Application.Launch("calc.exe");
        
        // 创建 Wait 实例
        var wait = new Wait(defaultTimeoutMs: 10000, defaultPollIntervalMs: 500);
        
        var window = app.GetMainWindow(automation);
        
        // 等待按钮出现
        var button = wait.ForElement(
            window,
            cf => cf.ByName("一").And(cf.ByControlType(ControlType.Button)),
            timeoutMs: 5000
        );
        
        Console.WriteLine("按钮已找到");
        button.AsButton().Invoke();
        
        System.Threading.Thread.Sleep(2000);
        app.Close();
        
        // 等待窗口关闭
        bool closed = wait.ForElementToDisappear(
            automation.GetDesktop(),
            cf => cf.ByName("计算器").And(cf.ByControlType(ControlType.Window)),
            timeoutMs: 5000
        );
        
        Console.WriteLine(closed ? "计算器已关闭" : "关闭超时");
    }
}
```

## 最佳实践

### 1. 避免固定等待

```csharp
// ❌ 不好
Thread.Sleep(5000);
var element = window.FindFirstDescendant(cf => cf.ByName("按钮"));

// ✅ 好
var element = WaitHelper.WaitForElement(
    window,
    cf => cf.ByName("按钮"),
    5000
);
```

### 2. 设置合理的超时时间

```csharp
// 快速操作：1-3 秒
var button = wait.ForElement(window, cf => cf.ByName("确定"), 3000);

// 正常操作：5-10 秒
var dialog = wait.ForElement(window, cf => cf.ByName("对话框"), 10000);

// 慢速操作：30-60 秒
var loadingComplete = wait.Until(() => IsLoadingComplete(), 60000);
```

### 3. 提供清晰的错误信息

```csharp
try
{
    var element = wait.ForElement(
        window,
        cf => cf.ByName("保存按钮"),
        5000
    );
}
catch (TimeoutException ex)
{
    Console.WriteLine("错误：找不到保存按钮");
    Console.WriteLine($"详细信息: {ex.Message}");
    throw;
}
```

### 4. 组合等待条件

```csharp
// 等待元素出现且可用
public static AutomationElement WaitForElementReady(
    AutomationElement parent,
    Func<ConditionFactory, ConditionBase> condition,
    int timeoutMs = 5000)
{
    var element = WaitHelper.WaitForElement(parent, condition, timeoutMs);
    
    if (!WaitHelper.WaitUntil(() => element.IsEnabled && !element.IsOffscreen, 3000))
    {
        throw new Exception("元素未就绪");
    }
    
    return element;
}
```
