# 03 - UI 自动化基础概念

本章介绍 UI 自动化的核心概念，帮助你更好地理解 FlaUI 的工作原理。

---

## UI Automation (UIA) 框架

### 什么是 UI Automation？

UI Automation (UIA) 是 Microsoft 提供的一个框架，用于以编程方式访问和操作用户界面元素。

**核心组件**：
1. **提供者（Provider）**：应用程序端，暴露 UI 元素信息
2. **客户端（Client）**：测试代码端，访问 UI 元素
3. **核心服务**：Windows 系统提供的中间层

### UIA2 vs UIA3

FlaUI 支持两种自动化引擎：

| 特性 | UIA2 | UIA3 |
|------|------|------|
| 系统要求 | Windows XP+ | Windows 7+ |
| 性能 | 较慢 | 更快 |
| 功能 | 基础 | 更丰富 |
| 推荐程度 | 备选 | 首选 |

**使用建议**：
- 优先使用 UIA3
- 如果遇到兼容性问题，再尝试 UIA2

```csharp
// 使用 UIA3
using var automation = new UIA3Automation();

// 使用 UIA2
using var automation = new UIA2Automation();
```

## 自动化元素 (AutomationElement)

### 元素树结构

Windows UI 应用程序的元素以树状结构组织：

```
桌面 (Desktop)
└── 窗口 (Window)
    ├── 菜单栏 (MenuBar)
    │   ├── 文件 (MenuItem)
    │   └── 编辑 (MenuItem)
    ├── 工具栏 (ToolBar)
    │   ├── 按钮1 (Button)
    │   └── 按钮2 (Button)
    └── 内容区 (Pane)
        ├── 文本框 (TextBox)
        └── 按钮 (Button)
```

### 元素关系

```csharp
// 获取父元素
var parent = element.Parent;

// 获取子元素
var children = element.FindAllChildren();

// 获取第一个子元素
var firstChild = element.FindFirstChild();

// 获取所有后代元素
var descendants = element.FindAllDescendants();
```

### 元素属性

每个自动化元素都有一组属性：

#### 基本属性

```csharp
var element = window.FindFirstDescendant(cf => cf.ByAutomationId("myButton"));

// 名称
string name = element.Name;

// 自动化ID（推荐用于元素定位）
string id = element.AutomationId;

// 类名
string className = element.ClassName;

// 控件类型
var controlType = element.ControlType;

// 是否可用
bool isEnabled = element.IsEnabled;

// 是否可见
bool isVisible = !element.IsOffscreen;

// 边界矩形
var bounds = element.BoundingRectangle;
```

#### 示例：打印元素信息

```csharp
using System;
using FlaUI.Core;
using FlaUI.Core.AutomationElements;
using FlaUI.UIA3;

class Program
{
    static void Main()
    {
        using var automation = new UIA3Automation();
        var app = Application.Launch("calc.exe");
        System.Threading.Thread.Sleep(1000);
        
        var window = app.GetMainWindow(automation);
        
        // 查找一个按钮
        var button = window.FindFirstDescendant(cf => cf.ByName("二"))?.AsButton();
        
        if (button != null)
        {
            PrintElementInfo(button);
        }
        
        app.Close();
    }
    
    static void PrintElementInfo(AutomationElement element)
    {
        Console.WriteLine("=== 元素信息 ===");
        Console.WriteLine($"Name: {element.Name}");
        Console.WriteLine($"AutomationId: {element.AutomationId}");
        Console.WriteLine($"ClassName: {element.ClassName}");
        Console.WriteLine($"ControlType: {element.ControlType}");
        Console.WriteLine($"IsEnabled: {element.IsEnabled}");
        Console.WriteLine($"IsOffscreen: {element.IsOffscreen}");
        Console.WriteLine($"BoundingRectangle: {element.BoundingRectangle}");
    }
}
```

## 控件类型 (ControlType)

FlaUI 支持多种控件类型：

### 常用控件类型

| 控件类型 | 说明 | 示例 |
|---------|------|------|
| `Button` | 按钮 | 确定、取消按钮 |
| `TextBox` | 文本框 | 输入框 |
| `CheckBox` | 复选框 | 多选框 |
| `RadioButton` | 单选按钮 | 单选框 |
| `ComboBox` | 下拉框 | 选择列表 |
| `ListBox` | 列表框 | 选项列表 |
| `Menu` | 菜单 | 主菜单 |
| `MenuItem` | 菜单项 | 菜单中的项 |
| `Window` | 窗口 | 应用程序窗口 |
| `TabControl` | 标签页控件 | 选项卡 |
| `Tree` | 树形控件 | 文件夹树 |
| `DataGrid` | 数据表格 | 表格数据 |

### 按控件类型查找元素

```csharp
using FlaUI.Core.Definitions;

// 查找按钮
var button = window.FindFirstDescendant(cf => cf.ByControlType(ControlType.Button));

// 查找文本框
var textBox = window.FindFirstDescendant(cf => cf.ByControlType(ControlType.Edit));

// 查找所有按钮
var allButtons = window.FindAllDescendants(cf => cf.ByControlType(ControlType.Button));

Console.WriteLine($"找到 {allButtons.Length} 个按钮");
```

### 类型转换

FlaUI 提供了便捷的类型转换方法：

```csharp
// 转换为按钮
var button = element.AsButton();

// 转换为文本框
var textBox = element.AsTextBox();

// 转换为复选框
var checkBox = element.AsCheckBox();

// 转换为下拉框
var comboBox = element.AsComboBox();

// 转换为列表框
var listBox = element.AsListBox();
```

## 模式 (Patterns)

模式定义了元素支持的操作类型。不同的控件支持不同的模式。

### 常用模式

#### 1. Invoke Pattern（调用模式）

用于可点击的元素（如按钮）：

```csharp
var button = element.AsButton();

// 检查是否支持 Invoke 模式
if (button.Patterns.Invoke.IsSupported)
{
    button.Invoke();  // 点击按钮
}
```

#### 2. Value Pattern（值模式）

用于有值的元素（如文本框）：

```csharp
var textBox = element.AsTextBox();

// 设置值
if (textBox.Patterns.Value.IsSupported)
{
    textBox.Text = "Hello World";
}

// 获取值
string value = textBox.Text;
```

#### 3. Toggle Pattern（切换模式）

用于可切换状态的元素（如复选框）：

```csharp
var checkBox = element.AsCheckBox();

// 切换状态
checkBox.Toggle();

// 设置状态
checkBox.IsChecked = true;

// 获取状态
bool isChecked = checkBox.IsChecked ?? false;
```

#### 4. Selection Pattern（选择模式）

用于可选择的元素（如列表、下拉框）：

```csharp
var comboBox = element.AsComboBox();

// 选择项
comboBox.Select("选项1");

// 获取选中项
var selectedItem = comboBox.SelectedItem;
Console.WriteLine($"当前选中: {selectedItem?.Name}");
```

#### 5. Expand/Collapse Pattern（展开/折叠模式）

用于可展开的元素（如树节点）：

```csharp
var treeItem = element.AsTreeItem();

// 展开
treeItem.Expand();

// 折叠
treeItem.Collapse();

// 检查状态
var state = treeItem.ExpandCollapseState;
```

### 模式支持检查

```csharp
var element = window.FindFirstDescendant(cf => cf.ByName("myElement"));

// 检查支持的模式
if (element.Patterns.Invoke.IsSupported)
{
    Console.WriteLine("支持 Invoke 模式");
}

if (element.Patterns.Value.IsSupported)
{
    Console.WriteLine("支持 Value 模式");
}

if (element.Patterns.Toggle.IsSupported)
{
    Console.WriteLine("支持 Toggle 模式");
}
```

## 查找策略

### 1. 直接子元素 vs 所有后代

```csharp
// 查找直接子元素（仅一层）
var child = window.FindFirstChild(cf => cf.ByName("myButton"));

// 查找所有后代元素（递归查找）
var descendant = window.FindFirstDescendant(cf => cf.ByName("myButton"));
```

**使用建议**：
- `FindFirstChild`：速度快，适合已知元素位置
- `FindFirstDescendant`：功能强，适合不确定元素层级

### 2. 单个元素 vs 多个元素

```csharp
// 查找第一个匹配的元素
var element = window.FindFirstDescendant(cf => cf.ByControlType(ControlType.Button));

// 查找所有匹配的元素
var elements = window.FindAllDescendants(cf => cf.ByControlType(ControlType.Button));

Console.WriteLine($"找到 {elements.Length} 个按钮");
foreach (var btn in elements)
{
    Console.WriteLine($"按钮: {btn.Name}");
}
```

### 3. 组合条件

```csharp
// 使用 And 组合条件
var element = window.FindFirstDescendant(cf => 
    cf.ByName("保存")
      .And(cf.ByControlType(ControlType.Button))
      .And(cf.ByClassName("Button")));

// 使用 Or 组合条件
var element = window.FindFirstDescendant(cf => 
    cf.ByName("确定")
      .Or(cf.ByName("OK")));
```

## 元素定位最佳实践

### 1. 优先级顺序

元素定位建议按以下优先级：

1. **AutomationId**（最稳定）
```csharp
var element = window.FindFirstDescendant(cf => cf.ByAutomationId("btnSave"));
```

2. **Name + ControlType**（较稳定）
```csharp
var element = window.FindFirstDescendant(cf => 
    cf.ByName("保存").And(cf.ByControlType(ControlType.Button)));
```

3. **ClassName**（一般）
```csharp
var element = window.FindFirstDescendant(cf => cf.ByClassName("Button"));
```

4. **XPath**（最后选择）
```csharp
var element = window.FindFirstByXPath("//Button[@Name='保存']");
```

### 2. 性能优化

```csharp
// ❌ 不推荐：查找范围过大
var button = automation.GetDesktop().FindFirstDescendant(cf => cf.ByName("按钮"));

// ✅ 推荐：缩小查找范围
var window = app.GetMainWindow(automation);
var button = window.FindFirstDescendant(cf => cf.ByName("按钮"));

// ✅ 更好：限定查找深度
var panel = window.FindFirstDescendant(cf => cf.ByAutomationId("mainPanel"));
var button = panel.FindFirstChild(cf => cf.ByName("按钮"));
```

### 3. 健壮性提升

```csharp
// 使用空值合并操作符
var button = window.FindFirstDescendant(cf => cf.ByName("按钮"))?.AsButton();
if (button != null)
{
    button.Invoke();
}

// 或者使用可选链
window.FindFirstDescendant(cf => cf.ByName("按钮"))?.AsButton()?.Invoke();
```

## 实战示例：遍历元素树

```csharp
using System;
using FlaUI.Core;
using FlaUI.Core.AutomationElements;
using FlaUI.UIA3;

class Program
{
    static void Main()
    {
        using var automation = new UIA3Automation();
        var app = Application.Launch("notepad.exe");
        System.Threading.Thread.Sleep(1000);
        
        var window = app.GetMainWindow(automation);
        
        // 遍历元素树
        Console.WriteLine("=== 元素树结构 ===");
        PrintElementTree(window, 0);
        
        Console.ReadKey();
        app.Close();
    }
    
    // 递归打印元素树
    static void PrintElementTree(AutomationElement element, int depth)
    {
        // 打印缩进
        string indent = new string(' ', depth * 2);
        
        // 打印元素信息
        Console.WriteLine($"{indent}[{element.ControlType}] {element.Name} (ID: {element.AutomationId})");
        
        // 递归打印子元素（限制深度避免过深）
        if (depth < 5)
        {
            try
            {
                var children = element.FindAllChildren();
                foreach (var child in children)
                {
                    PrintElementTree(child, depth + 1);
                }
            }
            catch (Exception ex)
            {
                Console.WriteLine($"{indent}  错误: {ex.Message}");
            }
        }
    }
}
```
