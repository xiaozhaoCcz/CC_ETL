# 16 - 性能优化技巧

本章介绍如何优化 FlaUI 自动化测试的性能，提高测试执行速度和稳定性。

---

## 性能瓶颈分析

### 常见性能问题

1. **元素查找慢**：查找范围过大或条件复杂
2. **等待时间长**：使用固定等待而非智能等待
3. **重复操作**：未缓存元素或重复初始化
4. **截图过多**：每步都截图影响性能
5. **资源未释放**：未正确释放资源导致内存泄漏

## 元素查找优化

### 1. 缩小查找范围

```csharp
// ❌ 慢：从桌面开始查找
var desktop = automation.GetDesktop();
var button = desktop.FindFirstDescendant(cf => cf.ByName("保存"));

// ✅ 快：从窗口开始查找
var window = app.GetMainWindow(automation);
var button = window.FindFirstDescendant(cf => cf.ByName("保存"));

// ✅ 更快：从已知容器开始查找
var panel = window.FindFirstDescendant(cf => cf.ByAutomationId("MainPanel"));
var button = panel.FindFirstChild(cf => cf.ByName("保存"));
```

### 2. 使用更精确的定位条件

```csharp
// ❌ 慢：仅使用名称
var button = window.FindFirstDescendant(cf => cf.ByName("确定"));

// ✅ 快：组合多个条件
var button = window.FindFirstDescendant(cf => 
    cf.ByAutomationId("btnOk")
      .And(cf.ByControlType(ControlType.Button)));

// ✅ 最快：使用 AutomationId（如果可用）
var button = window.FindFirstDescendant(cf => cf.ByAutomationId("btnOk"));
```

### 3. 避免深度查找

```csharp
// ❌ 慢：递归查找所有后代
var allButtons = window.FindAllDescendants(cf => cf.ByControlType(ControlType.Button));

// ✅ 快：只查找直接子元素（如果结构已知）
var buttons = window.FindAllChildren(cf => cf.ByControlType(ControlType.Button));
```

### 4. 使用 TreeScope 限制范围

```csharp
using FlaUI.Core.Definitions;

// 限制查找范围
var element = window.FindFirst(
    TreeScope.Children,  // 只查找直接子元素
    cf => cf.ByName("按钮")
);
```

## 元素缓存

### 1. 缓存常用元素

```csharp
public class LoginPage
{
    private readonly Window _window;
    
    // 缓存元素
    private TextBox _usernameBox;
    private TextBox _passwordBox;
    private Button _loginButton;
    
    public LoginPage(Window window)
    {
        _window = window;
    }
    
    // 懒加载 + 缓存
    private TextBox UsernameBox
    {
        get
        {
            if (_usernameBox == null)
            {
                _usernameBox = _window.FindFirstDescendant(cf => 
                    cf.ByAutomationId("UsernameTextBox"))?.AsTextBox();
            }
            return _usernameBox;
        }
    }
    
    private TextBox PasswordBox
    {
        get
        {
            if (_passwordBox == null)
            {
                _passwordBox = _window.FindFirstDescendant(cf => 
                    cf.ByAutomationId("PasswordTextBox"))?.AsTextBox();
            }
            return _passwordBox;
        }
    }
    
    private Button LoginButton
    {
        get
        {
            if (_loginButton == null)
            {
                _loginButton = _window.FindFirstDescendant(cf => 
                    cf.ByAutomationId("LoginButton"))?.AsButton();
            }
            return _loginButton;
        }
    }
    
    public void Login(string username, string password)
    {
        UsernameBox.Text = username;
        PasswordBox.Text = password;
        LoginButton.Invoke();
    }
}
```

### 2. 批量查找元素

```csharp
// ❌ 低效：多次查找
var button1 = window.FindFirstDescendant(cf => cf.ByName("按钮1"));
var button2 = window.FindFirstDescendant(cf => cf.ByName("按钮2"));
var button3 = window.FindFirstDescendant(cf => cf.ByName("按钮3"));

// ✅ 高效：一次查找所有
var allButtons = window.FindAllDescendants(cf => cf.ByControlType(ControlType.Button));
var button1 = allButtons.FirstOrDefault(b => b.Name == "按钮1");
var button2 = allButtons.FirstOrDefault(b => b.Name == "按钮2");
var button3 = allButtons.FirstOrDefault(b => b.Name == "按钮3");
```

## 等待优化

### 1. 使用智能等待

```csharp
public class SmartWait
{
    /// <summary>
    /// 智能等待：元素出现后立即返回
    /// </summary>
    public static AutomationElement ForElement(
        AutomationElement parent,
        Func<ConditionFactory, ConditionBase> condition,
        int timeoutMs = 5000,
        int pollIntervalMs = 100)  // 使用较短的轮询间隔
    {
        var startTime = DateTime.Now;
        
        while ((DateTime.Now - startTime).TotalMilliseconds < timeoutMs)
        {
            var element = parent.FindFirstDescendant(condition);
            if (element != null)
            {
                return element;  // 找到后立即返回，不浪费时间
            }
            
            Thread.Sleep(pollIntervalMs);
        }
        
        throw new TimeoutException($"元素在 {timeoutMs}ms 内未找到");
    }
}
```

### 2. 减少不必要的等待

```csharp
// ❌ 每次操作都等待固定时间
button.Invoke();
Thread.Sleep(500);
textBox.Text = "test";
Thread.Sleep(500);
checkbox.IsChecked = true;
Thread.Sleep(500);

// ✅ 仅在必要时等待
button.Invoke();
// 等待按钮点击的结果出现
WaitForElement("ResultLabel", 2000);

textBox.Text = "test";
// 文本输入通常不需要等待

checkbox.IsChecked = true;
// 状态改变通常是即时的
```

### 3. 并行等待

```csharp
// 等待多个条件同时满足
public static bool WaitForMultipleConditions(
    params Func<bool>[] conditions)
{
    var timeout = 5000;
    var startTime = DateTime.Now;
    
    while ((DateTime.Now - startTime).TotalMilliseconds < timeout)
    {
        if (conditions.All(c => c()))
        {
            return true;
        }
        Thread.Sleep(100);
    }
    
    return false;
}

// 使用
WaitForMultipleConditions(
    () => statusLabel.Name == "就绪",
    () => progressBar.Value == 100,
    () => loadButton.IsEnabled
);
```

## 截图优化

### 1. 按需截图

```csharp
public class OptimizedScreenshot
{
    private readonly bool _screenshotEnabled;
    private readonly bool _screenshotOnErrorOnly;
    
    public OptimizedScreenshot(bool enabled = true, bool onErrorOnly = false)
    {
        _screenshotEnabled = enabled;
        _screenshotOnErrorOnly = onErrorOnly;
    }
    
    public void CaptureIfNeeded(Window window, string name, bool isError = false)
    {
        if (!_screenshotEnabled)
        {
            return;
        }
        
        if (_screenshotOnErrorOnly && !isError)
        {
            return;
        }
        
        Capture.Element(window).ToFile($"{name}.png");
    }
}

// 使用
var screenshot = new OptimizedScreenshot(
    enabled: true,
    onErrorOnly: true  // 仅在错误时截图
);
```

### 2. 异步截图

```csharp
using System.Threading.Tasks;

public class AsyncScreenshot
{
    private readonly string _directory;
    
    public AsyncScreenshot(string directory)
    {
        _directory = directory;
        Directory.CreateDirectory(_directory);
    }
    
    public Task CaptureAsync(Window window, string name)
    {
        return Task.Run(() =>
        {
            var filename = Path.Combine(_directory, $"{name}.png");
            Capture.Element(window).ToFile(filename);
        });
    }
}

// 使用
var screenshot = new AsyncScreenshot("Screenshots");
await screenshot.CaptureAsync(window, "step1");  // 不阻塞主线程
```

## 资源管理

### 1. 正确释放资源

```csharp
// ✅ 使用 using 语句
public void TestMethod()
{
    using (var automation = new UIA3Automation())
    {
        var app = Application.Launch("app.exe");
        try
        {
            // 测试代码
        }
        finally
        {
            app?.Close();
        }
    }  // automation 自动释放
}

// ✅ 实现 IDisposable
public class TestPage : IDisposable
{
    private readonly Application _app;
    private readonly UIA3Automation _automation;
    
    public TestPage()
    {
        _automation = new UIA3Automation();
        _app = Application.Launch("app.exe");
    }
    
    public void Dispose()
    {
        _app?.Close();
        _automation?.Dispose();
    }
}
```

### 2. 避免内存泄漏

```csharp
// ❌ 可能导致内存泄漏
public class LeakyTest
{
    private List<AutomationElement> _elements = new List<AutomationElement>();
    
    [Fact]
    public void Test()
    {
        for (int i = 0; i < 1000; i++)
        {
            var element = window.FindFirstDescendant(cf => cf.ByName($"Item{i}"));
            _elements.Add(element);  // 不断积累，不释放
        }
    }
}

// ✅ 及时清理
public class CleanTest
{
    [Fact]
    public void Test()
    {
        for (int i = 0; i < 1000; i++)
        {
            var element = window.FindFirstDescendant(cf => cf.ByName($"Item{i}"));
            // 使用元素
            ProcessElement(element);
            // 不保存引用，让 GC 回收
        }
    }
}
```

## 性能监控

### 测试性能追踪

```csharp
using System.Diagnostics;

public class PerformanceTracker
{
    private readonly Stopwatch _stopwatch = new Stopwatch();
    private readonly Dictionary<string, long> _metrics = new Dictionary<string, long>();
    
    public void Start(string operation)
    {
        _stopwatch.Restart();
    }
    
    public void Stop(string operation)
    {
        _stopwatch.Stop();
        _metrics[operation] = _stopwatch.ElapsedMilliseconds;
        Console.WriteLine($"{operation}: {_stopwatch.ElapsedMilliseconds}ms");
    }
    
    public void PrintSummary()
    {
        Console.WriteLine("\n=== 性能统计 ===");
        foreach (var metric in _metrics.OrderByDescending(m => m.Value))
        {
            Console.WriteLine($"{metric.Key}: {metric.Value}ms");
        }
        Console.WriteLine($"总计: {_metrics.Values.Sum()}ms");
    }
}

// 使用
var tracker = new PerformanceTracker();

tracker.Start("启动应用");
var app = Application.Launch("app.exe");
tracker.Stop("启动应用");

tracker.Start("查找元素");
var element = window.FindFirstDescendant(cf => cf.ByName("按钮"));
tracker.Stop("查找元素");

tracker.Start("点击按钮");
element.AsButton().Invoke();
tracker.Stop("点击按钮");

tracker.PrintSummary();
```

## 性能对比示例

### 优化前后对比

```csharp
// 优化前：~15 秒
public void SlowTest()
{
    for (int i = 0; i < 10; i++)
    {
        var button = automation.GetDesktop()
            .FindFirstDescendant(cf => cf.ByName($"Button{i}"));
        button?.AsButton().Invoke();
        Thread.Sleep(1000);
    }
}

// 优化后：~3 秒
public void FastTest()
{
    // 1. 缩小查找范围
    var window = app.GetMainWindow(automation);
    
    // 2. 批量查找并缓存
    var allButtons = window.FindAllDescendants(cf => 
        cf.ByControlType(ControlType.Button));
    
    for (int i = 0; i < 10; i++)
    {
        // 3. 使用 AutomationId
        var button = allButtons.FirstOrDefault(b => 
            b.AutomationId == $"btn{i}")?.AsButton();
        
        button?.Invoke();
        
        // 4. 智能等待而非固定 Sleep
        WaitForCondition(() => IsProcessComplete(), 2000);
    }
}
```
