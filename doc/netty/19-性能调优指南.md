## 1. 线程模型优化

### 1.1 EventLoopGroup线程数设置

```java
/**
 * 线程数优化
 */
public class ThreadOptimization {
    
    public static void main(String[] args) throws Exception {
        // 获取CPU核心数
        int cpuCount = Runtime.getRuntime().availableProcessors();
        System.out.println("CPU核心数: " + cpuCount);
        
        // Boss线程：1个足够（只负责accept）
        EventLoopGroup bossGroup = new NioEventLoopGroup(1);
        
        // Worker线程：根据业务类型
        // IO密集型：CPU核心数 * 2
        // CPU密集型：CPU核心数 + 1
        EventLoopGroup workerGroup = new NioEventLoopGroup(cpuCount * 2);
        
        // 业务线程池：处理耗时操作
        ExecutorService businessExecutor = Executors.newFixedThreadPool(
            cpuCount * 4,
            new ThreadFactory() {
                private final AtomicInteger index = new AtomicInteger(0);
                @Override
                public Thread newThread(Runnable r) {
                    Thread thread = new Thread(r);
                    thread.setName("business-" + index.getAndIncrement());
                    thread.setDaemon(true);
                    return thread;
                }
            }
        );
        
        ServerBootstrap b = new ServerBootstrap();
        b.group(bossGroup, workerGroup)
         .channel(NioServerSocketChannel.class)
         .childHandler(new ChannelInitializer<SocketChannel>() {
             @Override
             protected void initChannel(SocketChannel ch) {
                 ch.pipeline()
                   // IO Handler在workerGroup中执行
                   .addLast(new StringDecoder())
                   .addLast(new StringEncoder())
                   // 业务Handler使用独立线程池
                   .addLast(new DefaultEventExecutorGroup(cpuCount * 2), 
                            new BusinessHandler(businessExecutor));
             }
         });
    }
}
```

### 1.2 避免阻塞EventLoop

```java
// ❌ 错误：在EventLoop中执行阻塞操作
public class BadHandler extends ChannelInboundHandlerAdapter {
    @Override
    public void channelRead(ChannelHandlerContext ctx, Object msg) {
        // 数据库查询（阻塞）
        String result = database.query();  // 阻塞EventLoop！
        
        // 文件IO（阻塞）
        Files.write(path, data);  // 阻塞EventLoop！
        
        ctx.writeAndFlush(result);
    }
}

// ✅ 正确：使用线程池处理阻塞操作
public class GoodHandler extends ChannelInboundHandlerAdapter {
    
    private final ExecutorService executor = Executors.newFixedThreadPool(10);
    
    @Override
    public void channelRead(ChannelHandlerContext ctx, Object msg) {
        // 提交到线程池
        executor.submit(() -> {
            try {
                // 阻塞操作在线程池中执行
                String result = database.query();
                Files.write(path, data);
                
                // 结果写回要在EventLoop中执行
                ctx.channel().eventLoop().execute(() -> {
                    ctx.writeAndFlush(result);
                });
            } catch (Exception e) {
                e.printStackTrace();
            }
        });
    }
}
```

## 3. 网络参数调优

### 3.1 TCP参数优化

```java
/**
 * TCP参数调优
 */
public class TcpOptimization {
    
    public static void configure(ServerBootstrap bootstrap) {
        bootstrap
            // ========== Boss配置 ==========
            
            // TCP连接队列大小（默认128，高并发时增大）
            .option(ChannelOption.SO_BACKLOG, 1024)
            
            // 端口复用（允许TIME_WAIT状态的端口被复用）
            .option(ChannelOption.SO_REUSEADDR, true)
            
            // ========== Worker配置 ==========
            
            // TCP保活（2小时无数据时发送探测包）
            .childOption(ChannelOption.SO_KEEPALIVE, true)
            
            // 禁用Nagle算法（小数据包立即发送，降低延迟）
            .childOption(ChannelOption.TCP_NODELAY, true)
            
            // 发送缓冲区大小
            .childOption(ChannelOption.SO_SNDBUF, 64 * 1024)
            
            // 接收缓冲区大小
            .childOption(ChannelOption.SO_RCVBUF, 64 * 1024)
            
            // 连接超时时间
            .childOption(ChannelOption.CONNECT_TIMEOUT_MILLIS, 3000)
            
            // 写缓冲区水位（防止OOM）
            .childOption(ChannelOption.WRITE_BUFFER_WATER_MARK,
                new WriteBufferWaterMark(32 * 1024, 64 * 1024));
    }
}
```

### 3.2 参数说明

| 参数 | 说明 | 推荐值 | 适用场景 |
|------|------|--------|---------|
| SO_BACKLOG | 连接队列大小 | 1024-2048 | 高并发 |
| SO_REUSEADDR | 端口复用 | true | 服务器 |
| SO_KEEPALIVE | TCP保活 | true | 长连接 |
| TCP_NODELAY | 禁用Nagle | true | 低延迟 |
| SO_SNDBUF | 发送缓冲区 | 64KB | 大数据传输 |
| SO_RCVBUF | 接收缓冲区 | 64KB | 大数据传输 |

## 4. 传输层优化

### 4.1 选择合适的传输方式

```java
/**
 * 传输方式选择
 */
public class TransportSelection {
    
    /**
     * 根据平台选择最优传输
     */
    public static EventLoopGroup createEventLoopGroup(int threads) {
        if (Epoll.isAvailable()) {
            // Linux平台：使用Epoll（性能最优）
            System.out.println("使用Epoll传输");
            return new EpollEventLoopGroup(threads);
        } else if (KQueue.isAvailable()) {
            // MacOS/BSD：使用KQueue
            System.out.println("使用KQueue传输");
            return new KQueueEventLoopGroup(threads);
        } else {
            // 其他平台：使用NIO
            System.out.println("使用NIO传输");
            return new NioEventLoopGroup(threads);
        }
    }
    
    public static Class<? extends ServerChannel> serverChannelClass() {
        if (Epoll.isAvailable()) {
            return EpollServerSocketChannel.class;
        } else if (KQueue.isAvailable()) {
            return KQueueServerSocketChannel.class;
        } else {
            return NioServerSocketChannel.class;
        }
    }
}
```

### 4.2 性能对比

| 传输方式 | 性能 | 平台 | 推荐场景 |
|---------|------|------|---------|
| Epoll | 最优 | Linux | 生产环境 |
| KQueue | 优 | MacOS/BSD | 开发环境 |
| NIO | 一般 | 跨平台 | 兼容性要求高 |

## 5. 零拷贝优化

### 5.1 CompositeByteBuf

```java
// ❌ 低效：复制数据
ByteBuf header = ...;
ByteBuf body = ...;
ByteBuf combined = Unpooled.buffer(header.readableBytes() + body.readableBytes());
combined.writeBytes(header);  // 复制
combined.writeBytes(body);    // 复制

// ✅ 高效：零拷贝
CompositeByteBuf composite = Unpooled.compositeBuffer();
composite.addComponents(true, header, body);  // 只引用，不复制
```

### 5.2 FileRegion

```java
/**
 * 文件零拷贝传输
 */
public class FileTransfer extends ChannelInboundHandlerAdapter {
    
    @Override
    public void channelRead(ChannelHandlerContext ctx, Object msg) throws Exception {
        File file = new File("large-file.dat");
        
        // ❌ 传统方式：复制数据
        byte[] data = Files.readAllBytes(file.toPath());
        ctx.writeAndFlush(Unpooled.wrappedBuffer(data));
        
        // ✅ 零拷贝方式：使用FileRegion
        RandomAccessFile raf = new RandomAccessFile(file, "r");
        FileRegion region = new DefaultFileRegion(raf.getChannel(), 0, file.length());
        ctx.writeAndFlush(region).addListener((ChannelFuture future) -> {
            raf.close();
        });
    }
}
```

## 7. 批量操作

### 7.1 批量写入

```java
/**
 * 批量写入优化
 */
public class BatchWrite extends ChannelInboundHandlerAdapter {
    
    @Override
    public void channelRead(ChannelHandlerContext ctx, Object msg) {
        // ❌ 低效：每次都flush
        ctx.writeAndFlush(msg1);
        ctx.writeAndFlush(msg2);
        ctx.writeAndFlush(msg3);
        
        // ✅ 高效：批量write，最后flush
        ctx.write(msg1);
        ctx.write(msg2);
        ctx.write(msg3);
        ctx.flush();  // 一次flush
    }
}
```

## 8. 监控和诊断

### 8.1 性能监控

```java
/**
 * 性能监控Handler
 */
public class PerformanceMonitorHandler extends ChannelDuplexHandler {
    
    private final AtomicLong readCount = new AtomicLong(0);
    private final AtomicLong readBytes = new AtomicLong(0);
    private final AtomicLong writeCount = new AtomicLong(0);
    private final AtomicLong writeBytes = new AtomicLong(0);
    
    @Override
    public void channelRead(ChannelHandlerContext ctx, Object msg) throws Exception {
        readCount.incrementAndGet();
        if (msg instanceof ByteBuf) {
            readBytes.addAndGet(((ByteBuf) msg).readableBytes());
        }
        super.channelRead(ctx, msg);
    }
    
    @Override
    public void write(ChannelHandlerContext ctx, Object msg, ChannelPromise promise) 
            throws Exception {
        writeCount.incrementAndGet();
        if (msg instanceof ByteBuf) {
            writeBytes.addAndGet(((ByteBuf) msg).readableBytes());
        }
        super.write(ctx, msg, promise);
    }
    
    public void printStats() {
        System.out.println("=== 性能统计 ===");
        System.out.println("读取次数: " + readCount.get());
        System.out.println("读取字节: " + readBytes.get() / 1024 + " KB");
        System.out.println("写入次数: " + writeCount.get());
        System.out.println("写入字节: " + writeBytes.get() / 1024 + " KB");
    }
}
```
