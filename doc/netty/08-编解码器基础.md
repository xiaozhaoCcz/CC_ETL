# 08 - 编解码器基础

编解码器是Netty中非常重要的组件，用于解决TCP的粘包/半包问题，实现协议的编码和解码。

## 1. 什么是粘包和半包？

### 1.1 TCP的流式传输

TCP是流式协议，没有消息边界的概念。

```
发送端发送3条消息：
Message1: "Hello"
Message2: "World"
Message3: "Netty"

接收端可能收到：
情况1（正常）: "Hello" "World" "Netty"
情况2（粘包）: "HelloWorld" "Netty"
情况3（半包）: "Hel" "loWor" "ldNetty"
情况4（粘包+半包）: "HelloWo" "rldNetty"
```

### 1.2 问题演示

```java
/**
 * 演示粘包半包问题
 */
public class StickyPacketDemo {
    
    // 服务器端
    static class Server {
        public static void main(String[] args) throws Exception {
            EventLoopGroup bossGroup = new NioEventLoopGroup(1);
            EventLoopGroup workerGroup = new NioEventLoopGroup();
            
            try {
                ServerBootstrap b = new ServerBootstrap();
                b.group(bossGroup, workerGroup)
                 .channel(NioServerSocketChannel.class)
                 .childHandler(new ChannelInitializer<SocketChannel>() {
                     @Override
                     protected void initChannel(SocketChannel ch) {
                         ch.pipeline().addLast(new ServerHandler());
                     }
                 });
                
                ChannelFuture f = b.bind(8080).sync();
                System.out.println("服务器启动");
                f.channel().closeFuture().sync();
            } finally {
                bossGroup.shutdownGracefully();
                workerGroup.shutdownGracefully();
            }
        }
    }
    
    static class ServerHandler extends ChannelInboundHandlerAdapter {
        private int count = 0;
        
        @Override
        public void channelRead(ChannelHandlerContext ctx, Object msg) {
            ByteBuf buf = (ByteBuf) msg;
            String message = buf.toString(CharsetUtil.UTF_8);
            
            System.out.println("第" + (++count) + "次接收: [" + message + "]");
            System.out.println("长度: " + message.length());
            
            buf.release();
        }
    }
    
    // 客户端
    static class Client {
        public static void main(String[] args) throws Exception {
            EventLoopGroup group = new NioEventLoopGroup();
            
            try {
                Bootstrap b = new Bootstrap();
                b.group(group)
                 .channel(NioSocketChannel.class)
                 .handler(new ChannelInitializer<SocketChannel>() {
                     @Override
                     protected void initChannel(SocketChannel ch) {
                         ch.pipeline().addLast(new ClientHandler());
                     }
                 });
                
                ChannelFuture f = b.connect("localhost", 8080).sync();
                f.channel().closeFuture().sync();
            } finally {
                group.shutdownGracefully();
            }
        }
    }
    
    static class ClientHandler extends ChannelInboundHandlerAdapter {
        @Override
        public void channelActive(ChannelHandlerContext ctx) {
            // 连续发送10条消息
            for (int i = 0; i < 10; i++) {
                String msg = "Message-" + i + "#";
                ByteBuf buf = Unpooled.copiedBuffer(msg, CharsetUtil.UTF_8);
                ctx.writeAndFlush(buf);
            }
        }
    }
}
```

**可能的输出（粘包）：**

```
服务器启动
第1次接收: [Message-0#Message-1#Message-2#]
长度: 30
第2次接收: [Message-3#Message-4#]
长度: 20
第3次接收: [Message-5#Message-6#Message-7#Message-8#Message-9#]
长度: 50
```

## 2. 解决方案

### 2.1 常见的解决方案

1. **固定长度**：每条消息固定N字节
2. **分隔符**：用特殊字符分隔消息（如\n）
3. **长度字段**：在消息头部加上长度字段
4. **固定头+变长体**：头部固定，包含长度信息

### 2.2 Netty提供的解码器

```
ByteToMessageDecoder (抽象类)
    │
    ├── FixedLengthFrameDecoder         ← 固定长度
    ├── LineBasedFrameDecoder           ← 换行符分隔
    ├── DelimiterBasedFrameDecoder      ← 自定义分隔符
    ├── LengthFieldBasedFrameDecoder    ← 长度字段
    └── 自定义解码器
```

## 3. 固定长度解码器

### 3.1 FixedLengthFrameDecoder

每条消息固定N字节。

```java
/**
 * 固定长度解码器示例
 */
public class FixedLengthExample {
    
    public static void main(String[] args) throws Exception {
        EventLoopGroup bossGroup = new NioEventLoopGroup(1);
        EventLoopGroup workerGroup = new NioEventLoopGroup();
        
        try {
            ServerBootstrap b = new ServerBootstrap();
            b.group(bossGroup, workerGroup)
             .channel(NioServerSocketChannel.class)
             .childHandler(new ChannelInitializer<SocketChannel>() {
                 @Override
                 protected void initChannel(SocketChannel ch) {
                     ch.pipeline()
                       // 固定长度解码器：每10字节一条消息
                       .addLast(new FixedLengthFrameDecoder(10))
                       .addLast(new StringDecoder(CharsetUtil.UTF_8))
                       .addLast(new ServerHandler());
                 }
             });
            
            ChannelFuture f = b.bind(8080).sync();
            System.out.println("服务器启动（固定长度10字节）");
            f.channel().closeFuture().sync();
        } finally {
            bossGroup.shutdownGracefully();
            workerGroup.shutdownGracefully();
        }
    }
    
    static class ServerHandler extends SimpleChannelInboundHandler<String> {
        private int count = 0;
        
        @Override
        protected void channelRead0(ChannelHandlerContext ctx, String msg) {
            System.out.println("第" + (++count) + "条消息: [" + msg + "]");
        }
    }
}
```

**客户端发送：**

```java
ctx.writeAndFlush(Unpooled.copiedBuffer("1234567890", CharsetUtil.UTF_8));
ctx.writeAndFlush(Unpooled.copiedBuffer("ABCDEFGHIJ", CharsetUtil.UTF_8));
ctx.writeAndFlush(Unpooled.copiedBuffer("abcdefghij", CharsetUtil.UTF_8));
```

**服务器接收（完美拆分）：**

```
第1条消息: [1234567890]
第2条消息: [ABCDEFGHIJ]
第3条消息: [abcdefghij]
```

**优缺点：**

| 优点 | 缺点 |
|------|------|
| ✅ 简单 | ❌ 浪费空间（不足长度需填充） |
| ✅ 可靠 | ❌ 不灵活（长度固定） |

## 4. 分隔符解码器

### 4.1 LineBasedFrameDecoder

使用换行符（\n或\r\n）作为分隔符。

```java
/**
 * 换行符解码器示例
 */
public class LineBasedExample {
    
    public static void main(String[] args) throws Exception {
        EventLoopGroup bossGroup = new NioEventLoopGroup(1);
        EventLoopGroup workerGroup = new NioEventLoopGroup();
        
        try {
            ServerBootstrap b = new ServerBootstrap();
            b.group(bossGroup, workerGroup)
             .channel(NioServerSocketChannel.class)
             .childHandler(new ChannelInitializer<SocketChannel>() {
                 @Override
                 protected void initChannel(SocketChannel ch) {
                     ch.pipeline()
                       // 换行符解码器：最大1024字节
                       .addLast(new LineBasedFrameDecoder(1024))
                       .addLast(new StringDecoder(CharsetUtil.UTF_8))
                       .addLast(new StringEncoder(CharsetUtil.UTF_8))
                       .addLast(new ServerHandler());
                 }
             });
            
            ChannelFuture f = b.bind(8080).sync();
            System.out.println("服务器启动（换行符分隔）");
            f.channel().closeFuture().sync();
        } finally {
            bossGroup.shutdownGracefully();
            workerGroup.shutdownGracefully();
        }
    }
    
    static class ServerHandler extends SimpleChannelInboundHandler<String> {
        private int count = 0;
        
        @Override
        protected void channelRead0(ChannelHandlerContext ctx, String msg) {
            System.out.println("第" + (++count) + "条消息: [" + msg + "]");
            
            // 回复
            ctx.writeAndFlush("服务器收到: " + msg + "\n");
        }
    }
}
```

**客户端发送（注意末尾的\n）：**

```java
ctx.writeAndFlush(Unpooled.copiedBuffer("Hello\n", CharsetUtil.UTF_8));
ctx.writeAndFlush(Unpooled.copiedBuffer("World\n", CharsetUtil.UTF_8));
ctx.writeAndFlush(Unpooled.copiedBuffer("Netty\n", CharsetUtil.UTF_8));
```

**服务器接收（自动去除\n）：**

```
第1条消息: [Hello]
第2条消息: [World]
第3条消息: [Netty]
```

## 5. 长度字段解码器

### 5.1 LengthFieldBasedFrameDecoder

这是最常用也最灵活的解码器！

**协议格式：**

```
+--------+----------+
| Length |  Data    |
| 4字节  |  N字节   |
+--------+----------+
```

**参数说明：**

```java
public LengthFieldBasedFrameDecoder(
    int maxFrameLength,        // 最大帧长度
    int lengthFieldOffset,     // 长度字段偏移量
    int lengthFieldLength,     // 长度字段字节数
    int lengthAdjustment,      // 长度调整值
    int initialBytesToStrip    // 跳过的字节数
)
```

### 5.2 基本使用

```java
/**
 * 长度字段解码器示例
 */
public class LengthFieldExample {
    
    public static void main(String[] args) throws Exception {
        EventLoopGroup bossGroup = new NioEventLoopGroup(1);
        EventLoopGroup workerGroup = new NioEventLoopGroup();
        
        try {
            ServerBootstrap b = new ServerBootstrap();
            b.group(bossGroup, workerGroup)
             .channel(NioServerSocketChannel.class)
             .childHandler(new ChannelInitializer<SocketChannel>() {
                 @Override
                 protected void initChannel(SocketChannel ch) {
                     ch.pipeline()
                       /**
                        * maxFrameLength: 1024 - 最大帧长度
                        * lengthFieldOffset: 0 - 长度字段从第0字节开始
                        * lengthFieldLength: 4 - 长度字段占4字节
                        * lengthAdjustment: 0 - 长度值不需要调整
                        * initialBytesToStrip: 4 - 解码后跳过前4字节（长度字段）
                        */
                       .addLast(new LengthFieldBasedFrameDecoder(
                           1024, 0, 4, 0, 4))
                       .addLast(new StringDecoder(CharsetUtil.UTF_8))
                       .addLast(new ServerHandler());
                 }
             });
            
            ChannelFuture f = b.bind(8080).sync();
            System.out.println("服务器启动（长度字段解码）");
            f.channel().closeFuture().sync();
        } finally {
            bossGroup.shutdownGracefully();
            workerGroup.shutdownGracefully();
        }
    }
    
    static class ServerHandler extends SimpleChannelInboundHandler<String> {
        @Override
        protected void channelRead0(ChannelHandlerContext ctx, String msg) {
            System.out.println("收到消息: [" + msg + "], 长度: " + msg.length());
        }
    }
}
```

**客户端编码：**

```java
public class LengthFieldEncoder extends MessageToByteEncoder<String> {
    
    @Override
    protected void encode(ChannelHandlerContext ctx, String msg, ByteBuf out) {
        byte[] data = msg.getBytes(CharsetUtil.UTF_8);
        int length = data.length;
        
        // 写入长度
        out.writeInt(length);
        // 写入数据
        out.writeBytes(data);
        
        System.out.println("编码: 长度=" + length + ", 数据=" + msg);
    }
}
```

**客户端发送：**

```java

ctx.writeAndFlush("World!");  // 发送: 00 00 00 06 57 6F 72 6C 64 21
```

### 5.3 复杂协议示例

**协议格式：**

```
+------+--------+------+----------+
| Magic| Length | Type |  Data    |
| 4B   |  4B    | 1B   |  NB      |
+------+--------+------+----------+
```

**解码器配置：**

```java
// lengthFieldOffset = 4    (长度字段从第4字节开始，跳过Magic)
// lengthFieldLength = 4    (长度字段占4字节)
// lengthAdjustment = 1     (长度值后面还有1字节Type)
// initialBytesToStrip = 0  (不跳过任何字节，完整保留)

new LengthFieldBasedFrameDecoder(1024, 4, 4, 1, 0)
```

**完整实现：**

```java
/**
 * 自定义协议
 */
public class CustomProtocol {
    
    private static final int MAGIC = 0xCAFEBABE;
    
    /**
     * 编码器
     */
    public static class Encoder extends MessageToByteEncoder<Message> {
        @Override
        protected void encode(ChannelHandlerContext ctx, Message msg, ByteBuf out) {
            byte[] data = msg.getData().getBytes(CharsetUtil.UTF_8);
            
            out.writeInt(MAGIC);           // 魔数
            out.writeInt(data.length);     // 长度
            out.writeByte(msg.getType());  // 类型
            out.writeBytes(data);          // 数据
        }
    }
    
    /**
     * 解码器
     */
    public static class Decoder extends LengthFieldBasedFrameDecoder {
        
        public Decoder() {
            super(1024, 4, 4, 1, 0);
        }
        
        @Override
        protected Object decode(ChannelHandlerContext ctx, ByteBuf in) throws Exception {
            ByteBuf frame = (ByteBuf) super.decode(ctx, in);
            if (frame == null) {
                return null;
            }
            
            try {
                // 读取魔数
                int magic = frame.readInt();
                if (magic != MAGIC) {
                    throw new IllegalArgumentException("无效的魔数: " + magic);
                }
                
                // 读取长度
                int length = frame.readInt();
                
                // 读取类型
                byte type = frame.readByte();
                
                // 读取数据
                byte[] data = new byte[length];
                frame.readBytes(data);
                
                Message message = new Message();
                message.setType(type);
                message.setData(new String(data, CharsetUtil.UTF_8));
                
                return message;
            } finally {
                frame.release();
            }
        }
    }
    
    /**
     * 消息类
     */
    public static class Message {
        private byte type;
        private String data;
        
        // getter和setter
        public byte getType() { return type; }
        public void setType(byte type) { this.type = type; }
        public String getData() { return data; }
        public void setData(String data) { this.data = data; }
        
        @Override
        public String toString() {
            return "Message{type=" + type + ", data='" + data + "'}";
        }
    }
}
```

```java
/**
 * 完整的编解码器示例
 */
public class CodecExample {
    
    public static void main(String[] args) throws Exception {
        EventLoopGroup bossGroup = new NioEventLoopGroup(1);

                       .addLast("serverHandler", new ServerHandler());
                 }
             });
            
            ChannelFuture f = b.bind(8080).sync();
            System.out.println("服务器启动");

            bossGroup.shutdownGracefully();
            workerGroup.shutdownGracefully();
        }
    }

        @Override
        protected void channelRead0(ChannelHandlerContext ctx, String msg) {

        }
    }
}
```

## 7. 自定义编解码器

### 7.1 ByteToMessageDecoder

```java
/**
 * 自定义解码器
 */
public class MyDecoder extends ByteToMessageDecoder {
    
    @Override
    protected void decode(ChannelHandlerContext ctx, ByteBuf in, List<Object> out) {
        // 检查是否有足够的数据
        if (in.readableBytes() < 4) {
            return;  // 不够4字节，等待更多数据
        }
        
        // 标记当前位置
        in.markReaderIndex();
        
        // 读取长度
        int length = in.readInt();
        
        // 检查数据是否完整
        if (in.readableBytes() < length) {
            in.resetReaderIndex();  // 重置，等待更多数据
            return;
        }
        
        // 读取数据
        byte[] data = new byte[length];
        in.readBytes(data);
        
        // 添加到输出列表
        String message = new String(data, CharsetUtil.UTF_8);
        out.add(message);
        
        System.out.println("解码: " + message);
    }
}
```

## 8. 最佳实践

### 8.1 解码器的顺序

```java
// ✅ 正确顺序
pipeline
    .addLast("frameDecoder", new LengthFieldBasedFrameDecoder(...))  // 1. 拆包
    .addLast("stringDecoder", new StringDecoder())                   // 2. 类型转换
    .addLast("businessHandler", new BusinessHandler());              // 3. 业务处理
```

### 8.2 编码器的顺序

```java
// ✅ 正确顺序
pipeline
    .addLast("stringEncoder", new StringEncoder())           // 1. 类型转换
    .addLast("frameEncoder", new LengthFieldPrepender(4))    // 2. 添加长度
    .addLast("businessHandler", new BusinessHandler());      // 3. 业务处理
```

### 8.3 ReplayingDecoder

简化解码逻辑，不需要检查可读字节数。

```java
public class MyReplayingDecoder extends ReplayingDecoder<Void> {
    
    @Override
    protected void decode(ChannelHandlerContext ctx, ByteBuf in, List<Object> out) {
        // 不需要检查readableBytes，ReplayingDecoder会自动处理
        int length = in.readInt();       // 如果不够4字节，会自动等待
        byte[] data = new byte[length];
        in.readBytes(data);              // 如果数据不够，会自动等待
        
        out.add(new String(data, CharsetUtil.UTF_8));
    }
}
```
