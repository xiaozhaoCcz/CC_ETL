支持mysql，oracle数据库之间的同步，后续会支持更多的数据源

**2.测试datax功能**

```python
python ./bin/datax.py ./job/job.json
```

### MYSQL-MYSQL之间的数据同步

**1.首先需要配置cc-job-executor下的application.yml**

- cc-job.executor.jsonpath：这是json存放的临时位置，可以任务指定
- cc-job.pypthon：这里datax.py的存放位置，路径在datax安装包下的bin文件夹中 `datax->bin->datax.py`

```yaml
cc-job:
  job:
    admin:
      ### datax admin address list, such as "http://address" or "http://address01,http://address02"
      #addresses: http://127.0.0.1:8080
      addresses: http://127.0.0.1:8989/xxl-job-admin,http://127.0.0.1:8990/xxl-job-admin
    executor:
      appname: cc-job-executor
      address:
      ip:
      #port: 9999
      port: 12000
      ### job log path
      #logpath: ./data/applogs/executor/jobhandler
      logpath: /Users/zhaowenpeng/logs
      ### job log retention days
      logretentiondays: 30
    ### job, access token
    accessToken: default_token

  executor:
    #jsonpath: D:\\temp\\executor\\json\\
    jsonpath:  /Users/zhaowenpeng/Downloads/datax/

  #pypath: F:\tools\datax\bin\datax.py
  pypath: /Users/zhaowenpeng/Downloads/datax/bin/datax.py
```

### 任务失败重试

模拟任务5运行失败3次后任务运行成功，任务7会等待任务5重试3次后成功则继续运行

- 更改demo5的代码

  ```java
  @XxlJob("demoJobHandler5")
      public void demoJobHandler5() throws Exception {
  
          XxlJobHelper.log(">>>>>>>> demoJobHandler5 start");
  
          for (int i = 0; i < 10; i++) {
              XxlJobHelper.log("demoJobHandler5 beat at:" + i);
              System.out.println("demoJobHandler5 beat at:" + i);
              TimeUnit.SECONDS.sleep(1);
          }
          //default success
          if(count.incrementAndGet()<=3){
              System.out.println(">>>>>>>>count"+count.get());
              throw  new RuntimeException();
          }
          XxlJobHelper.log(">>>>>>>> demoJobHandler5 end");
      }
  ```
