# 🖥️ PC端功能介绍

## 📋 平台介绍

**CcETL** 是一款面向数据开发和自动化运维的可视化任务编排与调度平台。平台支持多种类型的任务节点（如 SQL、Shell、Node.js、Bean 等），通过拖拽、连线等方式，帮助用户快速搭建数据处理流程，实现任务的自动化执行、监控与管理。

🏁 当前pc端还不太稳定，存在一些bug，目前正在修复中🥱😣，一个人工作量太大了😭...

## 🚀 操作步骤详解

### 1. 📝 新建任务组
- 点击左上角"新建"，输入任务组名称，创建新的任务组。

### 2. ➕ 添加任务节点
- 在编排区空白处右键，选择需要的节点类型（如 SQL、Shell、Node.js、Bean）。
- 填写节点名称及相关参数（如 SQL 语句、Shell 脚本、Bean 名称等）。

### 3. 🔗 配置任务流程
- 拖动节点之间的连线，设置任务的执行顺序和依赖关系。
- 支持多入口、多出口、分支、汇聚等复杂流程。

### 4. 💾 保存任务组
- 点击"保存"按钮，保存当前任务组的流程配置。

### 5. ▶️ 运行任务组
- 点击右上角"运行"按钮，平台会按照流程依赖自动执行各个节点任务。
- 运行过程中可实时查看日志。

### 6. 📋 查看与调试日志
- 在下方日志监控区，实时查看每个节点的执行日志，便于调试和排查问题。

### 7. 🔧 其他操作
- 支持任务组的删除、重命名、分区调整等。
- 可通过设置界面配置平台参数。

## 🎯 典型使用场景

### 📊 数据同步与清洗
通过 SQL、Shell、Node.js 节点组合，实现多源数据的同步、清洗与加工。

### 🤖 自动化运维
利用 Shell 节点批量执行服务器脚本，自动化日常运维任务。

### 🏢 复杂业务编排
通过 Bean 节点扩展自定义逻辑，满足企业级复杂业务需求。

### 🔄 多任务依赖调度
支持任务间依赖、分支、并发、汇聚等多种调度模式。

---

## ⚠️ 注意事项

- 🔧 节点参数需根据实际环境正确配置，如数据库连接、脚本路径等。
- 🧪 流程保存后建议及时运行测试，确保各节点配置无误。
- 📝 日志区可帮助快速定位问题，建议关注异常和错误信息。
- 👥 平台支持多用户协作，建议合理规划任务组分区和命名规范。
