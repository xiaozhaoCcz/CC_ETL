# 页面样式优化说明

## 概述
本次优化对 `src/views/main/main.vue` 页面进行了全面的样式改进，使其看起来更加专业化和现代化。

## 主要改进内容

### 1. 设计系统
- **CSS变量系统**: 引入了完整的设计令牌系统，包括颜色、阴影、圆角等
- **现代化配色**: 使用蓝色主题 (#2563eb) 作为主色调
- **字体优化**: 采用系统字体栈，提升可读性

### 2. 视觉层次
- **卡片式设计**: 主要区域使用圆角卡片设计，增加层次感
- **阴影系统**: 三级阴影系统 (sm, md, lg) 增强立体感
- **边框优化**: 使用更细腻的边框颜色和渐变效果

### 3. 交互体验
- **悬停效果**: 所有可交互元素都有平滑的悬停动画
- **微交互**: 添加了图标旋转、弹跳等微动画
- **状态反馈**: 改进的激活状态和运行状态指示器

### 4. 标签页系统
- **现代化标签**: 圆角设计，更好的视觉层次
- **图标支持**: 添加了表情符号图标增强可识别性
- **关闭按钮**: 优化的关闭按钮交互效果

### 5. 日志区域
- **标签页设计**: 现代化的标签页设计，支持滚动
- **空状态优化**: 友好的空状态提示，包含图标和说明
- **运行指示器**: 改进的运行状态指示器动画

### 6. 拖拽分隔线
- **视觉提示**: 更明显的拖拽区域和视觉反馈
- **交互状态**: 悬停和拖拽时的状态变化
- **中心指示器**: 居中的拖拽指示器

### 7. Element Plus 组件优化
- **对话框美化**: 圆角设计，更好的头部和底部样式
- **按钮优化**: 统一的按钮样式和交互效果
- **表单控件**: 优化的输入框、选择器等样式
- **消息提示**: 现代化的消息提示样式

### 8. 响应式设计
- **移动端适配**: 针对小屏幕的优化
- **弹性布局**: 更好的响应式布局

### 9. 可访问性
- **深色模式**: 支持系统深色模式
- **高对比度**: 支持高对比度模式
- **减少动画**: 支持减少动画偏好设置

### 10. 性能优化
- **CSS变量**: 使用CSS变量提升性能
- **硬件加速**: 使用transform和opacity进行动画
- **滚动优化**: 自定义滚动条样式

## 技术特点

### CSS变量系统
```css
:root {
  --primary-color: #2563eb;
  --shadow-md: 0 4px 6px -1px rgb(0 0 0 / 0.1);
  --radius-md: 0.5rem;
  /* ... */
}
```

### 现代化动画
```css
@keyframes bounce {
  0%, 20%, 53%, 80%, 100% { transform: translate3d(0, 0, 0); }
  40%, 43% { transform: translate3d(0, -8px, 0); }
  /* ... */
}
```

### 响应式设计
```css
@media (max-width: 768px) {
  .main-container {
    .platform { margin: 0.5rem; }
    /* ... */
  }
}
```

## 浏览器兼容性
- 现代浏览器 (Chrome 88+, Firefox 85+, Safari 14+)
- 支持CSS变量和现代CSS特性
- 优雅降级到基础样式

## 使用说明
1. 样式已完全集成到现有组件中
2. 无需额外配置，开箱即用
3. 支持主题切换和自定义
4. 响应式设计自动适配不同屏幕
