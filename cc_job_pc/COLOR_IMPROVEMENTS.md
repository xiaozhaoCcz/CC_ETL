# 节点状态颜色优化

## 优化概述

本次优化将节点响应状态的颜色从简单的亮色调整为更加专业化的配色方案，提升了视觉体验和可读性。

## 颜色方案对比

### 优化前
- 失败状态：`#CC0000` (亮红色)
- 成功状态：`#66FF99` (亮绿色)  
- 运行中状态：`#FFFF33` (亮黄色)
- 默认状态：`#000` (黑色)

### 优化后
- 失败状态：`#DC2626` (专业红色 - 更柔和)
- 成功状态：`#059669` (专业绿色 - 更沉稳)
- 运行中状态：`#EA580C` (专业橙色 - 更醒目)
- 等待状态：`#2563EB` (专业蓝色 - 新增)
- 暂停状态：`#6B7280` (专业灰色 - 新增)
- 默认状态：`#374151` (深灰色 - 更专业)

## 技术实现

### 1. 颜色常量管理
- 创建了 `src/utils/colors.ts` 文件统一管理颜色常量
- 定义了 `NODE_STATUS_COLORS` 对象包含所有状态颜色
- 提供了 `getNodeStatusColor()` 函数进行状态到颜色的映射

### 2. 代码优化
- 在 `main.vue` 中导入专业化的颜色配置
- 替换了硬编码的颜色值为常量引用
- 更新了节点状态检测逻辑使用新的颜色值

### 3. 颜色特点
- **失败状态**：使用较柔和的红色，减少视觉冲击
- **成功状态**：使用沉稳的绿色，传达可靠感
- **运行中状态**：使用醒目的橙色，便于快速识别
- **等待状态**：使用专业的蓝色，表示待处理
- **暂停状态**：使用中性的灰色，表示非活跃状态

## 视觉效果提升

1. **专业性**：颜色更加符合企业级应用的视觉标准
2. **可读性**：颜色对比度适中，减少视觉疲劳
3. **一致性**：统一使用颜色常量，确保整个应用的颜色一致性
4. **可维护性**：集中管理颜色配置，便于后续调整

## 使用方式

```typescript
import { getNodeStatusColor, NODE_STATUS_COLORS } from "@/utils/colors.ts";

// 获取状态对应的颜色
const color = getNodeStatusColor(status);

// 直接使用颜色常量
const failedColor = NODE_STATUS_COLORS.FAILED;
```
