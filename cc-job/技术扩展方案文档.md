## 第一部分：现有架构分析

### 1. 系统架构概述

#### 1.1 整体架构描述

Cc-ETL 是一个基于 XXL-Job 深度改造的可视化任务调度平台，采用经典的三层架构设计：

```
┌─────────────────────────────────────────────────────────┐
│                    展示层 (Presentation)                 │
│  ┌─────────────────┐         ┌─────────────────┐       │
│  │  JavaFX GUI客户端 │         │  Web管理界面    │       │
│  │  (cc-job-gui)   │         │  (已移除)       │       │
│  └─────────────────┘         └─────────────────┘       │
└─────────────────────────────────────────────────────────┘
                        ↓ HTTP/WebSocket
┌─────────────────────────────────────────────────────────┐
│                   应用层 (Application)                   │
│  ┌─────────────────────────────────────────────┐        │
│  │        调度管理中心 (cc-job-admin)           │        │
│  │  • 任务注册与管理                            │        │
│  │  • Cron调度触发                              │        │
│  │  • 执行器管理                                │        │
│  │  • 任务监控与日志                            │        │
│  └─────────────────────────────────────────────┘        │
└─────────────────────────────────────────────────────────┘
                        ↓ RPC通信
┌─────────────────────────────────────────────────────────┐
│                   执行层 (Execution)                     │
│  ┌──────────────────┐       ┌──────────────────┐       │
│  │  任务编排执行器   │       │   普通任务执行器  │       │
│  │ (executor-compose)│       │ (executor-sample) │       │
│  │  • 任务组编排     │       │  • BEAN任务      │       │
│  │  • 拓扑排序       │       │  • API任务       │       │
│  │  • 并行执行       │       │  • SQL任务       │       │
│  │  • 依赖管理       │       │  • GLUE脚本      │       │
│  └──────────────────┘       └──────────────────┘       │
└─────────────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────────┐
│                 数据层 (Data Storage)                    │
│  ┌─────────────┐  ┌──────────────┐  ┌──────────────┐  │
│  │   MySQL      │  │  文件日志系统  │  │  外部数据源   │  │
│  │  任务配置    │  │  执行日志      │  │  (DataX集成)  │  │
│  └─────────────┘  └──────────────┘  └──────────────┘  │
└─────────────────────────────────────────────────────────┘
```

#### 1.2 核心组件职责

**cc-job-admin (调度管理中心)**
- 任务注册中心：管理所有任务和任务组的元数据
- 调度中心：基于Cron表达式触发任务执行
- 监控中心：收集和展示任务执行状态、日志、统计信息
- API服务：为GUI客户端提供RESTful接口

**cc-job-executor-compose (任务编排执行器)**
- 核心编排引擎：实现复杂任务流的编排与调度
- 拓扑排序：解析任务依赖关系，构建有向无环图(DAG)
- 并行执行：基于异步框架实现任务并发执行
- 状态管理：跟踪每个节点的执行状态并实时同步

**cc-job-gui (JavaFX客户端)**
- 可视化编排：拖拽式画布支持节点和连线操作
- 实时监控：通过WebSocket接收任务执行状态更新
- 配置管理：提供丰富的任务配置界面
- 日志查看：多标签页日志面板，支持搜索和过滤

**cc-job-xo (数据对象层)**
- 实体定义：JobInfo、JobNode、JobEdge等核心实体
- Mapper接口：MyBatis Plus数据访问层
- DTO/VO对象：数据传输和视图对象

### 2. 核心模块分析

该模块是整个任务编排系统的核心，负责将用户在GUI中设计的任务流转换为实际的执行计划。

### 3. 任务编排执行流程

#### 3.1 完整执行流程图（文字描述）

```
【用户操作】
   ↓
[1] 用户在GUI画布中拖拽节点并连接成任务流
   ↓
[2] 点击保存按钮，将任务组结构保存到数据库
   • 保存JobInfo（任务组信息）
   • 保存JobNode列表（节点信息）
   • 保存JobEdge列表（边信息）
   ↓
[3] 点击运行按钮，GUI调用Admin接口触发任务组
   ↓
【调度中心 - cc-job-admin】
   ↓
[4] Admin接收到运行请求，查找对应的执行器
   • 根据executorHandler找到"任务组编排执行器"
   • 生成执行批次ID
   ↓
[5] Admin通过RPC调用执行器的runJobGroupXxlJob方法
   ↓
【编排执行器 - cc-job-executor-compose】
   ↓
[6] JobGroupExecutorComplete接收请求
   ↓
[7] 委托给TaskGroupOrchestrator.execute()
   ↓
[8] prepareExecution() - 准备执行
   • 从Admin获取任务组信息
   • 获取所有节点和边
   • 构建任务依赖图（GraphBuilder）
   • 验证无循环依赖
   ↓
[9] buildExecutionPlan() - 构建执行计划
   • 为每个JobNode创建WorkerWrapper
   • 建立WorkerWrapper之间的依赖关系
   • WorkerWrapper封装了实际的任务执行逻辑
   ↓
[10] executeTaskGroup() - 执行任务组
   • 调用异步编排框架 Async.beginWork()
   • 框架根据依赖关系自动调度任务执行
   • 支持并行执行无依赖关系的任务
   ↓
【任务执行阶段】
   ↓
[11] 对于每个WorkerWrapper中的任务节点：
   a. TaskExecutor.executeTask() 被调用
   b. 检查任务暂停状态
   c. 通过JobTriggerService触发实际任务
      • 对于BEAN任务：调用Spring容器中的Bean方法
      • 对于API任务：发起HTTP请求
      • 对于SQL任务：连接数据库执行SQL
      • 对于GLUE任务：动态编译执行脚本代码
   d. 监听任务执行状态
      • 轮询查询任务日志状态
      • 处理成功/失败/超时情况
   e. 根据失败策略决定是否重试
   ↓
[12] 状态同步
   • 每个节点执行状态变化时，更新数据库
   • 通过WebSocket推送状态到GUI客户端
   • GUI实时更新节点颜色（运行中/成功/失败）
   ↓
[13] 任务组执行完成
   • 收集所有节点的执行结果
   • 生成执行报告
   • 回调Admin报告执行结果
   ↓
【结果展示】
   ↓
[14] GUI日志面板显示完整执行日志
[15] 节点状态指示器显示最终状态
```

#### 3.2 关键代码流程分析

**步骤8：准备执行上下文**

```java
/**
 * 准备执行上下文
 * 
 * 职责：
 * 1. 从Admin获取任务组、节点、边信息
 * 2. 构建任务依赖图
 * 3. 验证图的有效性（无环检测）
 */
private ExecutionContext prepareExecution(Long taskGroupId, String executionBatchId) {
    logger.debug("[Orchestrator] 准备执行上下文 - taskGroupId: {}", taskGroupId);
    
    // 获取任务组信息
    JobInfo taskGroupInfo = adminApiClient.getJobInfo(taskGroupId);
    if (taskGroupInfo == null) {
        throw new RuntimeException("获取任务组信息失败");
    }
    
    // 获取节点和边
    List<JobNode> nodes = adminApiClient.getJobNodes(taskGroupId);
    List<JobEdge> edges = adminApiClient.getJobEdges(taskGroupId);
    
    if (nodes.isEmpty()) {
        logger.warn("[Orchestrator] 任务组没有节点 - taskGroupId: {}", taskGroupId);
        XxlJobHelper.handleSuccess("任务组没有节点，跳过执行");
        throw new RuntimeException("任务组没有节点");
    }
    
    logger.info("[Orchestrator] 获取到 {} 个节点，{} 条边", nodes.size(), edges.size());
    
    // 构建任务图（内部会进行拓扑排序和环检测）
    graphBuilder.buildGraph(taskGroupId, nodes, edges);
    
    // 保存XXL-Job上下文到ThreadLocal
    XxlJobContext xxlJobContext = XxlJobContext.getXxlJobContext();
    CONTEXT_HOLDER.set(xxlJobContext);
    
    // 构建执行上下文对象
    return ExecutionContext.builder()
            .taskGroupId(taskGroupId)
            .executionBatchId(executionBatchId)
            .taskGroupInfo(taskGroupInfo)
            .nodes(nodes)
            .edges(edges)
            .xxlJobContext(xxlJobContext)
            .executeKey(buildExecuteKey(taskGroupId, executionBatchId))
            .build();
}
```

**步骤9：构建执行计划**

```java
/**
 * 构建执行计划
 * 
 * 职责：
 * 1. 为每个JobNode创建对应的WorkerWrapper
 * 2. 建立WorkerWrapper之间的依赖关系
 * 3. 将执行计划存入缓存供后续查询
 */
private List<WorkerWrapper<Long, String>> buildExecutionPlan(ExecutionContext context) {
    logger.debug("[Orchestrator] 构建执行计划");
    
    // 创建WorkerWrapper列表
    // WorkerWrapper是异步编排框架中的工作单元
    // 每个Wrapper封装了一个任务节点的执行逻辑
    List<WorkerWrapper<Long, String>> workerWrappers = 
            wrapperFactory.createWorkerWrappers(context);
    
    if (workerWrappers.isEmpty()) {
        throw new RuntimeException("没有可执行的任务");
    }
    
    // 根据JobEdge建立WorkerWrapper之间的依赖关系
    // 例如：如果边E1指向节点N2，则N2对应的Wrapper需要依赖N1对应的Wrapper
    dependencyBuilder.buildDependencies(workerWrappers, context.getNodes(), context.getEdges());
    
    // 保存到运行中的任务映射（用于停止、查询状态等操作）
    RUNNING_JOBS.put(context.getExecuteKey(), workerWrappers);
    
    // 保存执行上下文（用于任务完成后收集节点状态）
    CONTEXT_MAP.put(context.getExecuteKey(), context);
    
    return workerWrappers;
}
```

**步骤11：执行单个任务节点**

```java
/**
 * 执行单个任务
 * 
 * 职责：
 * 1. 检查任务暂停状态
 * 2. 触发任务执行
 * 3. 监听执行状态直到完成
 * 4. 处理重试逻辑
 * 
 * @param context 执行上下文
 * @param node 任务节点
 * @param jobInfo 任务信息
 * @param retryCount 当前重试次数
 * @param jobResults 结果映射（用于记录所有节点的执行结果）
 * @return 执行结果描述
 */
public String executeTask(ExecutionContext context, JobNode node, JobInfo jobInfo, 
                         int retryCount, Map<String, Boolean> jobResults) {
    logger.info("[TaskExecutor] 开始执行任务 - jobId: {}, nodeId: {}, 重试次数: {}",
            jobInfo.getId(), node.getId(), retryCount);
    
    try {
        // 1. 检查并处理暂停状态
        // 如果任务被标记为暂停，则跳过执行
        handlePauseIfNeeded(jobInfo);
        
        // 2. 触发任务执行
        // 这里会根据任务类型（BEAN/API/SQL等）调用相应的执行器
        boolean triggerSuccess = jobTriggerService.triggerJob(
                context.getXxlJobContext(), jobInfo, context.getExecutionBatchId());
        
        if (!triggerSuccess) {
            return handleTriggerFailure(jobInfo);
        }
        
        // 3. 监听任务执行状态
        // 通过轮询方式查询任务日志，直到任务完成
        return monitorExecution(context, node, jobInfo, retryCount, jobResults);
        
    } catch (Exception e) {
        return handleExecutionError(context, node, jobInfo, e);
    }
}
```

### 4. 数据模型设计

#### 4.1 核心实体关系

```
┌─────────────────┐
│    JobPart      │  任务分区（用于组织管理）
│ ─────────────── │
│ • id            │
│ • partName      │
│ • description   │
└────────┬────────┘
         │ 1
         │
         │ N
┌────────┴────────┐
│   JobCompose    │  任务组（可包含多个任务节点）
│ ─────────────── │
│ • id            │
│ • composeName   │
│ • partId        │ ──> 外键指向JobPart
└────────┬────────┘
         │ 1
         │
         ├─────────────────┬─────────────────┐
         │ N               │ N               │ N
┌────────┴────────┐ ┌─────┴──────┐ ┌────────┴────────┐
│    JobNode      │ │  JobEdge   │ │    JobInfo      │
│ ─────────────── │ │ ──────────  │ │ ─────────────── │
│ • id            │ │ • id        │ │ • id            │
│ • jobId         │ │ • fromNodeId│ │ • jobDesc       │
│ • jobParentId   │ │ • endNodeId │ │ • glueType      │
│ • nodePositionX │ │ • jobParentId│ │ • executorHandler│
│ • nodePositionY │ │ • pointsList│ │ • executorParam │
│ • nodeType      │ │ • properties│ │ • executorTimeout│
│ • triggerStatus │ └────────────┘ │ • triggerStatus │
│ • properties    │                │ • jobType       │
└─────────────────┘                └─────────────────┘
       ↑                                    ↑
       │ N                                  │ 1
       │                                    │
       └────────────────────────────────────┘
         jobId 外键关系
```

**实体说明：**

1. **JobPart（任务分区）**
   - 最顶层的组织单位
   - 用于按业务或部门划分任务
   
2. **JobCompose（任务组）**
   - 一个可视化的任务编排单元
   - 包含多个JobNode和JobEdge
   - 本身也是一个JobInfo（jobType=2）

3. **JobNode（任务节点）**
   - 任务组中的一个节点
   - 通过jobId关联到实际的JobInfo
   - 存储节点在画布上的位置信息
   - nodeType字段用于区分普通节点和条件节点

4. **JobEdge（任务边）**
   - 表示节点之间的依赖关系
   - fromNodeId → endNodeId 表示执行顺序
   - pointsList存储连线的路径点（用于GUI渲染）

5. **JobInfo（任务信息）**
   - 实际的任务配置
   - glueType: BEAN/API/SQL/GLUE(Java)/GLUE(Shell)等
   - executorHandler: 执行器标识
   - jobType: 0-普通任务, 2-任务组

#### 4.2 JobNode 实体详解

```java
@TableName("job_node")
public class JobNode extends BaseEntity {
    
    /**
     * 关联的任务ID
     * 外键指向job_info表
     */
    private Long jobId;
    
    /**
     * 父任务组ID
     * 外键指向job_compose表的id（也是job_info的id）
     */
    private Long jobParentId;
    
    /**
     * 节点在画布上的X坐标
     * 用于GUI渲染节点位置
     */
    private Double nodePositionX;
    
    /**
     * 节点在画布上的Y坐标
     */
    private Double nodePositionY;
    
    /**
     * 节点入度（有多少条边指向该节点）
     * 用于拓扑排序
     */
    private Long nodeInDegree;
    
    /**
     * 节点出度（有多少条边从该节点出发）
     */
    private Long nodeOutDegree;
    
    /**
     * 排序字段
     */
    private Integer sort;
    
    /**
     * 子节点列表（JSON格式）
     * 【扩展用途】：未来用于存储条件节点的子节点ID列表
     * 例如：if节点包含then分支和else分支的子节点
     */
    private String children;
    
    /**
     * 节点属性（JSON格式）
     * 【扩展用途】：存储节点特定的配置
     * 例如：条件表达式、循环变量、循环次数等
     */
    private String properties;
    
    /**
     * 节点类型
     * 当前值：null 或 "task"（普通任务节点）
     * 【扩展值】：
     *   - "if-else": 条件分支节点
     *   - "while": 循环节点
     *   - "foreach": 遍历节点
     *   - "parallel": 并行分组节点
     *   - "sequential": 串行分组节点
     */
    private String nodeType;
    
    /**
     * 节点运行状态
```

### 功能一：条件控制节点

#### 5.1 功能概述

条件控制节点是对现有线性任务流的重要扩展，允许任务流根据运行时条件动态选择执行路径，支持分支、循环等复杂流程控制。

**核心价值：**
- 提升任务编排的灵活性，支持复杂业务逻辑
- 减少冗余任务配置，通过条件判断实现一个任务组适配多种场景
- 增强任务流的可读性和可维护性

**支持的节点类型：**

| 节点类型 | 描述 | 使用场景 |
|---------|------|---------|
| **if-else** | 条件分支 | 根据条件执行不同的任务分支 |
| **while** | 条件循环 | 重复执行任务直到条件不满足 |
| **foreach** | 集合遍历 | 对集合中每个元素执行相同任务 |
| **switch-case** | 多分支选择 | 根据变量值选择不同分支 |

```java
/**
 * if-else节点执行器
 */
@Component("ifElseNodeExecutor")
public class IfElseNodeExecutor implements ConditionalNodeExecutor {
    
    @Autowired
    private ExpressionEvaluator expressionEvaluator;
    
    @Autowired
    private DataContextManager contextManager;
    
    @Override
    public ExecutionResult execute(JobNode node, ExecutionContext context) {
        // 1. 解析节点配置
        IfElseNodeConfig config = JSON.parseObject(
            node.getProperties(), IfElseNodeConfig.class);
        
        // 2. 获取数据上下文
        DataContext dataContext = contextManager.getContext(
            context.getExecutionBatchId());
        
        // 3. 计算条件表达式
        boolean conditionResult;
        try {
            conditionResult = expressionEvaluator.evaluateBoolean(
                config.getCondition(), 
                dataContext, 
                config.getEvaluationTimeout()
            );
            
            logger.info("[IfElse-节点{}] 条件: {}, 结果: {}", 
                node.getId(), config.getCondition(), conditionResult);
                
        } catch (Exception e) {
            // 处理表达式计算失败
            return handleEvaluationFailure(config, e);
        }
        
        // 4. 选择执行分支
        List<Long> branchNodes = conditionResult 
            ? config.getThenBranchNodeIds()
            : config.getElseBranchNodeIds();
            
        if (branchNodes == null || branchNodes.isEmpty()) {
            logger.info("[IfElse-节点{}] 选中分支为空，跳过执行", node.getId());
            return ExecutionResult.success("分支为空");
        }
        
        // 5. 执行分支
        logger.info("[IfElse-节点{}] 执行{}分支，节点数: {}", 
            node.getId(), 
            conditionResult ? "THEN" : "ELSE", 
            branchNodes.size());
            
        return executeBranch(branchNodes, context);
    }
    
    /**
     * 执行分支节点
     */
    private ExecutionResult executeBranch(List<Long> nodeIds, 
                                          ExecutionContext context) {
        // 加载分支节点
        List<JobNode> branchNodeList = jobNodeService.listByIds(nodeIds);
        
        // 构建WorkerWrapper
        List<WorkerWrapper<Long, String>> wrappers = 
            wrapperFactory.createWorkersForBranch(
                branchNodeList, context);
        
        // 执行分支任务组
        try {
            Async.beginWork(
                context.getTaskGroupInfo().getExecutorTimeout(), 
                wrappers);
            return ExecutionResult.success("分支执行成功");
        } catch (Exception e) {
            return ExecutionResult.failure("分支执行失败: " + e.getMessage());
        }
    }
    
    @Override
    public String getNodeType() {
        return "if-else";
    }
}
```

**执行流程：**

```java
/**
 * while循环节点执行器
 */
@Component("whileNodeExecutor")
public class WhileNodeExecutor implements ConditionalNodeExecutor {
    
    @Override
    public ExecutionResult execute(JobNode node, ExecutionContext context) {
        WhileNodeConfig config = parseConfig(node.getProperties());
        DataContext dataContext = contextManager.getContext(
            context.getExecutionBatchId());
        
        int iterationCount = 0;
        boolean shouldContinue = true;
        List<String> iterationResults = new ArrayList<>();
        
        // 初始化循环变量
        dataContext.put(config.getLoopVariableName(), 0);
        
        logger.info("[While-节点{}] 开始循环，最大次数: {}", 
            node.getId(), config.getMaxIterations());
        
        // 循环主体
        while (shouldContinue && iterationCount < config.getMaxIterations()) {
            iterationCount++;
            dataContext.put(config.getLoopVariableName(), iterationCount);
            
            logger.info("[While-节点{}] 第 {} 次循环", node.getId(), iterationCount);
            
            // BEFORE模式：先检查条件
            if ("BEFORE".equals(config.getConditionCheckTiming())) {
                shouldContinue = evaluateCondition(
                    config.getCondition(), dataContext);
                    
                if (!shouldContinue) {
                    logger.info("[While-节点{}] 条件不满足，退出循环", node.getId());
                    break;
                }
            }
            
            // 执行循环体
            ExecutionResult loopResult = executeLoopBody(
                config.getLoopBodyNodeIds(), context);
            iterationResults.add(loopResult.getMessage());
            
            if (!loopResult.isSuccess()) {
                logger.error("[While-节点{}] 循环体执行失败: {}", 
                    node.getId(), loopResult.getMessage());
                return ExecutionResult.failure(
                    String.format("第%d次循环失败: %s", 
                        iterationCount, loopResult.getMessage()));
            }
            
            // AFTER模式：后检查条件
            if ("AFTER".equals(config.getConditionCheckTiming())) {
                shouldContinue = evaluateCondition(
                    config.getCondition(), dataContext);
            }
            
            // 循环间隔
            if (config.getIntervalMs() > 0) {
                Thread.sleep(config.getIntervalMs());
            }
        }
        
        // 检查是否达到最大次数
        if (iterationCount >= config.getMaxIterations()) {
            logger.warn("[While-节点{}] 达到最大循环次数: {}", 
                node.getId(), config.getMaxIterations());
        }
        
        logger.info("[While-节点{}] 循环结束，共执行 {} 次", 
            node.getId(), iterationCount);
            
        return ExecutionResult.success(
            String.format("循环完成，迭代%d次", iterationCount));
    }
    
    @Override
    public String getNodeType() {
        return "while";
    }
}
```

**执行流程：**

```java
/**
 * foreach遍历节点执行器
 */
@Component("foreachNodeExecutor")
public class ForeachNodeExecutor implements ConditionalNodeExecutor {
    
    @Override
    public ExecutionResult execute(JobNode node, ExecutionContext context) {
        ForeachNodeConfig config = parseConfig(node.getProperties());
        DataContext dataContext = contextManager.getContext(
            context.getExecutionBatchId());
        
        // 1. 解析集合表达式
        List<?> collection = evaluateCollection(
            config.getCollectionExpression(), dataContext);
        
        // 2. 验证集合
        if (collection == null || collection.isEmpty()) {
            logger.warn("[Foreach-节点{}] 集合为空", node.getId());
            return ExecutionResult.success("集合为空，跳过遍历");
        }
        
        if (collection.size() > config.getMaxItems()) {
            return ExecutionResult.failure(
                String.format("集合大小 %d 超过最大限制 %d", 
                    collection.size(), config.getMaxItems()));
        }
        
        logger.info("[Foreach-节点{}] 开始遍历，元素数: {}, 模式: {}", 
            node.getId(), collection.size(), config.getExecutionMode());
        
        // 3. 根据执行模式选择遍历方式
        if ("SEQUENTIAL".equals(config.getExecutionMode())) {
            return executeSequential(collection, config, context, dataContext);
        } else {
            return executeParallel(collection, config, context, dataContext);
        }
    }
    
    /**
     * 串行执行
     */
    private ExecutionResult executeSequential(List<?> collection, 
                                              ForeachNodeConfig config,
                                              ExecutionContext context,
                                              DataContext dataContext) {
        int successCount = 0;
        int failureCount = 0;
        Map<Integer, String> failureMessages = new HashMap<>();
        
        for (int i = 0; i < collection.size(); i++) {
            Object item = collection.get(i);
            
            // 设置当前元素和索引到上下文
            dataContext.put(config.getItemVariableName(), item);
            dataContext.put(config.getIndexVariableName(), i);
            
            logger.info("[Foreach-节点{}] 处理元素 {}/{}", 
                node.getId(), i + 1, collection.size());
            
            // 执行循环体
            ExecutionResult result = executeLoopBody(
                config.getLoopBodyNodeIds(), context);
            
            if (result.isSuccess()) {
                successCount++;
            } else {
                failureCount++;
                failureMessages.put(i, result.getMessage());
                
                logger.error("[Foreach-节点{}] 元素 {} 执行失败: {}", 
                    node.getId(), i, result.getMessage());
                
                // 根据失败策略处理
                if ("FAIL_FAST".equals(config.getFailureStrategy())) {
                    return ExecutionResult.failure(
                        String.format("元素%d执行失败: %s", i, result.getMessage()));
                }
                // CONTINUE模式继续执行下一个元素
            }
        }
        
        // 返回汇总结果
        String resultMsg = String.format(
            "遍历完成，总数:%d，成功:%d，失败:%d", 
            collection.size(), successCount, failureCount);
        logger.info("[Foreach-节点{}] {}", node.getId(), resultMsg);
        
        // 将结果存入上下文供后续节点使用
        dataContext.put("foreachResult", Map.of(
            "total", collection.size(),
            "success", successCount,
            "failure", failureCount,
            "failureMessages", failureMessages
        ));
        
        return failureCount == 0 
            ? ExecutionResult.success(resultMsg)
            : ExecutionResult.partialSuccess(resultMsg);
    }
    
    /**
     * 并行执行
     */
    private ExecutionResult executeParallel(List<?> collection, 
                                           ForeachNodeConfig config,
                                           ExecutionContext context,
                                           DataContext dataContext) {
        // 创建线程池
        ExecutorService executor = Executors.newFixedThreadPool(
            config.getParallelism(),
            new ThreadFactoryBuilder()
                .setNameFormat("foreach-worker-%d")
                .build()
        );
        
        List<Future<ExecutionResult>> futures = new ArrayList<>();
        AtomicInteger successCount = new AtomicInteger(0);
        AtomicInteger failureCount = new AtomicInteger(0);
        
        // 提交所有任务
        for (int i = 0; i < collection.size(); i++) {
            final int index = i;
            final Object item = collection.get(i);
            
            Future<ExecutionResult> future = executor.submit(() -> {
                // 为每个线程创建独立的数据上下文
                DataContext threadContext = dataContext.createChildContext();
                threadContext.put(config.getItemVariableName(), item);
                threadContext.put(config.getIndexVariableName(), index);
                
                logger.info("[Foreach-节点{}] 并行处理元素 {}", 
                    node.getId(), index);
                
                try {
                    ExecutionResult result = executeLoopBody(
                        config.getLoopBodyNodeIds(), context);
                    
                    if (result.isSuccess()) {
                        successCount.incrementAndGet();
                    } else {
                        failureCount.incrementAndGet();
                    }
                    
                    return result;
                } catch (Exception e) {
                    failureCount.incrementAndGet();
                    return ExecutionResult.failure("元素执行异常: " + e.getMessage());
                }
            });
            
            futures.add(future);
        }
        
        // 等待所有任务完成（带超时）
        int timeout = context.getTaskGroupInfo().getExecutorTimeout();
        for (int i = 0; i < futures.size(); i++) {
            try {
                futures.get(i).get(timeout, TimeUnit.SECONDS);
            } catch (TimeoutException e) {
                logger.error("[Foreach-节点{}] 元素 {} 执行超时", node.getId(), i);
                failureCount.incrementAndGet();
            } catch (Exception e) {
                logger.error("[Foreach-节点{}] 元素 {} 执行异常", node.getId(), i, e);
                failureCount.incrementAndGet();
            }
        }
        
        executor.shutdown();
        
        String resultMsg = String.format(
            "并行遍历完成，总数:%d，成功:%d，失败:%d", 
            collection.size(), successCount.get(), failureCount.get());
        logger.info("[Foreach-节点{}] {}", node.getId(), resultMsg);
        
        return failureCount.get() == 0 
            ? ExecutionResult.success(resultMsg)
            : ExecutionResult.partialSuccess(resultMsg);
    }
    
    @Override
    public String getNodeType() {
        return "foreach";
    }
}
```

### 功能二：通用节点间参数传递机制

#### 6.1 功能概述

参数传递机制是任务编排系统的核心基础设施，允许节点之间共享数据和传递执行结果。一个强大的参数传递机制能够：

- 支持任意类型的数据传递（基本类型、对象、集合）
- 实现跨节点的数据共享和访问
- 支持多个上游节点结果的合并
- 提供灵活的表达式语法访问数据

**应用场景：**

1. **数据查询与处理链**：查询节点 → 数据处理节点 → 结果入库节点
2. **条件判断**：数据采集节点 → if节点（根据采集结果判断）→ 不同处理分支
3. **循环处理**：分页查询节点 → foreach节点（遍历每条记录）→ 处理节点
4. **结果聚合**：多个并行查询节点 → 汇总节点（合并所有查询结果）

##### 6.2.1 DataContext 核心类

```java
package com.cc.job.executor.compose.core.context;

import java.util.*;
import java.util.concurrent.ConcurrentHashMap;

/**
 * 数据上下文 - 任务组执行期间的数据共享容器
 * 
 * 特性：
 * 1. 线程安全：使用ConcurrentHashMap保证并发访问安全
 * 2. 层次结构：支持父子上下文，子上下文可以访问父上下文的数据
 * 3. 类型转换：提供类型安全的数据访问方法
 * 4. 作用域隔离：foreach等场景可以创建子上下文，避免数据污染
 * 
 * @author cc-job-team
 */
public class DataContext {
    
    /** 执行批次ID，唯一标识一次任务组执行 */
    private final String executionBatchId;
    
    /** 数据存储 - 键值对形式 */
    private final Map<String, Object> data = new ConcurrentHashMap<>();
    
    /** 父上下文（支持上下文嵌套） */
    private final DataContext parentContext;
    
    /** 元数据：记录每个数据项的来源节点ID */
    private final Map<String, Long> dataSourceMap = new ConcurrentHashMap<>();
    
    /** 元数据：记录每个数据项的创建时间 */
    private final Map<String, Long> dataTimestampMap = new ConcurrentHashMap<>();
    
    /**
     * 构造根上下文
     */
    public DataContext(String executionBatchId) {
        this.executionBatchId = executionBatchId;
        this.parentContext = null;
    }
    
    /**
     * 构造子上下文
     */
    private DataContext(String executionBatchId, DataContext parent) {
        this.executionBatchId = executionBatchId;
        this.parentContext = parent;
    }
    
    /**
     * 创建子上下文
     * 
     * 使用场景：foreach循环中为每个迭代创建独立的上下文
     */
    public DataContext createChildContext() {
        return new DataContext(this.executionBatchId, this);
    }
    
    /**
     * 存储数据
     * 
     * @param key 数据键
     * @param value 数据值
     * @param sourceNodeId 数据来源节点ID
     */
    public void put(String key, Object value, Long sourceNodeId) {
        data.put(key, value);
        dataSourceMap.put(key, sourceNodeId);
        dataTimestampMap.put(key, System.currentTimeMillis());
    }
    
    /**
     * 存储数据（简化版）
     */
    public void put(String key, Object value) {
        put(key, value, null);
    }
    
    /**
     * 获取数据
     * 
     * 查找顺序：当前上下文 → 父上下文 → 祖父上下文 → ...
     */
    public Object get(String key) {
        // 先在当前上下文查找
        if (data.containsKey(key)) {
            return data.get(key);
        }
        
        // 如果没找到，尝试从父上下文获取
        if (parentContext != null) {
            return parentContext.get(key);
        }
        
        return null;
    }
    
    /**
     * 获取数据（类型安全）
     * 
     * @param key 数据键
     * @param clazz 期望的数据类型
     * @return 类型转换后的数据
     */
    public <T> T get(String key, Class<T> clazz) {
        Object value = get(key);
        if (value == null) {
            return null;
        }
        
        if (clazz.isInstance(value)) {
            return clazz.cast(value);
        }
        
        // 尝试类型转换
        return convertType(value, clazz);
    }
    
    /**
     * 获取字符串类型数据
     */
    public String getString(String key) {
        return get(key, String.class);
    }
    
    /**
     * 获取整数类型数据
     */
    public Integer getInteger(String key) {
        return get(key, Integer.class);
    }
    
    /**
     * 获取布尔类型数据
     */
    public Boolean getBoolean(String key) {
        return get(key, Boolean.class);
    }
    
    /**
     * 获取列表类型数据
     */
    @SuppressWarnings("unchecked")
    public <T> List<T> getList(String key) {
        Object value = get(key);
        if (value instanceof List) {
            return (List<T>) value;
        }
        return null;
    }
    
    /**
     * 获取Map类型数据
     */
    @SuppressWarnings("unchecked")
    public <K, V> Map<K, V> getMap(String key) {
        Object value = get(key);
        if (value instanceof Map) {
            return (Map<K, V>) value;
        }
        return null;
    }
    
    /**
     * 检查是否包含某个键
     */
    public boolean containsKey(String key) {
        if (data.containsKey(key)) {
            return true;
        }
        if (parentContext != null) {
            return parentContext.containsKey(key);
        }
        return false;
    }
    
    /**
     * 移除数据
     */
    public void remove(String key) {
        data.remove(key);
        dataSourceMap.remove(key);
        dataTimestampMap.remove(key);
    }
    
    /**
     * 清空当前上下文（不影响父上下文）
     */
    public void clear() {
        data.clear();
        dataSourceMap.clear();
        dataTimestampMap.clear();
    }
    
    /**
     * 获取所有数据键
     */
    public Set<String> keySet() {
        Set<String> keys = new HashSet<>(data.keySet());
        if (parentContext != null) {
            keys.addAll(parentContext.keySet());
        }
        return keys;
    }
    
    /**
     * 获取所有变量（包括父上下文）
     */
    public Map<String, Object> getAllVariables() {
        Map<String, Object> allData = new HashMap<>();
        
        // 先添加父上下文的数据
        if (parentContext != null) {
            allData.putAll(parentContext.getAllVariables());
        }
        
        // 再添加当前上下文的数据（会覆盖父上下文的同名键）
        allData.putAll(data);
        
        return allData;
    }
    
    /**
     * 获取数据来源节点ID
     */
    public Long getDataSource(String key) {
        if (dataSourceMap.containsKey(key)) {
            return dataSourceMap.get(key);
        }
        if (parentContext != null) {
            return parentContext.getDataSource(key);
        }
        return null;
    }
    
    /**
     * 类型转换工具
     */
    @SuppressWarnings("unchecked")
    private <T> T convertType(Object value, Class<T> targetType) {
        if (value == null) {
            return null;
        }
        
        // String类型转换
        if (targetType == String.class) {
            return (T) value.toString();
        }
        
        // 数值类型转换
        if (targetType == Integer.class || targetType == int.class) {
            if (value instanceof Number) {
                return (T) Integer.valueOf(((Number) value).intValue());
            }
            return (T) Integer.valueOf(value.toString());
        }
        
        if (targetType == Long.class || targetType == long.class) {
            if (value instanceof Number) {
                return (T) Long.valueOf(((Number) value).longValue());
            }
            return (T) Long.valueOf(value.toString());
        }
        
        if (targetType == Double.class || targetType == double.class) {
            if (value instanceof Number) {
                return (T) Double.valueOf(((Number) value).doubleValue());
            }
            return (T) Double.valueOf(value.toString());
        }
        
        // 布尔类型转换
        if (targetType == Boolean.class || targetType == boolean.class) {
            if (value instanceof Boolean) {
                return (T) value;
            }
            return (T) Boolean.valueOf(value.toString());
        }
        
        throw new ClassCastException(
            String.format("无法将 %s 转换为 %s", 
                value.getClass().getName(), targetType.getName()));
    }
    
    @Override
    public String toString() {
        return String.format("DataContext[batchId=%s, size=%d, parent=%s]",
            executionBatchId, data.size(), parentContext != null ? "yes" : "no");
    }
}
```

```java
package com.cc.job.executor.compose.core.context;

import org.springframework.stereotype.Component;
import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;

/**
 * 数据上下文管理器
 * 
 * 职责：
 * 1. 管理所有任务组执行的数据上下文
 * 2. 提供上下文的创建、获取、销毁接口
 * 3. 自动清理过期的上下文（防止内存泄漏）
 * 
 * @author cc-job-team
 */
@Component
public class DataContextManager {
    
    /** 所有活跃的数据上下文 */
    private final Map<String, DataContext> contextMap = new ConcurrentHashMap<>();
    
    /** 上下文创建时间记录 */
    private final Map<String, Long> contextCreateTimeMap = new ConcurrentHashMap<>();
    
    /** 上下文最大存活时间（毫秒），默认24小时 */
    private static final long MAX_CONTEXT_AGE_MS = 24 * 60 * 60 * 1000;
    
    /**
     * 创建数据上下文
     */
    public DataContext createContext(String executionBatchId) {
        DataContext context = new DataContext(executionBatchId);
        contextMap.put(executionBatchId, context);
        contextCreateTimeMap.put(executionBatchId, System.currentTimeMillis());
        
        logger.info("[DataContext] 创建上下文: {}", executionBatchId);
        return context;
    }
    
    /**
     * 获取数据上下文
     */
    public DataContext getContext(String executionBatchId) {
        DataContext context = contextMap.get(executionBatchId);
        if (context == null) {
            // 如果上下文不存在，自动创建
            context = createContext(executionBatchId);
        }
        return context;
    }
    
    /**
     * 销毁数据上下文
     */
    public void destroyContext(String executionBatchId) {
        DataContext context = contextMap.remove(executionBatchId);
        contextCreateTimeMap.remove(executionBatchId);
        
        if (context != null) {
            context.clear();
            logger.info("[DataContext] 销毁上下文: {}", executionBatchId);
        }
    }
    
    /**
     * 清理过期的上下文
     * 
     * 通过定时任务定期调用
     */
    @Scheduled(fixedDelay = 3600000) // 每小时执行一次
    public void cleanupExpiredContexts() {
        long now = System.currentTimeMillis();
        int cleanupCount = 0;
        
        for (Map.Entry<String, Long> entry : contextCreateTimeMap.entrySet()) {
            long age = now - entry.getValue();
            if (age > MAX_CONTEXT_AGE_MS) {
                String batchId = entry.getKey();
                destroyContext(batchId);
                cleanupCount++;
            }
        }
        
        if (cleanupCount > 0) {
            logger.info("[DataContext] 清理 {} 个过期上下文", cleanupCount);
        }
    }
    
    /**
     * 获取所有活跃的上下文数量
     */
    public int getActiveContextCount() {
        return contextMap.size();
    }
}
```

```java
package com.cc.job.executor.compose.core.model;

import java.util.HashMap;
import java.util.Map;

/**
 * 执行结果对象
 * 
 * 封装节点执行的结果数据，包括：
 * - 执行状态（成功/失败/部分成功）
 * - 结果数据（可以是任意类型）

 */
public class ExecutionResult {
    
    /** 执行状态 */
    private ResultStatus status;
    
    /** 结果数据 */
    private Object data;
    
    /** 错误消息 */
    private String message;
    
    /** 元数据（额外信息） */
    private Map<String, Object> metadata = new HashMap<>();
    
    /** 执行耗时（毫秒） */
    private Long executionTime;
    
    public enum ResultStatus {
        SUCCESS,         // 成功
        FAILURE,         // 失败
        PARTIAL_SUCCESS, // 部分成功（如foreach中部分元素成功）
        SKIPPED          // 跳过（如条件不满足）
    }
    
    // 构造函数
    private ExecutionResult(ResultStatus status, Object data, String message) {
        this.status = status;
        this.data = data;
        this.message = message;
    }
```

```java
public class TaskExecutor {
    
    @Autowired
    private DataContextManager contextManager;
    
    public String executeTask(ExecutionContext context, JobNode node, JobInfo jobInfo,
                             int retryCount, Map<String, Boolean> jobResults) {
        // ... 执行任务逻辑 ...
        
        // 任务执行成功后，捕获结果并存入上下文
        if (执行成功) {
            // 1. 获取数据上下文

            Object taskResult = parseTaskResult(jobInfo, jobLog);

            // 键格式：node_{nodeId} 或者使用任务名称
            String resultKey = String.format("node_%d_result", node.getId());
            dataContext.put(resultKey, taskResult, node.getId());
            
            // 也可以用任务名称作为键（更友好）

                dataContext.put(jobInfo.getJobDesc() + "_result", taskResult, node.getId());
            }
            
            logger.info("[TaskExecutor] 节点 {} 执行结果已存入上下文，键: {}",
                node.getId(), resultKey);
        }
        
        // ... 返回执行结果 ...
    }
    
    /**
     * 解析任务执行结果
     * 
     * 根据任务类型，从不同的来源提取结果数据
     */
    private Object parseTaskResult(JobInfo jobInfo, JobLog jobLog) {
        String glueType = jobInfo.getGlueType();
        
        switch (glueType) {
            case "BEAN":
            case "GLUE_JAVA":
                // Java任务：从日志中提取JSON结果
                return parseJsonFromLog(jobLog.getHandleMsg());
                
            case "API":
                // API任务：解析HTTP响应
                return parseApiResponse(jobLog.getHandleMsg());
                
            case "SQL":
                // SQL任务：返回查询结果集
                return parseSqlResult(jobLog.getHandleMsg());
                
            default:
                // 其他类型：返回原始日志
                return jobLog.getHandleMsg();
        }
    }
    
    /**
     * 从日志中解析JSON结果
     * 
     * 约定：任务执行时，将结果以JSON格式输出到日志中
     * 格式：【RESULT_START】{json data}【RESULT_END】
     */
    private Object parseJsonFromLog(String log) {
        String startMarker = "【RESULT_START】";
        String endMarker = "【RESULT_END】";
        
        int startIndex = log.indexOf(startMarker);
        int endIndex = log.indexOf(endMarker);
        
        if (startIndex >= 0 && endIndex > startIndex) {
            String jsonStr = log.substring(
                startIndex + startMarker.length(), endIndex).trim();
            
            try {
                return JSON.parseObject(jsonStr);
            } catch (Exception e) {
                logger.warn("解析JSON结果失败: {}", e.getMessage());
                return jsonStr;
            }
        }
        
        return null;
    }
}
```

```java
/**
 * 多节点结果合并器
 * 
 * 当一个节点依赖多个上游节点时，提供结果合并和访问能力
 */
@Component
public class MultiNodeResultMerger {
    
    /**
     * 合并多个节点的执行结果
     * 
     * @param context 数据上下文
     * @param dependencyNodeIds 依赖的节点ID列表
     * @return 合并后的结果对象
     */
    public MergedResult mergeResults(DataContext context, 
                                     List<Long> dependencyNodeIds) {
        MergedResult merged = new MergedResult();
        
        for (Long nodeId : dependencyNodeIds) {
            // 获取节点结果
            String resultKey = String.format("node_%d_result", nodeId);
            Object result = context.get(resultKey);
            
            if (result != null) {
                // 将结果添加到合并对象中
                merged.addNodeResult(nodeId, result);
                
                // 同时支持通过节点名称访问
                JobNode node = jobNodeService.getById(nodeId);
                if (node != null && node.getJobId() != null) {
                    JobInfo jobInfo = jobInfoService.getById(node.getJobId());
                    if (jobInfo != null) {
                        merged.addNodeResult(jobInfo.getJobDesc(), result);
                    }
                }
            }
        }
        
        return merged;
    }
}
```

```java
@Component
public class ExpressionEvaluator {
    
    /**
     * 计算表达式（支持多节点结果访问）
     */
    public Object evaluate(String expression, 
                          DataContext dataContext,
                          MergedResult mergedResult) {
        // 构建SpEL上下文
        StandardEvaluationContext spelContext = new StandardEvaluationContext();
        
        // 1. 注入数据上下文中的所有变量
        for (Map.Entry<String, Object> entry : dataContext.getAllVariables().entrySet()) {
            spelContext.setVariable(entry.getKey(), entry.getValue());
        }
        
        // 2. 注入合并结果
        if (mergedResult != null) {
            spelContext.setVariable("merged", mergedResult);
            spelContext.setVariable("mergedMap", mergedResult.toMap());
            
            // 将各个节点的结果也分别注入
            for (Map.Entry<String, Object> entry : mergedResult.toMap().entrySet()) {
                spelContext.setVariable(entry.getKey(), entry.getValue());
            }
        }
        
        // 3. 注入内置函数和工具类
        spelContext.setVariable("StringUtils", StringUtils.class);
        spelContext.setVariable("CollectionUtils", CollectionUtils.class);
        spelContext.setVariable("DateUtils", DateUtils.class);
        
        // 4. 预处理表达式
        String processedExpr = preprocessExpression(expression);
        
        // 5. 解析并计算表达式
        ExpressionParser parser = new SpelExpressionParser();
        Expression exp = parser.parseExpression(processedExpr);
        
        return exp.getValue(spelContext);
    }
    
    /**
     * 预处理表达式
     * 
     * 转换规则：
     * - ${variable} → #variable
     * - @nodeName → #nodeName
     */
    private String preprocessExpression(String expression) {
        // ${...} 转换为 #...
        String result = expression.replaceAll("\\$\\{([^}]+)\\}", "#$1");
        
        // @nodeName 转换为 #nodeName
        result = result.replaceAll("@(\\w+)", "#$1");
        
        return result;
    }
}
```

```java
            // 启动浏览器
            BrowserType.LaunchOptions options = new BrowserType.LaunchOptions()
                .setHeadless(config.isHeadless())
                .setChannel(config.getBrowserType()); // chromium, firefox, webkit

            String browserId = UUID.randomUUID().toString();

            // 返回浏览器ID，供后续节点使用
            return ExecutionResult.success(Map.of("browserId", browserId));
            
        } catch (Exception e) {
            logger.error("[Browser] 打开浏览器失败", e);
            return ExecutionResult.failure("打开浏览器失败: " + e.getMessage());
        }
    }
    
    /**
     * 导航节点
     */
    public ExecutionResult navigate(String browserId, String url) {
        Browser browser = browserInstances.get(browserId);
        if (browser == null) {
            return ExecutionResult.failure("浏览器实例不存在: " + browserId);
        }
        
        try {
            BrowserContext context = browser.newContext();
            Page page = context.newPage();
            
            logger.info("[Browser] 导航到: {}", url);
            page.navigate(url);
            
            // 等待页面加载完成
            page.waitForLoadState(LoadState.NETWORKIDLE);
            
            return ExecutionResult.success("导航成功");
            
        } catch (Exception e) {
            logger.error("[Browser] 导航失败", e);
            return ExecutionResult.failure("导航失败: " + e.getMessage());
        }
    }
    
    /**
     * 点击元素节点
     */
    public ExecutionResult click(String browserId, String selector) {
        try {
            Browser browser = browserInstances.get(browserId);
            Page page = getActivePage(browser);
            
            logger.info("[Browser] 点击元素: {}", selector);
            
            // 等待元素可见
            page.waitForSelector(selector, new Page.WaitForSelectorOptions()
                .setTimeout(10000));
            
            // 点击
            page.click(selector);
            
            return ExecutionResult.success("点击成功");
            
        } catch (Exception e) {
            logger.error("[Browser] 点击失败", e);
            return ExecutionResult.failure("点击失败: " + e.getMessage());
        }
    }
    
    /**
     * 输入文本节点
     */

            Page page = getActivePage(browser);

            page.fill(selector, text);

     * 提取数据节点
     */
    public ExecutionResult extract(String browserId, String selector, 
                                   String extractType) {
        try {
            Browser browser = browserInstances.get(browserId);
            Page page = getActivePage(browser);
            
            logger.info("[Browser] 提取数据: {}, 类型: {}", selector, extractType);
            
            ElementHandle element = page.querySelector(selector);
            if (element == null) {
                return ExecutionResult.failure("未找到元素: " + selector);
            }

                case "text" -> element.textContent();
                case "html" -> element.innerHTML();
                case "value" -> element.getAttribute("value");
                default -> element.textContent();
            };
            
            return ExecutionResult.success(result);
            
        } catch (Exception e) {
            logger.error("[Browser] 提取数据失败", e);
            return ExecutionResult.failure("提取失败: " + e.getMessage());
        }
    }
```

```java
            };
            
            logger.info("[Desktop] 点击鼠标: {}", button);
            robot.mousePress(buttonMask);
            robot.mouseRelease(buttonMask);
            
            return ExecutionResult.success("点击成功");
        } catch (Exception e) {
            return ExecutionResult.failure("点击失败: " + e.getMessage());
        }
    }
    
    /**
     * 键盘输入
     */
    public ExecutionResult keyboardType(String text) {
        try {
            logger.info("[Desktop] 输入文本: {}", text);
            
            for (char c : text.toCharArray()) {
                int keyCode = KeyEvent.getExtendedKeyCodeForChar(c);
                
                if (KeyEvent.CHAR_UNDEFINED == keyCode) {
                    logger.warn("无法输入字符: {}", c);
                    continue;
                }
                
                robot.keyPress(keyCode);
                robot.keyRelease(keyCode);
                Thread.sleep(50); // 每个字符间隔50ms
            }
            
            return ExecutionResult.success("输入成功");
        } catch (Exception e) {
            return ExecutionResult.failure("输入失败: " + e.getMessage());
        }
    }
    
    /**
     * 快捷键
     */
    public ExecutionResult hotkey(List<String> keys) {
        try {
            logger.info("[Desktop] 按下快捷键: {}", String.join("+", keys));
            
            // 按下所有键
            for (String key : keys) {
                int keyCode = getKeyCode(key);
                robot.keyPress(keyCode);
            }
            
            Thread.sleep(100);
            
            // 释放所有键（逆序）
            for (int i = keys.size() - 1; i >= 0; i--) {
                int keyCode = getKeyCode(keys.get(i));
                robot.keyRelease(keyCode);
            }
            
            return ExecutionResult.success("快捷键执行成功");
        } catch (Exception e) {
            return ExecutionResult.failure("快捷键失败: " + e.getMessage());
        }
    }
    
    /**
     * 屏幕截图
     */
    public ExecutionResult screenshot(String savePath) {
        try {
            logger.info("[Desktop] 截取屏幕: {}", savePath);
            
            Rectangle screenRect = new Rectangle(Toolkit.getDefaultToolkit().getScreenSize());
            BufferedImage screenshot = robot.createScreenCapture(screenRect);
            
            File outputFile = new File(savePath);
            ImageIO.write(screenshot, "png", outputFile);
            
            return ExecutionResult.success(Map.of(
                "imagePath", savePath,
                "width", screenshot.getWidth(),
                "height", screenshot.getHeight()
            ));
        } catch (Exception e) {
            return ExecutionResult.failure("截图失败: " + e.getMessage());
        }
    }
    
    /**
     * 等待延迟
     */
    public ExecutionResult delay(int milliseconds) {
        try {
            logger.info("[Desktop] 等待 {} 毫秒", milliseconds);
            robot.delay(milliseconds);
            return ExecutionResult.success("等待完成");
        } catch (Exception e) {
            return ExecutionResult.failure("等待失败: " + e.getMessage());
        }
    }
    
    /**
     * 获取键码
     */
    private int getKeyCode(String keyName) {
        return switch (keyName.toUpperCase()) {
            case "CTRL", "CONTROL" -> KeyEvent.VK_CONTROL;
            case "ALT" -> KeyEvent.VK_ALT;
            case "SHIFT" -> KeyEvent.VK_SHIFT;
            case "ENTER", "RETURN" -> KeyEvent.VK_ENTER;
            case "ESC", "ESCAPE" -> KeyEvent.VK_ESCAPE;
            case "TAB" -> KeyEvent.VK_TAB;
            case "SPACE" -> KeyEvent.VK_SPACE;
            case "BACKSPACE" -> KeyEvent.VK_BACK_SPACE;
            case "DELETE" -> KeyEvent.VK_DELETE;
            default -> KeyEvent.getExtendedKeyCodeForChar(keyName.charAt(0));
        };
    }
}
```

```java
@Component("imageRecognitionExecutor")
public class ImageRecognitionExecutor {
    
    private Screen screen;
    
    public ImageRecognitionExecutor() {
        screen = new Screen();
    }
    
    /**
     * 查找图像并点击
     */
    public ExecutionResult findAndClick(String imagePath) {
        try {
            logger.info("[ImageRecognition] 查找并点击图像: {}", imagePath);
            
            // 在屏幕上查找图像
            Match match = screen.find(new Pattern(imagePath)
                .similar(0.8)); // 相似度阈值80%
            
            if (match != null) {
                match.click();
                logger.info("[ImageRecognition] 找到图像并点击，位置: ({}, {})",
                    match.getX(), match.getY());
                
                return ExecutionResult.success(Map.of(
                    "found", true,
                    "x", match.getX(),
                    "y", match.getY(),
                    "score", match.getScore()
                ));
            } else {
                return ExecutionResult.failure("未找到图像: " + imagePath);
            }
            
        } catch (FindFailed e) {
            return ExecutionResult.failure("图像查找失败: " + e.getMessage());
        }
    }
    
    /**
     * 等待图像出现
     */
    public ExecutionResult waitForImage(String imagePath, int timeoutSeconds) {
        try {
            logger.info("[ImageRecognition] 等待图像出现: {}, 超时: {}秒", 
                imagePath, timeoutSeconds);
            
            Match match = screen.wait(new Pattern(imagePath), timeoutSeconds);
            
            return ExecutionResult.success(Map.of(
                "found", true,
                "x", match.getX(),
                "y", match.getY()
            ));
            
        } catch (FindFailed e) {
            return ExecutionResult.failure("等待超时，未找到图像: " + imagePath);
        }
    }
    
    /**
     * 在图像位置输入文本
     */
    public ExecutionResult typeOnImage(String imagePath, String text) {
        try {
            Match match = screen.find(imagePath);
            match.click();
            Thread.sleep(200);
            match.type(text);
            
            return ExecutionResult.success("输入成功");
        } catch (Exception e) {
            return ExecutionResult.failure("输入失败: " + e.getMessage());
        }
    }
}
```

## 总结与建议

### 核心要点

1. **条件控制节点**
   - 支持if-else、while、foreach三种核心类型
   - 基于SpEL表达式实现灵活的条件判断
   - GUI采用容器化设计，支持节点嵌套和拖拽

2. **参数传递机制**
   - DataContext提供线程安全的数据共享
   - 支持层次化上下文（父子关系）
   - 表达式语法支持多节点结果访问和合并

3. **RPA功能演进**
   - 网页自动化：集成Playwright实现浏览器操作
   - 桌面自动化：Java Robot + SikuliX实现基础操作
   - 分阶段实施，逐步增强能力

### 技术风险与应对

| 风险项 | 影响 | 应对措施 |
|-------|------|---------|
| 表达式计算性能 | 复杂表达式可能影响执行效率 | 1. 设置超时限制<br>2. 缓存表达式解析结果<br>3. 提供性能监控 |
| 数据上下文内存占用 | 大数据量场景可能导致OOM | 1. 设置上下文大小限制<br>2. 定时清理过期上下文<br>3. 支持数据分页处理 |
| GUI复杂度增加 | 容器嵌套可能导致渲染性能下降 | 1. 虚拟化渲染技术<br>2. 限制嵌套层级<br>3. 优化重绘逻辑 |
| 浏览器自动化稳定性 | 网页结构变化导致选择器失效 | 1. 支持多种选择器策略<br>2. 智能重试机制<br>3. 提供元素录制工具 |

### 后续扩展方向

1. **AI辅助编排**：使用大语言模型自动生成任务流
2. **可视化调试**：支持断点、单步执行、变量查看
3. **版本管理**：任务组配置的版本控制和回滚
4. **市场化**：构建任务模板市场，用户共享任务组
5. **云原生**：支持容器化部署和Kubernetes编排
