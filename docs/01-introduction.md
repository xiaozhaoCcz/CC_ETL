# 介绍 (Introduction)

## 项目简介

Cc-ETL 是一款基于 **XXL-Job** 深度改造的可视化定时任务调度平台，专为数据集成和任务编排而设计。平台通过可视化拖拽界面实现复杂任务流程的编排，支持多种任务类型，并深度集成 **DataX** 实现高效的数据同步能力。

> **说明**：目前项目还在测试阶段，部分功能仍在开发与优化中，欢迎学习与反馈。

---

## 项目定位

| 定位 | 说明 |
|------|------|
| **数据集成平台** | 专业的数据管道工具，支持多数据源间的全量/增量同步 |
| **任务调度中心** | 提供企业级的任务编排与调度能力，支持复杂工作流 |
| **可视化运维工具** | PC 端界面设计，提供直观的操作体验 |
| **企业级解决方案** | 支持高可用集群部署，满足生产环境要求 |

---

## 项目优势

1. **零中间件依赖**：仅需 MySQL 数据库即可完整部署，极大降低运维复杂度。
2. **可视化编排**：拖拽式流程设计，无需编程基础即可构建复杂任务链。
3. **多端协同**：当前以 PC 端为主，功能完备，支持离线使用。
4. **功能完备**：支持 Bean、API、SQL、Shell、DataX、GLUE(Java/Shell/Python/PHP/Nodejs/PowerShell/C#) 等多种任务类型。
5. **高性能设计**：基于 XXL-Job 内核，支持海量任务并发处理。
6. **高可用保障**：支持集群部署、故障转移、负载均衡。

---

## 项目亮点

- **开源项目**：基于 MIT 协议，完全开源免费。
- **社区活跃**：持续更新迭代，积极响应用户反馈。
- **PC 端成熟**：基于 JavaFX，489 个测试用例覆盖，功能稳定可靠。

---

## 核心组件（一句话）

| 组件 | 说明 |
|------|------|
| **Admin (cc-job-admin)** | 任务注册中心、调度中心、监控中心，提供 REST API 与 XXL-Job 兼容接口。 |
| **Executor (cc-job-executor)** | 单任务执行器，执行 Bean/API/SQL/DataX/GLUE 等各类任务。 |
| **Executor-Compose (cc-job-executor-compose)** | 任务组编排执行器，负责拓扑排序与依赖编排，调度子任务到 Executor。 |
| **PC GUI (cc-job-gui)** | 基于 JavaFX 的桌面应用，提供任务编排、画布、树形视图、日志等完整功能。 |
