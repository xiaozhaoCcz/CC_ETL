# 前端手册 (Frontend Manual)

本章介绍 PC 端（cc-job-gui）的主界面布局、十大功能模块、任务节点运行模式与高级配置。功能用例细节可参考 [GUI 功能测试文档](../doc/测试文档/GUI功能测试文档.md)。

---

## PC 端总览

PC 端基于 **JavaFX** 开发，主界面（MainView）采用多面板布局：

- **顶部**：工具栏（文件、编辑、视图、运行、用户信息）
- **左侧**：树形视图（分区 / 任务组 / 节点 / 边）+ 小地图
- **中央**：画布（NodeCanvas）+ 任务导航栏（标签页）
- **底部**：日志面板
- **底部状态栏**：状态信息

十大功能模块：顶部工具栏、画布交互、树形视图、任务导航栏、日志面板、小地图、面板管理、撤销重做、缩放平移、快捷键。任务节点支持 10 种运行模式及路由/阻塞/失败/超时/重试等高级配置。

---

## 顶部工具栏 (TopToolBar)

### 文件操作

- **新建任务**：打开新建任务对话框，创建单任务（可再被加入任务组）。
- **新建任务组**：创建任务组容器，需选择分区与执行器（建议选 cc-job-executor-compose）。
- **打开**：打开已有任务配置（具体行为以当前实现为准，如打开本地文件或拉取列表）。
- **保存**：将当前任务组的节点与边保存到后端；未选择任务组时会提示。

### 编辑操作

- **撤销 / 重做**：多步撤销（Ctrl+Z）与重做（Ctrl+Y），按钮根据历史是否可撤销/可重做自动启用或禁用。
- **框选**：切换框选模式，在画布上拖拽矩形可多选节点。
- **横向布局 / 纵向布局**：对当前选中的多个节点进行横向或纵向均匀排列。

### 视图操作

- **放大 / 缩小**：画布缩放，范围约 25%～300%。
- **适应画布**：恢复为 100% 缩放。
- 工具栏上会实时显示当前缩放比例。

### 运行控制

- **运行**：对当前选中的任务组发起执行；未选任务组会提示。
- **停止**：停止当前正在运行的任务组。
- 运行中时运行按钮禁用、停止按钮可用；支持多任务组同时运行。

### 用户信息

- 登录后显示用户名、用户 ID、头像（如首字母圆形图标）。
- 点击可弹出用户相关菜单（如登出）；未登录时该区域为空。

## 画布交互 (NodeCanvas)

### 节点操作

- **右键创建节点**：在画布空白处右键，选择「添加节点」打开节点配置对话框（需先选中任务组）。
- **拖拽移动**：支持单节点与多节点同时拖拽；连线会随节点移动而更新。
- **选择**：单击选中单节点；框选模式下拖拽矩形可多选。
- **连接器**：鼠标悬停节点时显示上下左右四个连接点，从一个点拖到另一节点即可创建边；支持连线实时预览；禁止自连接。
- **删除**：删除选中节点会级联删除相关连线。

### 节点右键菜单

- 编辑节点、复制节点、查看详情、更改颜色、禁用/启用节点、删除节点。

### 画布右键菜单

- 添加节点、运行任务组、粘贴节点、主题切换。

### 框选与对齐

- 通过工具栏进入框选模式后，在画布上拖拽出蓝色半透明选择框，可对框内节点批量移动、删除或使用横向/纵向布局；对齐操作支持撤销。

---

## 树形视图 (TaskTree)

- **层级**：分区（Partition）→ 任务组 → 任务节点、边节点；支持展开/折叠，空任务组有提示。
- **交互**：点击任务组可将其加载到画布；点击任务节点可在画布中高亮；画布与树形视图选择双向同步。
- **右键菜单**：分区（新建任务组、刷新等）、任务组（编辑、新建节点、删除等）、任务节点（编辑、删除、刷新等）。
- **搜索**：输入关键字实时过滤任务组与节点，支持模糊匹配；可清除搜索恢复全部。
- **运行状态**：运行中的任务组有运行指示（如闪烁）；完成后可有完成状态样式。

---

## 任务导航栏 (TaskNavigationBar)

- 选择任务组时会自动为其创建标签页，标签显示任务组名称；重复选择同一任务组会切换到已有标签。
- 点击标签切换任务组视图；可关闭标签，关闭当前标签后自动切换到前一个。
- 运行中的任务组在对应标签上显示运行指示器（如闪烁），多任务组可同时显示各自状态。

---

## 日志面板 (LogPanel)

- **级别与格式**：支持信息、警告、错误、成功等级别，不同颜色与统一格式（如 `[时间] [级别] 消息内容`）。
- **滚动**：新日志时自动滚到底部；用户手动滚动时暂停自动滚动；支持滚到顶部/底部。
- **搜索**：关键字高亮、实时过滤（防抖约 300ms）、大小写不敏感；无匹配时提示。
- **多标签**：全局标签 + 按任务组分的标签，不同任务组日志隔离；可清空当前标签、复制选中日志，并显示日志总数与搜索结果数。

---

## 小地图 (MiniMap)

- **缩略图**：实时显示画布整体布局（节点与连线缩略），比例约 1:10，画布变化时自动更新（节流约 200ms）。
- **视口**：红色矩形表示当前可视区域，画布滚动时同步移动；点击小地图可跳转到对应画布区域，拖拽视口可平移画布。
- **尺寸**：宽度随左侧面板、高度随窗口自适应，最小约 150×150px。
- **弹出**：可弹出为独立窗口，与主窗口画布同步。

---

## 面板管理

- **树形视图、小地图、日志面板** 均可单独关闭或恢复；关闭后出现折叠侧边栏与恢复按钮，分割线随之调整。
- **弹出**：树形视图、小地图、日志面板均可弹出为独立窗口（如 400×500、800×500）；弹出后功能保留，关闭弹出窗口后内容回到主窗口。
- 支持全部关闭、全部恢复、全部弹出及混合状态。

---

## 撤销重做系统

- **UndoRedoManager** 记录节点创建、移动、删除、连线等操作；支持多步撤销（Ctrl+Z）与重做（Ctrl+Y），并完整恢复节点与连线状态。
- 工具栏撤销/重做按钮根据是否有可撤销/可重做历史自动启用或禁用。

---

## 缩放与平移

- **缩放**：25%～300%，工具栏有放大/缩小/适应画布；到达边界后不再继续缩放。
- **平移**：拖动画布可平移；小地图视口矩形与画布位置同步，可通过小地图点击或拖拽视口快速定位。

## 任务节点：10 种运行模式

每个任务节点需绑定一个「任务」（job_info），并选择运行模式与执行器。

| 模式 | 说明 |
|------|------|
| **BEAN** | 执行 Spring 容器中的 Bean 方法，支持自定义 JobHandler、参数传递。 |
| **API** | HTTP/HTTPS 调用，JobHandler 一般为 runApiHandler，支持 GET/POST/PUT/DELETE 等。 |
| **SQL** | 执行 SQL 脚本或存储过程，支持多数据源、参数化查询。 |
| **GLUE(Java)** | 在线编写 Java 代码，集成 GLUE IDE。 |
| **GLUE(Shell)** | 执行 Shell 脚本与系统命令，跨平台。 |
| **GLUE(Python)** | 执行 Python 脚本，需 Python 3.6+。 |
| **GLUE(PHP)** | 执行 PHP 脚本，需 PHP 7.0+。 |
| **GLUE(Nodejs)** | 执行 Node.js 脚本，支持 npm。 |
| **GLUE(PowerShell)** | 执行 PowerShell，Windows 优化。 |
| **GLUE(C#)** | 执行 C# 脚本，.NET 生态。 |

任务组中的节点应选择 **cc-job-executor-compose** 作为执行器；单任务可选择普通 **Executor**。

## 任务节点：高级配置

- **路由策略**（10 种）：第一个、最后一个、轮询、随机、一致性哈希、最不经常使用、最近最久未使用、故障转移、忙碌转移、分片广播。
- **阻塞处理**（3 种）：单机串行、丢弃后续调度、覆盖之前调度。
- **失败策略**（2 种）：忽略、失败（标记失败并可能停止后续）。
- **任务超时时间**：单位秒，默认 300，0 表示不超时；超时后自动终止。
- **失败重试次数**：默认 0，可配置多次重试，重试间隔由调度侧控制。
