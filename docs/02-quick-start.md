# 快速了解 (Quick Start)

本章帮助你在约 5 分钟内了解 Cc-ETL 的核心组件、数据流向与使用流程。

---

## 核心组件

| 组件 | 职责 |
|------|------|
| **cc-job-admin** | 任务与执行器注册、调度触发、监控统计、REST API、SSE/WebSocket 实时状态 |
| **cc-job-executor** | 执行单任务：Bean、API、SQL、DataX、GLUE(Shell/Java 等) |
| **cc-job-executor-compose** | 接收任务组执行请求，拉取节点与边，拓扑排序后按依赖调用 Executor 执行 |
| **cc-job-gui (PC 端)** | 任务编排、画布、树形视图、日志、运行控制、数据源与任务管理 |

---

## 数据流向

整体流程：**任务配置 → 任务调度 → 任务执行 → 状态监控**。

```
┌─────────────────────────────────────────────────────────────────────────┐
│  1. 任务配置                                                              │
│     PC 端 / 接口 → 任务、任务组、节点、边、数据源 → 存储到 MySQL            │
└─────────────────────────────────────────────────────────────────────────┘
                                        ↓
┌─────────────────────────────────────────────────────────────────────────┐
│  2. 任务调度                                                              │
│     Admin 根据 Cron 或手动触发 → 选择执行器（Executor 或 Executor-Compose） │
└─────────────────────────────────────────────────────────────────────────┘
                                        ↓
┌─────────────────────────────────────────────────────────────────────────┐
│  3. 任务执行                                                              │
│     · 单任务：Admin → Executor，执行后回调结果与日志                        │
│     · 任务组：Admin → Executor-Compose → 拉取节点/边 → 拓扑排序            │
│               → 按层级调用 Executor 执行各节点 → 上报节点状态               │
└─────────────────────────────────────────────────────────────────────────┘
                                        ↓
┌─────────────────────────────────────────────────────────────────────────┐
│  4. 状态监控                                                              │
│     执行状态、日志 → Admin 存储 → PC 端通过 SSE/WebSocket/接口 实时展示     │
└─────────────────────────────────────────────────────────────────────────┘
```

---

## 使用流程

1. **环境搭建**  
   安装 JDK 17+、Maven、MySQL；初始化数据库；配置并启动 Admin、Executor、Executor-Compose（任务组需 Compose）；按需配置 DataX。

2. **系统配置**  
   在 Admin 中注册执行器；在 PC 端或接口中配置数据源、任务、任务组（节点与边）。

3. **任务设计**  
   在 PC 端创建分区与任务组，在画布上拖拽节点、连线配置依赖，设置任务类型与参数；保存任务组。

4. **执行监控**  
   手动或按 Cron 触发任务/任务组；在 PC 端查看画布节点状态、日志面板与运行指示器。
